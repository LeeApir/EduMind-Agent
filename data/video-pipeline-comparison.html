MANIM · STEP 01

确认动画场景

先把“链表中间插入节点”拆成可验证的状态变化，避免让模型自由发挥镜头。

输入：A → B → C，在 A 与 B 之间插入 X
初始：A.next = B
动作：创建 X → A 指向 X → X 指向 B
验收：最终链路 A → X → B → C
