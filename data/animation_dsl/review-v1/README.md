# DSL 独立审核运行材料

`prompt.md` 和 `schema.json` 是 ADR-0010 已批准附件的原字节副本，历史提案附件不修改。运行时记录准确 SHA256，并拒绝加载后文件漂移。独立审核模块为 `backend/app/agents/animation_dsl_review.py`。

T025 每次重新进行本地校验、编译与 AST 检查，向 review 档位发送完整规范 DSL、可信轨迹和服务端绑定的最小参考。参考独立上限 8192 UTF-8 字节；缺失、超限、目标不匹配不发送。未知画像保持空，不发送完整聊天、生成 Python 或凭据。生成来源必须由调用方提供实际 Gateway 模型来源、生成 Prompt 和采样摘要；审核来源由服务端选定路由和实际适配器记录，未知模型 revision 显式为 `unknown`。

输出严格按批准 schema 核验，并复核动作索引、NFC、控制字符及秘密/路径/原候选长段回显。单次审核 60 秒上限；独立 review 路由必须与 T012 当前选项一致，不隐式回退或重试。不可用与事实 reject 分开；revise 的具体意见仅在本次流程内供后续 T026 定向修正使用。失败数据库记录只有固定类别/严重程度/索引/错误码及摘要，不含未审核候选或审核自由文本。

Alembic `0023_animation_dsl_reviews` 新增不可变政策目录、审核记录、正式候选，以及只追加的政策/候选撤回记录。候选通过 owner/单元/场景版本/审核摘要复合外键绑定 pass；插入触发器复核实际 DSL/轨迹摘要及审核与政策一致性，内容与审核记录禁止 UPDATE。已有审核数据时降级拒绝，不能默默删除学习数据；按 owner 删除学习数据的正常级联仍可用。

当前运行版本必须由受信维护代码在自己的事务中显式调用 `admit_current_policy(db)` 登记；保存和读取不会自动登记或复活撤回政策。`qualified_candidate(..., lock=True)` 顺序锁定课程 release/单元/场景 → candidate → policy，以供 T028 在 Job 锁之后组合；撤回不反向锁 Job/cache。每次资格检查重新读取当前场景、参考、完整图谱摘要及政策，旧 pass 不是永久可用凭证。

T025 没有新增 HTTP、渲染 Job、媒体缓存或动态开放。T026 负责至多两次修正与模板降级，T027 负责实际容器重编译/渲染，T028 负责准备操作、Job/媒体引用和发布/读取资格。Fake/Mock HTTP 与隔离 PostgreSQL 验证不代表真实模型审核质量通过。
