# 阶段任务归档

根目录 `task.json` 只保存当前活动阶段，是开发任务状态的唯一事实来源。本目录保存已经完成阶段的最终任务账本快照，仅用于历史追溯、答辩证据和断点恢复。

## 规则

- 阶段退出验收完成且所有任务已有完成提交后，才允许归档。
- 将最终根 `task.json` 原样复制为 `docs/tasks/<phase>.json`，再用下一阶段任务替换根文件。
- 归档文件只读，不得从中领取任务、修改状态或补写结果。
- 若历史记录需要纠正，在 `process.txt` 追加说明，不改写归档快照。
- 阶段归档、根任务文件切换、规则更新和 `process.txt` 阶段事件应放在同一个治理提交中。
