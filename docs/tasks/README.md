# 阶段任务归档

根目录 `task.json` 只保存当前活动阶段。本目录保存已结束阶段的最终账本，只读追溯，不得领取或更新任务。

## 规则

- 阶段退出验收完成后才能归档。经批准的收尾决定明确暂缓的任务，保留原blocked及失败证据，不伪造完成；其余done任务须有完成提交。
- 将最终根 `task.json` 逐字节复制为 `docs/tasks/<phase>.json`，再用下一阶段细化任务替换根文件。
- 历史更正只在 `process.txt` 追加说明，不覆盖归档。后续恢复遗留能力须在新阶段建立任务并引用旧记录。
- 归档、根账本切换、规则与日志在同一治理提交中完成。未来阶段仅保留目标，正式进入后再细化。
