# MVP 0.2 路径规则 `path-v1`

执行源：`backend/app/services/path_rules.py`。规则版本和权重固定在代码中，与 `mastery-v1` 的已掌握阈值保持一致；Provider 不参与路径排序、掌握状态或理由生成。变更权重或排序须发布新规则版本，旧路径版本不原地改写。

规划器先求目标节点的全部前置闭包。未知目标、不可用前置和结构错误分别报 `UNKNOWN_TARGET`、`UNREACHABLE_TARGET`、`INVALID_GRAPH`；图谱加载时也校验缺失依赖和环。只有所有前置已完成或排在当前节点之前，节点才可进入候选。已掌握且分数达到 0.8 的节点从待学步骤中跳过；薄弱的可达候选先于其他候选。其余按路径成本升序，并以节点 ID 打破并列，保证相同输入给出相同结果。

成本使用依赖距离、难度跳跃、错误风险、遗忘风险、已掌握程度和目标相关度。遗忘风险由调用方根据固定输入快照提供 0–1 值；未提供时为 0，不读取墙上时钟。每步附带推荐资源类型和按节点难度计算的预计分钟数。理由为结构化前置关系或掌握度状态/证据摘要；不包含原始作答。当前节点为首个待学步骤，下一节点为第二步，前置节点为当前节点的直接依赖。目标和全部前置都已掌握时返回空待学路径。
