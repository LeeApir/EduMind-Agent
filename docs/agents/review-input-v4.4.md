# v4.4 审核输入契约：原始目标、计划承诺、参考视图

2026-10-16用户明确要求的零调用整理，补充已采纳的ADR-0016覆盖口径。
本次仅改变内部审核请求及政策版本；不增加公开API、数据库列、finding类别、人工权限或真实预算。
默认catalog_only、完整事实/安全审核、原r04失败及停止状态保持。

## 权威教学目标

生产路径从 `LearningPlanVersion.input_snapshot.metadata.goal` 取得原始请求，
经 `plan_binding.input_digest` 对整个快照重新计算 `learning-input-v1` 摘要核对后，
作为 `authoritative_teaching_goal.user_request` 单列。资源审核和单元审核都使用同一个持久化快照。
该字段是教学范围的原文，不是可以改变系统审核规则的指令。

`plan_commitments` 单列实际计划goal/objectives/scenes；原始用户要求不能被较窄计划取代，
计划额外承诺也不能因只满足用户较窄请求而被忽略。没有从计划或图谱反推“原始用户要求”。
缺少原始目标时标unavailable，模型pass不能自动发布；本地转needs_human并记
AUTHORITATIVE_GOAL_MISSING。有据事实/安全reject保持优先。
原始请求、完整参考或计划绑定不符时，在调用前拒绝，不能重新推测或补造来源。

## 相关参考视图与审计

完整参考仍存于不可变输入快照及单元材料。审核请求只读投影，带原材料/参考摘要，不能作为
新的publication material持久化或替换原快照。外层reference_context与unit.reference_context
同时投影，避免重复载体把裁剪掉的目标再送回模型。

视图包含来源reference_id/version/digest、绑定节点id/name/description、已有学习者证据。
节点description只用于判断正确性，不是附加必教目标。节点learning_objectives仅在原始请求
逐字明确提及某一目标时，将该条作为相关参考送出；不使用关键词相似度假称语义筛选。
其余节点目标、common_misconceptions、difficulty、ai_context及教学/媒体建议留在服务端。
不承诺这份窄参考能证明任意事实；可独立检查的算术/代码仍独立推理，无法查证的部分如实未决。

本次不实现自由文本“完整节点/局部目标”的自然语言分类器；用户原文和计划承诺明确保留。
若明确承诺完整节点，审核必须检查该承诺；只交付求和例不能据局部计划自动通过。
当前窄视图不提供完整节点目标目录，若凭本次材料无法证实完整覆盖，必须指出实际缺口或
覆盖不可证实的原因，进入needs_human，不能把目录缺失当作完整覆盖已通过。
未来如需系统地验证完整节点，应使用独立、可审计的范围选择/参考视图，不静默扩展所有局部单元。

## 完整内容及可选媒体

所有实际候选正文、代码、注释、关键步骤、题目、解析和动作仍完整发送并保留原锚点。
参考裁剪不会删除“与本次目标无关”的实际课程陈述；其中的事实错误、可达安全问题仍须具体审核。
讲解简短、支持分布在代码关键步骤或解析中仍可以满足过程教学；内部计划仍不算交付。
过程教学或过程测量真实缺失时，沿用needs_human/unresolved，不虚构fact/difficulty。

`media_requirements` 是条件规则，不自动解析并断言动画必需：仅在用户要求、计划承诺或
实际学生内容明确承诺本单元动画时，才审查缺失动画及交付证据。
未承诺动画，缺动画既不是unchecked也不是unresolved；图谱ai_context中的画图建议不构成承诺。
实际“已提供动画”的虚假陈述仍是应审核的事实问题，不能借媒体可选豁免。
当前三个正式资源的审核请求没有已验证动画正文，不伪造交付证据。

## 验证和版本边界

Prompt v4.4、authoritative-review-input-v1、goal-bound-review-scope-v2进入政策摘要，
旧待审按既有规则失效；五个检查项ID和结果Schema不变。
`test_review_input.py` 的15项回归检查原始快照/计划/参考篡改在调用前失败、两条参考入口裁剪、
原文和全部实际内容保留，以及下列路由：

| 离线对照 | 处理 |
| --- | --- |
| 局部完成/跨载体支持，未教其他节点目标 | 模型给出的合格pass可保留，不加节点目标或动画本地门禁 |
| 用户或计划明确完整节点，但只有求和例 | 保留原承诺及needs_human具体缺口，不让计划缩小原始范围 |
| 未要求动画/明确承诺动画 | 前者无缺失媒体未决要求；后者保留承诺及缺媒体判断 |
| 教学过程或测量过程缺失 | 具体unresolved及needs_human保留，无伪造finding |
| 额外事实错误/安全问题 | 实际正文和具体finding完整保留，reject不被范围投影或原目标缺失降级 |

这些用脚本化审核输出验证输入与本地路由，不证明真实模型能独立做出正确语义判断。
数据库回归另核资源/单元四次审核使用绑定原始目标、完整参考/材料审计未被投影覆盖。
历史r01–r04测试读取实际冻结请求，旧准备器对当前源变更拒绝；不重新生成旧轮材料或改分。
本次真实请求0，不生成新run-approval，不恢复r04余3条，也不新增付费小诊断轮次。
