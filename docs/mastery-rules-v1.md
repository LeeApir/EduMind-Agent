# MVP 0.2 掌握度规则 v1

规则标识 `mastery-v1` 对应 `backend/app/services/mastery_rules.py` 中的固定配置；修改任一权重、阈值或舍入方式必须发布新规则版本。输入为同一 owner、同一知识节点按 `created_at, id` 稳定排序的已提交学习证据；不读取模型输出或墙上时钟，因此同一证据序列可重算为同一结果。

每条有效测验按服务端评分更新 0–1 分值：首次正确得分的增益系数为 0.55，后续复习测验为 0.4125；每次测验先保留旧分的 98%。低于 0.5 的测验按连续错误次数增加扣分，最多按三次计算。提示一级/二级分别扣 0.04/0.08；重新解释只标记需要支持，不推断答错或直接扣分。资源选择和显式反馈不产生正确性；“跳过”“标记已会”绝不直接推成 `mastered`。

每条证据后将分值限制在 0–1，并使用 Python `round(value, 4)`（中点取偶）固定到四位小数。低于 0.4 或最近有困惑风险时为 `weak`；达到 0.8 且无近期风险为 `mastered`；其余为 `learning`。没有证据时才是 `unseen`。一次有效变化创建 `node_mastery_revisions`，记录前后分值、状态、规则版本和触发证据 ID，并替换 `node_mastery_current`；即使分值/状态未变化，新证据仍可将现有路径标为待重规划。

测验提交在同一 PostgreSQL 事务中插入证据、重放该节点证据、创建 revision、更新当前投影并写入持久化的路径待重规划标记。按 owner+节点取得事务级锁，避免并发写入乱序。T014 的提示和反馈命令沿用同一规则与事务入口；T017 负责短事务路径重算。
