# ADR0065 补充 · 栈双画像提示词 v2 有限试验

当前仅冻结准确执行包。真实发送需单独批准本包及本批 C2。

1. 固定 T135 的 v2 A/B 原始请求，分别为同一栈目标和程序材料下的两份合成自述。两槽均生成新正文，单独绑定新操作、封存、审核与私有课程版本。T134 的 A 课程和 B 失败记录仅供历史追溯。
2. 沿用共用入口和 ADR0065 双槽规则。全批 0 次规划、2 次正文、0 次修订，每槽各一次，无重试、回退或探测。建议 A 后 B，各槽创建操作起独立 1,800 秒，发送前预留 90 秒 I/O 边界。审核和准入在各槽窗口内；学习验收可随后进行。失败或未知时保留原件、停止该槽，另一槽按其授权独立执行。
3. C2 延续尽力停止、停止后仍可能迟发或计费、实际金额未知且无可验证费用硬上限、本机原件无独立抗回滚保障、服务端留存未独立验证。每请求 `max_output_tokens=4000`，累计 8,000 为请求参数上限。每槽输入回报须 ≤139,264、输出回报须 ≤4,000，这些校验阈值无法约束收费。
4. 先逐课审核并逐项定位实现因果说明，保留 T132 三项差异标准和课程、对照分开判定规则。允许两课共享必要知识。各自正确但差异不足时保留可学课程，记录对照未通过。若只有一课可学，记录对照未完成。
