# ADR-0027：新自由课程独立验收口径

- 状态：Proposed，等待准确 A—E 及 manifest 附件批准。
- 日期：2026-10-22；任务：PHASE-1.5-T005。
- 输入：PRD §0.5/§9.1、ADR-0023、已批准 ADR-0024/0025/0026 与已确认 T004 设计。
- 本次只有方案；实际 Provider 请求/费用授权均为 0，运行保持 catalog_only。

## 需要批准的决定

| 决定 | 具体内容 |
| --- | --- |
| A 质量对象与阈值 | 首次 schema≥98%；完整草稿、需求兑现、可学性各≥95%；画像对照≥90%；事实单元≥99%、答案/评分键100%且无严重错误；审核严重错误召回≥90%、意见精确率≥90%，正确对照不得被误阻断。精确分母与无法判定处理见附件。 |
| B 样本和独立性 | 开发12个课程槽、6对画像；独立质量40槽（10对画像20槽+20单目标），另20严重错误/20正确审核对照；至少100个首次结构输出。独立性能另40槽；样本不足不缩分母。H继续封存，由T039只读核对资格元数据，不擅自读取内容或用来调优。 |

| D 工程与停止 | 安全/身份/版本/隔离/预算/撤销工程用例100%通过且0skip；未知发送不重发；全固定槽记录；任何严重教学错误、安全泄漏/越权、预算异常或独立性污染立即停止；不重新抽样冲淡失败。 |

## 解释与取舍

学生能直接学草稿是既定方向；这个决定不要求模型意见全部通过后才可见。schema和人工语义评测分别计分；草稿可见不等于已签核或有可靠答案。正式掌握度准入与缺陷确认继续遵守ADR-0026，不能靠本验收人工标签直接写入产品签核。

采用课程、原子事实/答案、成对画像和故障用例不同分母，防止长课程稀释短课程失败。全局率之外，各主题及已知/未知画像分层须达到同一课程级质量门槛；小分层取整会要求全部通过。40槽只提供本批有限样本证据，不声称总体错误率或统计置信保证。

保留原PRD的98/95/90数值和首段10秒目标；首次结构计算不由修复成功抹去，正式资源旧95%与旧P1失败仍保留。本提案新增草稿质量判据和完整场景计时，不追认旧正式发布能力。若真实性能无法达到，T041 blocked，须另提明确范围/阈值变更，禁止执行时自行放宽。

所有准确规则见[验收契约](../acceptance/phase-1.5-acceptance-contract-r01/contract.md)、[机器可读政策](../acceptance/phase-1.5-acceptance-contract-r01/policy.json)、[计算边界例](../acceptance/phase-1.5-acceptance-contract-r01/examples.json)与[manifest](../acceptance/phase-1.5-acceptance-contract-r01/manifest.json)。后续批准登记优先于冻结文件的Proposed/pending字样，原件不得回写。
