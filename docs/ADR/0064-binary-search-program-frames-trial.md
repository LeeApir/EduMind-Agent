# ADR0064 二分查找程序帧说明版单次新正文验证

状态为零调用准备，真实执行待用户批准准确清单、请求及下述 C2 边界。

1. 固定主例为升序数组 `[2,5,8,12,16]` 查找 `5`，沿用 T129 的 `binary-search-program-frames-v1` 原请求。程序持有固定提纲、代码、事实、六帧及说明、迁移题材料和答案。模型只返回讲解、引用、总结、四题题干及解析。
2. 共用命令增加 `--topic binary-search-program-frames`。新批次 `binary-search-program-frames-r01` 使用既有专用回环开发库与新的独立课程、操作和原件目录。批准绑定清单、请求、额度和窗口。候选绑定操作、请求、响应收据及程序材料；新的独立全文审核绑定候选摘要，额外核对正文与程序轮次一致。场景版本保存请求、响应和审核摘要。T129 封存候选及审核白名单仅适用于原回放。
3. 拟批准 DeepSeek 官方 Responses 一次 `deepseek-flash` 请求。规划、修订、回退和重试额度均为 0。操作创建即登记新 1,800 秒窗口，开始发送前预留既有 90 秒 I/O 超时额度。超时是传输的 I/O 限制，实际墙钟不保证在 90 秒中断。真实准入须在窗口内完成，随后进行浏览器学习验收。
4. C2 例外沿用单前台传输的尽力停止语义。HTTP 请求最多 1 次，请求体最多 131,072 字节，参数 `max_output_tokens=4000`；本机保留固定请求及实际回报用量，金额、缓存命中与服务端最终计费未知。停止后的在途请求仍可能迟发或计费，原件目录无独立抗回滚保护；`store=false` 回显无法独立验证服务端保留行为。不复用任何历史额度。
5. 在首次结构、独立全文教学审核或准入出现失败时，保留原件及具体原因，使用共用停止命令。不给失败课追加补写、修订或重试。通过仅交付私有开发草稿，T038、T102 和 T128 的历史判定保持。
