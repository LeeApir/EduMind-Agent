# ADR0055 固定头插方案的新输入端到端验证

状态：零调用接线获准。以下运行契约为新批提案，待执行包评估和用户准确批准。

## A. 输入和同版材料

T111 固定目标由真实应用表单保存，准确文字见执行包 `goal.txt`。支持清单只含 `head-new-C`，初始 `[5]`，依次插入 `-2、9`，两次假定分配成功。先备知识为自述。入口要求空画像，避免把额外学生信息带入这次固定输入。真实规划仍负责目标、引文、场景及教学顺序。本批测固定输入的流程复用。

沿用 T108 规划 wire v2、本地完整 Schema 和教学输出 Schema。新规划请求的程序依据只列 C。相对 T109 r01，**首稿**就携带 T110 的版本化补充证据。程序按实际 13 帧推导展示范围，并单独计算忽略两次返回值的对照。独立期望为接收后 `[9,-2,5]`，忽略后 `[5]` 且 `t0/t1` 不可达。T108/T109 的请求与旧记录按原版本复核。

## B. 首次结果、审核和有限修订

先以严格 JSON、响应协议、Schema 和材料绑定验首稿。拟保留 ADR0053 唯一格式恢复例外，即正文内既定四题各最多重复两次且值与类型完全相同，仅确定性删除第二成员。保存严格失败、原始字节和派生位置。其他协议错误直接停止。修订响应必须严格通过。

独立评估逐段、逐帧、逐题核对，见执行包 `review-policy.md`。首稿或合法恢复稿通过即准入。相对 ADR0053，允许位置增加 `failure_scope`。相对 ADR0054 的 B 局部修订，本批从准确候选和本次审核生成封闭 Schema，位置不限于 B 的固定段。最多一次修订，允许位置为 `paragraphs[i]` 完整文字及引用、`learning_summary`、`failure_scope`。每条阻断意见须可定位、可修复且引用父稿原文。程序合并仅替换批准位置，复算候选并拒绝未知 ID、额外字段和邻段原文复制。引用支持、职责保留、近似复制、解释遗漏及全文一致性由独立重评判断。

范围外阻断、规划／协议／程序事实／安全失败或修订后仍不通过，保存证据并停止。程序代码、事实、状态、答案、题干、解析、步进说明、生命周期、目标、规划及证据全程绑定。模型输出后若需改冻结运行范围或扩大允许范围，本轮复用验证失败。

## C. 批次与费用

拟用 `head-fixed-r01`，最大 3 次 HTTP。真实规划 1 次、正文首稿 1 次、条件修订最多 1 次。发送窗口提议 600 秒，实际起止在用户批准并就绪后登记，以批次窗口与应用操作有效期中较早者为准。每次由用户从单前台入口启动，阶段间人工独立审核。规划与正文输出各 8,000 token，修订 4,000，合计预约最多 20,000。每请求本地输入预约 139,264，合计 417,792。请求上限 131,072 字节，响应 2 MiB，I/O 超时 90 秒。参数与命令见执行包。

拟沿用明确的单批 C2 例外。前台尽力停止，最后检查后仍可能迟发或继续计费。原件保存在本机，无独立抗回滚保障。账单金额无可验证硬上限，本地 token 限制和 Provider 自报用量用于记录。旧批授权为零继承，T102 仍 blocked。任何需要核实费用或风险条款的判断在新授权前完成。

## D. 产品投影与最终验收

新来源 `head-fixed-course-v1`／`head-fixed-r01` 包含证据版本和摘要，区分真实首稿、格式恢复、模型局部修订和离线夹具。沿用原操作与私有版本从 v1 到 v2 的准入路径。公开页面呈现候选与材料来源，参考答案继续由服务端私有保存，反馈仅用于课程内比较。

准备阶段只验证固定执行入口至真实本机开发库及课程投影。最终验收还要有真实原件、独立全文结论和实际浏览器学习记录。首次结构、首次教学、格式恢复、模型修订、最终交付分开记录。阶段边界与 T038 门槛沿用原契约。
