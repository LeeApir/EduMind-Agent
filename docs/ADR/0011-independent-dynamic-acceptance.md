# ADR-0011：独立动态验收、预算与开放门禁

状态：**Proposed，等待用户批准 A–D**。任务：PHASE-1-T035。

依据：PRD §0/0.1、§9.1、[已批准的 Phase 1 验收计划](../acceptance/phase-1-acceptance-plan.md) §3–5。本文不修改旧 T033，不扩大 Phase 1 产品范围，不批准任何真实调用。完整附件与源码版本绑定见 [提案 manifest](../acceptance/phase-1-dynamic-v1/manifest.json)。

## A. 历史失败与固定集合

历史归档 `588f5dc90680ab551b70f13c5f8a77c8cece6b60` 只读。附件保存 8 个历史审核输入的原 ID、内容/请求 hash、原始用户 payload，以及 9 个历史未发布槽的记录 hash。旧结果仍为 blocked，2033/2500 不转为新授权。历史 payload 可由原归档逐字核对；采用新指令时，明确称为新配置复验，不冒充原请求重放。

诊断只用历史样本，四组分别执行：5 个错误检出、同 5 个分类观测、1 个正确对照、2 个长审核。每组各需独立授权；分类组再次发送也另计费。每个缺陷必须被具体定位、类别正确，正确对照必须 pass，长审核必须完整且 schema 有效。任一失败即停止本组，不自动切换到另一组或正式集合。若历史材料被用于调参，继续留在诊断组，不能计入新例。

正式资源审核新例固定 **20 严重错误 + 20 正确对照 + 10 长审核**，文件顺序为发送顺序。严重错误为不同的 C 内存/边界缺陷，标签仍待人工核对；长例为 100 步变长数组操作轨迹。100 个新生成槽为当前 10 节点各 10 目标，固定 C，不推断未知画像；另报告 9 个历史未发布槽复验，历史组和新组不合并。所有正式新例禁止用于诊断调参；一旦泄露给调参环节，该集合退休，并在新轮次重新冻结新例，不能保留其成绩。

样本上的 `pending` 是批准前状态。批准本附件视为批准列出的预期标签；执行前受信组合层必须保存批准记录的确切 hash，而非改写样本状态。如人工发现标签错误，先修改提案并重新批准，禁止跑完再改标签。

## B. 分组判定与观测

保留原指标：新生成 100 槽首次完整 schema ≥98%，三类必需资源最终全部审核并发布 ≥95%，已发布资源最终 schema 100%；每一实际生成/审核组合独立计算。严重错误检出 ≥90%，分母固定 20，超时/截断/无效输出和泛泛 reject 均不是检出。

提出以下**新增准入阈值，须本 ADR 批准后生效**：分类准确率 ≥90%（同 20 缺陷全分母；只有具体检出且类别正确计分），正确对照 pass ≥95%（20 槽，最多误拒 1），长审核完整结束且 schema 有效 ≥95%（10 槽，因此需要 10/10）。长审核“完整”不代表事实正确，事实标签和误拒另外列报。正确对照发生重大错误断言时立即停止，不能以平均比例掩盖。正式组出现具体严重漏检或环境/协议失败立即停止，后续未运行槽留在分母；不能替换补跑、跨配置拼成绩。

人工检出标注绑定 case/input hash、实际响应 hash、具体缺陷、位置、类别及人工标注记录 hash。机器统计器接受受信组合层已核对的观察数据，不自动从 reject 文本推断正确；布尔标注不是签名或发布授权。保存调用 ID 摘要、阶段、终止原因、可见输出/推理 token（未知单列）、schema/事实结果和固定错误码；不保存 Key、原始厂商错误、完整私有对话。

计时仍沿用验收计划，失败/超时/缺失终点计 +∞；HTTP 首字节、教学正文首 token、完整首段、动画可播放分别记录，不混用。本文没有任何真实质量或性能通过结果。

## C. 精确配置与费用预留

当前配置模板为 `DRAFT_NO_TARGET`，模型、价格和真实调用授权都未确定，额度 **0 请求 / 0 费用**。不默认选择模型。T039 在调用前为本地/云端/各原生目标分别形成完整 `FROZEN_RUN_READY`：实际 Provider/目标 digest、模型/可得 revision（不可得记录 unknown）、adapter/能力、完整提示与采样/推理/输出限制、参考输入、代码/锁文件、槽顺序、超时、缓存/预热规则、批准前置证据及计费上限；生成 quality 和独立 review 的组合分别绑定。T026–T028/T037 的未来代码不能以当前 hash 冒充已冻结，实际轮次必须重新冻结并批准。

`scripts/acceptance_support/phase1_budget.py` 提供仅供本地验收使用的 SQLite 原子预留计数器：先预留再发送，单轮最多 1 个在途尝试；重启不重置、失败不退款、用量未知或超过已证明上限立即停。探测、模型刷新、画像、生成、审核、修正、预热以及实际重试/回退均占请求与费用。最多 2 次定向修正按每资源计算，每次全量重审，审核不可用不能触发自动修正。每槽和每轮均有上限。

计数器检查实际 wire 的输出总 token 上限字段，输入以实际 wire 字节数加已证明的额外 token 上限保守预留，输出包括推理与可见文本；价格、额外收费、token/字节上界、总输出限制无法证明时不得启动。只使用同币种 micro-unit，分别向上取整，不猜汇率，不依赖优惠/缓存折扣。免费本地目标也要明确请求授权；价格为 0 不能绕过调用计数。

该计数器没有网络、密钥读取或生产配置入口，**不是完整鉴权器**。受信验收组合层仍须验证批准记录、阶段证据确实通过、wire 对应槽输入及实际目标/模型、ADR-0008 同意/凭据版本/SSRF 与发送锁，并强制 transport 超时；目前未构建真实发送器。`Approval` 只能由该组合层解析真实人工记录，不能把任意 JSON 布尔值当授权。T039 真实接入前须测试这条完整调用链，不能仅凭计数器单测启用网络。

## D. 测试与正式开放分离

批准 A–D 只允许冻结规则并继续实现，不批准付费或开放。T039 接入、T040 各诊断组、T040 正式质量、T041 E2E 各自审批确切轮次/目标/请求/费用/范围，上一阶段通过不自动授权下一阶段。回退目标必须单独批准，禁止静默跨厂商。

当前 `catalog_only` 保持。动态资源/课堂只能在同一冻结组合的 T040 质量通过、T041 测试范围和预算获批后，在隔离环境验收；正式开放还需明确批准能力、配置和证据版本。DSL 还需 T026–T028、T037 完成，并单独冻结具体事实错误/正确/长候选及生成、渲染集合，经人工批准、独立真实审核质量与实际画面/媒体验收；本文资源样本不授权 DSL 或用资源分数替代 DSL 分数。新模型、审核 pass 候选、AST 通过或 Worker 安装均不解除门禁。

旧目录内容、owner/CSRF、人工签核、撤回、租约、媒体隔离与禁止任意代码边界持续有效。任何配置或代码/Prompt 变化使原轮次失效，形成新轮次并重新审批；不降低旧指标。
