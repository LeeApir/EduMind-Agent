# ADR-0025：渐进课程生成、恢复与局部修订

- 状态：Proposed；PHASE-1.5-T002，2026-10-21。
- 前提：[ADR-0023](0023-free-course-learning-and-ui-direction.md)方向及[ADR-0024批准](0024-approval-20261021.json)。
- 本提案仅设计；Provider实际请求授权仍为0，运行保持catalog_only。

## 具体决定提案

| 决定 | 拟冻结规则 | 影响 |
| --- | --- | --- |
| A 渐进状态 | 大纲默认继续，完整首场景入清单后才发first_scene_ready；部分完成、生成状态、学习进度独立 | 不用空卡片或流片段代表可学，后续故障保留已就绪内容 |
| B 持久调度与事件 | 独立PG操作/步骤/预约/事件/收据表，PG轮询worker；每课/owner最多1活动操作、全局2；租约45s/心跳10s/围栏令牌 | 不占HTTP连接做持久调度，不把旧动画Job当课程操作；GET EventSource可重放 |
| C 规模与成本 | 1–8场景；单操作13次尝试/600s/输入200k输出48k token；单调用120s/输入32k输出8k；每课累计40次/输入600k输出144k | 上限不是授权额度或性能承诺；失败/取消/未知用量计入，额度不足不启动新调用 |
| D 重试、取消、恢复 | 自动传输重试总2次、每步骤1次；格式修复总2次、每步骤1次；未知发送结果不自动重发并隔离调用槽，可信结算前阻止新调用；取消围栏阻止晚写 | 刷新不扣费；恢复须显式新键和新操作，仍受课程累计上限 |
| E 局部修订与媒体 | 修改锁定基线，重建目标及依赖后代；旧清单直到替换子集完整就绪再原子切换；可选媒体不阻断可学 | 普通优化保留旧版；已确认错误按T003禁用事实阻断旧版，不能靠历史绕过 |

规范附件：[状态与执行契约](../acceptance/phase-1.5-generation-contract-r01/contract.md)、[状态/预算表](../acceptance/phase-1.5-generation-contract-r01/policy.json)、[API补充](../api/phase-1.5-generation.openapi.json)、[正负例](../acceptance/phase-1.5-generation-contract-r01/examples.json)。[manifest](../acceptance/phase-1.5-generation-contract-r01/manifest.json)绑定准确文件；当前无批准登记。

## 与T001的关系

保持T001冻结字节，新附件仅补足其预留的操作、事件、计划状态与规模字段，不改owner/版本/旧课程边界。T001的OpenAPI是初始读取投影；本提案增加操作端点与场景表达schema，T021依两个批准记录合并，现行主OpenAPI及路由不变。

T003仍须冻结缺陷确认、练习反馈/评分、导师上下文；T005仍须冻结质量及性能测量。此处资源上限不代替验收阈值。后续真实验证另需准确执行包、费用及请求批准；不得自动恢复旧余额、调用延期厂商或切换Provider。

## 取舍与批准

PG轮询优先复用现有PG基础，避免先引入新的Broker投递依赖；保留将来经ADR引入Celery的余地。单课串行按拓扑顺序生成，首版牺牲并行吞吐换取明确的版本与成本控制。Provider不提供幂等保证时无法承诺网络外部恰好执行一次，因此发送结果未知即停，并如实保留预约。

请批准或修改A—E及准确附件，特别是数值上限、未知结果停止与修订影响规则。批准前T002不done，不实现对应调度或接口。已确认A—F产品方向不重复审批。
