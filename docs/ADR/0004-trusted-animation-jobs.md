# ADR-0004：可信模板渲染与持久化动画 Job

- 状态：Proposed，待用户批准；未实施
- 日期：2026-09-28
- 关联任务：MVP-0.3-T002（接口细化 T004；实现 T005–T015）
- 依据：[PRD](../PRD.md) §3.3、§8.3、§9.2、§10.4

## 目标与替代方案

动画仅按需运行。优先已审核预渲染缓存，其次可信参数化模板；不执行模型生成 Python，不开放完整 DSL、Redis/Celery、TTS、任意命令或上传模板。仅进程内队列无法恢复；数据库事务内渲染会长期占锁；完整分布式队列超出P0，因此选择 PostgreSQL 任务表与独立轮询执行进程。

以下均为具体待批准决定，不因提交此文件而生效。现有学习操作恢复语义仍按 ADR-0002，不向其追授可靠中断检测。

## 决定 A：可信输入与执行沙箱

模板注册记录固定 ID、模板版本、源代码摘要、参数 schema、人工教学审核与版本化静态审核记录。仅链表插入/删除；参数白名单为有界节点整数值数组、操作索引与插入值，不接受代码、路径、URL、模块、场景类名或命令。范围与边界行为由 T005 固定，未审核版本不得被选择。

编译仅从受版本控制模板注入已校验类型字面量，之后再做 AST/静态规则检查：业务模板仅允许指定 Manim API 与有限纯计算；禁止任意导入、动态属性逃逸、反射、eval/exec、shell、网络和任意文件访问。AST 不是隔离的替代品，Manim 内部合法媒体写入由容器约束。

执行进程与API分离。每次尝试使用固定摘要镜像及非root用户、只读根文件系统、无宿主socket/设备/密钥、禁网、drop all capabilities、no-new-privileges及受限进程数128。仅挂载当前尝试的已审核输入目录只读、输出目录可写；临时目录受限256MiB；每次尝试的输出挂载必须有256MiB总量硬配额（含中间文件），无法建立配额时拒绝执行，不依赖渲染结束后的大小检查。不挂整个媒体库/代码仓库。限制为CPU 2核、内存1GiB、总墙钟120s，超时终止整棵进程树；无Docker或隔离验证失败时返回 RENDER_UNAVAILABLE，禁止宿主回退。渲染容器不连接数据库、不接收Cookie/Provider密钥。

仅固定执行器构造命令参数，无shell字符串拼接。输出相对路径和类型白名单 MP4/SRT，拒绝符号链接、路径穿越、额外文件及单文件超过64MiB；执行器检查 MP4 可解码、时长30–90s、SRT时间范围与字幕非空有效，以及参数/模板教学审核适用性。P0无模型调用，正式动画需 schema、可信模板Review规则审核记录与媒体校验全部通过；任一失败不发布。容器包、字体、Manim版本及渲染参数须固定并计入缓存键。

## 决定 B：持久化领取与状态

PostgreSQL 为唯一事实源：Job记录 owner、学习单元/场景已审核版本、规范化参数摘要、模板/审核/渲染器版本、幂等请求摘要、状态、attempt、lease_token、lease_expires_at、取消标志、资源引用及单调事件序号。所有引用使用包含owner/单元的约束，不允许跨owner绑定。

| 起点 | 动作/条件 | 终点及原子写入 |
| --- | --- | --- |
| 无 | 合法请求且缓存命中 | succeeded；建立owner授权资源引用并记事件，不启动渲染 |
| 无 | 合法请求且缓存未命中 | queued；创建Job与queued事件 |
| queued | 执行器领取 | running；attempt加1、随机租约token、租约及事件同事务 |
| running | 受限执行/校验通过 | 当前租约CAS且未取消时 succeeded；资源引用与终态事件同事务 |
| running | 执行/审核失败 | 当前租约CAS写failed及去敏错误码；不发布候选 |
| queued/running | 用户取消先取得行锁 | cancelled；失效租约、追加事件，后台杀容器并清理尝试输出 |
| running | 租约过期且重启回收 | attempt<2则queued，否则failed(RENDER_INTERRUPTED)；失效旧token并记恢复事件 |
| failed/cancelled | 用户明确重试 | 新Job queued；retry_of指向原Job，原终态不变 |
| succeeded | 取消/重试 | 409 JOB_STATE_CONFLICT；资源继续可用 |

领取使用短事务 SELECT FOR UPDATE SKIP LOCKED；租约30s、心跳每10s、数据库时间为准。心跳及完成都校验Job状态、attempt、token以及lease_expires_at仍大于数据库当前时间；过期即失去续租/提交权限，即使回收器尚未运行也不可续租或发布。旧执行器即使迟到也不能提交。重启轮询器先回收过期租约，不根据一次GET或进程内存判断失败。最多2次自动领取尝试含重启，不无限重跑；明确重试创建新Job，仍受相同限制。

取消与发布在同一Job行锁上排序：先发布则取消409；先取消则任何完成CAS失败。取消返回代表逻辑终态，容器清理允许最多10s；终止失败记运维告警并继续隔离，不能重开资源发布。数据库与磁盘不跨系统伪装原子事务：先停止容器使产物不再可变，执行器通过不跟随符号链接的安全打开读取和校验，再以禁止覆盖的原子发布写入不可变内容地址（已有对象须校验摘要后复用），最后提交数据库引用；失败留下孤儿，由无引用且超过24h的清理过程回收；发布、引用提交与GC使用同缓存键的数据库协调锁，GC锁内重新确认不存在正式引用或有效发布意图，禁止检查后直接删除。数据库已引用文件缺失则媒体返回 MEDIA_UNAVAILABLE，不得声称缓存命中成功。

## 决定 C：幂等、缓存与授权

所有写入从Cookie取owner，并校验同源Origin、CSRF与Idempotency-Key。唯一键为(owner,操作类别,幂等键)，摘要包含目标、版本与全部参数。同键同摘要重放原回执，异摘要409 IDEMPOTENCY_CONFLICT；不同owner不得命中他人的回执。自动恢复不创建新业务Job；明确重试使用新幂等键并保留原Job。

缓存键包含模板ID/版本/源摘要、规范化参数、字幕/语言版本、Review规则版本、Manim/镜像/字体版本及渲染配置摘要，不包含owner/密钥/私有画像。P0只允许白名单教学参数，不把姓名/私有自由文本写入共享缓存。多个Job可同时计算同键；发布按唯一缓存键收敛至一个不可变已审核媒体条目，失败的临时产物不进入缓存。共享字节不等于共享授权：每个owner必须通过合法动画请求取得自己的资源绑定，不允许凭缓存键读取。

媒体/导出通过同源受Cookie保护接口，服务端校验owner资源引用及已审核状态，跨owner和未知对象均404。不暴露缓存绝对路径/容器输出/任意远程URL，不使用公开静态目录；支持经授权的Range请求与固定Content-Type，SRT/MP4下载使用安全文件名，nosniff、私有缓存策略。Markdown只能读取owner已审核资源，不发起渲染；尚未生成媒体返回 MEDIA_NOT_READY。

## 决定 D：Job事件重放

状态修改与持久事件在同一事务提交，事件ID为Job内递增整数，GET Job SSE接受Last-Event-ID，仅发送大于游标的事件，无游标从头读取。心跳不占持久序号；终态事件发送后关闭；终态Job且传入游标已消费其终态序号时立即结束，不等待不存在的新事件。超前游标409 EVENT_CURSOR_INVALID；已清理事件410 EVENT_CURSOR_EXPIRED并要求GET快照再订阅。GET快照与last_event_id在同一一致性读取中返回，客户端应用该快照后以该游标订阅后续事件，不能以无游标重开导致反复410。重复事件由客户端以(Job,id)去重，不能因重连重新生成。

事件默认随Job保留，P0不新增自动删除策略；不审批匿名数据整体留存期限。未来删除按独立留存ADR，游标过期语义提前固定。事件只包含阶段/进度/稳定错误码/资源ID，不含模板源码、路径、Cookie或Provider上下文。跨owner订阅404，连接建立时及每轮数据库读取验证会话有效性，过期结束订阅；不以已打开连接永久延长2h会话。

## 自查场景与后续验证

| 场景 | 必须结果 |
| --- | --- |
| 同键并发创建、同键异参数 | 一个回执；异摘要409 |
| 取消与完成两种锁顺序 | 只出现一个终态，取消胜者零正式资源 |
| API/执行器重启与过期租约 | 状态/事件可恢复，旧token发布失败，最多2次 |
| 磁盘写后DB失败；DB引用媒体丢失 | 孤儿未授权且可清理；缺失不能缓存成功 |
| 两owner同参数、媒体猜ID/Range/下载 | 可复用字节；未绑定owner404 |
| 代码/路径/URL/导入/符号链接/联网尝试 | 输入或静态规则拒绝；容器独立拦截，无宿主回退 |
| 重连、终态、超前/过期游标、Cookie过期 | 按D稳定处理，不追加渲染 |

T004固定字段/错误schema；T008实测隔离、超时与进程树终止；T010–T014验证事务/竞态/owner/重放；T031真实容器重启；T032按T001口径测量。当前只有文档自查，没有运行这些未来实现验收，亦没有支付/调用Provider。
