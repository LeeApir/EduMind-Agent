# ADR0059 固定栈主题课程迁移

状态为限定离线实施。真实批次、费用例外及准确执行包待用户批准。

1. T119 固定一个主题、一个 C 实现、一个场景及两组数据。程序提纲准确引用原目标，规划请求为 0。程序持有代码、容量、边界、帧、状态、情境和答案。模型仅生成中文正文、帧说明、题干、解析和总结。独立教学审核仍绑定准确候选和全部材料。
2. 在开发私有场景读取投影增加 `stack_lifo_model_generation` 来源和 `stack` 的五帧分支。帧沿用元素与高亮 ID，附同版本代码定位、单步出栈值和模型说明。沿用 `show_step`、私有版本及服务端题组，题干由程序附完整情境代码。已有生产投影、权限、正式签核及评分门槛沿用原契约。开发操作显示独立前台模式，无普通调度预算或补全入口。固定目标由本机受限入口建立，复用现有课程仓储和页面。
3. 只拟议一次首稿请求。首稿机械合格后才能做独立全文审核，审核通过才写入可学版本。失败保留。仅教学表达、解释缺漏或事实引用的局部问题可提出一次定点修订，须根据真实父稿冻结确切路径、绑定审核并另获准确授权。本包不含修订请求。协议、事实结论、题义、答案、代码、轨迹或安全阻断不自动修复。
4. 复用 ADR0058 已实测的封闭 DeepSeek Responses 回执和原件保管，使用新的批次、材料、Schema、隔离数据库和 1,800 秒窗口。没有旧余额、重试或回退。单前台尽力停止及本机证据保管仍受 C2 例外限制。本批不计 T038 多主题门禁，不改变 T102 结论。
