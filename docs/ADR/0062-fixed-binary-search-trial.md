# ADR0062 固定二分查找课程试验

当前为零调用准备，真实请求须经准确批准。

1. T122 固定升序数组 `[2,5,8,12,16]` 和目标 5。程序持有 C 代码、六帧、事实、迁移场景及答案。模型只生成讲解、帧说明、题干、解析和总结。教学审核核对两端包含的区间、比较方向、中点取整、命中和区间耗尽，以及重复值不保证返回首个位置。
2. 共用入口增加 `binary-search` 配置。沿用单前台传输、严格响应校验、封存和审核准入。私有场景投影增加固定来源及区间和指针状态，复用现有播放、代码高亮和服务端答题。试验限定专用开发库，夹具只准入隔离测试库并标明来源。
3. 提议使用 DeepSeek 官方 Responses 发送 1 次首稿。规划、修订、重试和回退额度均为 0。新窗口为 1,800 秒。失败或结果未知即按批次规则封存停止。独立全文审核通过后，在窗口内准入新私有课程，再完成浏览器学习验收。需一并确认本批 C2 费用、尽力停止及原件保管例外。
