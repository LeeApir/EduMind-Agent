# ADR0057 · AIAPI r05 封存正文的私有导入

2026-11-09，用户明确批准限定规则及实施。交付任务 PHASE-1.5-T112。

仅允许本机开发专用库通过显式 CLI 导入 AIAPI r05 已评估正文。导入资格来自本条规则及准确的独立教学评估。导入器从加密原件重新提取原始正文，核对请求、响应、正文、候选、真实规划、程序材料和独立评估绑定。只接受候选 `b7759b9d5d7b7f0cf2fb96445e776d1fec3592dd97c1d741f1ee655a5fedcdc9` 及其准确原件和审核。该历史评估的 `admission_eligible=false` 记录原生成链的准入结论。

新私有版本使用 `reviewed_archived_response_import` 来源及独立导入规则版本。存储复用回放的零出站记账，历史用量留在原始收据。页面标明「从已封存响应提取的正文，独立教学评估通过」，请求模型为 `gpt-6.1-sol`，实际模型与存储状态未确认。原响应字段、正文、`AIAPI_ENVELOPE`、失败记录和 `STOP` 保留。普通生成继续执行原严格协议，T107 原回放仍只接收 C01 和 C02。

导入以 owner 和候选摘要绑定幂等，在单一事务中复用私有快照仓储、准入及课程版本。浏览器验收覆盖完整阅读、13 帧和代码高亮、播放控制、四题反馈及刷新。练习答案留在服务端，反馈为课程内暂定比较。课程交付记为封存正文限定导入，T111 固定方案端到端复用和 T038 的门禁分别按原契约判定。
