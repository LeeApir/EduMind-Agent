# ADR0058 固定头插课程的 DeepSeek 官方直连验证

状态：用户已确认选择 DeepSeek。T114 完成后由用户批准准确执行包及实际预算。真实调用授权当前为 0。

## A. 课程与接口

沿用 ADR0055 的固定输入、程序证据、规划与教学请求构造、Schema、独立教学审核及局部修订规则。课程从新访客表单提交后开始。新批为 `head-fixed-deepseek-r01`，固定通过 `https://api.deepseek.com/responses` 请求 `deepseek-flash`。只请求非流式、`store=false`、`temperature=0.2`、`reasoning.effort=none` 和 strict JSON Schema。

`head-deepseek-responses-v1` 按已封存官方响应形态核对终态、模型标签、存储回报、推理及采样、输出上限、实际用量与完整 Schema 回显。附加的 `description` 和 `verbosity` 只能为 null。独立 `instructions` 缺省或 null 时记为回显不可用，有文本时必须与请求的 system 文本一致。识别的附加字段及允许值由代码固定。其他字段、未知输出类型、冲突回显、用量不一致或超限均停止。完整原始字节先保存再解析。模型标签及参数均为 Provider 报告，实际模型快照、内部指令、存储和账单没有独立确认。

## B. 时限、费用与停止

专用开发库中的本批应用操作由数据库记载创建时间，创建时间加 1,800 秒即应用及前台共同截止。批准记录必须准确绑定这两个时刻、context 摘要和 manifest。预检时安排评估者和终端，随后才创建操作。开始发送时至少剩余 90 秒，90 秒为 HTTPX 每阶段 I/O 超时。到期、取消或未知结果拒绝继续和写入新准入。读回原件和查看已有课程可在截止后进行。

规划一次、正文一次、符合审核范围时最多修订一次。每次输入预约 139,264，总计 417,792。输出上限依次为 8,000、8,000、4,000，总计 20,000。单请求 131,072 字节，响应 2 MiB。本批不继承历史额度。依据当前公开非缓存输入及输出峰价估算满预约约 USD 0.14934。以真实账单为准，需批准本批 C2 例外。本机原件无独立抗回滚保障，单前台尽力停止仍存在迟发或继续计费风险，金额无可验证硬上限。[DeepSeek 官方定价](https://api-docs.deepseek.com/quick_start/pricing/)
