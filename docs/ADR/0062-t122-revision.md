# ADR0062 补充提案 · T122 十字段修订

新批次以封存的首稿响应、原请求、原结果记录及程序材料摘要绑定来源。原稿因四个缺失解析被拒绝，原审核状态、STOP 和 HALT 按封存摘要核对。新候选携带原响应摘要，父候选字段为 null。

仅替换四题的题干和 f2、f4 的说明，并补齐四题解析。题干由程序给出固定替换文字并逐字核对，沿用相同场景数据、目标、观察时点、题义、输入形式和答案。模型返回十个字符串，程序逐项合并并按完整首稿契约校验。独立评估者依据程序材料对新候选执行原八项全文审核。

提议继续使用 DeepSeek 官方 Responses，单次修订，规划、整课生成、重试及回退额度均为 0。另登记 30 分钟窗口。原访客名下建立独立操作及封存目录。协议、内容、未知结果或审核阻断均按共用停止规则处理。独立全文审核通过后，在窗口内准入私有课并做实际浏览器验收。准确包和本批 C2 例外待批准。
