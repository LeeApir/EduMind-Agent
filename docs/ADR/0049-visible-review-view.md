# ADR-0049：以可见教学视图作为审核证据边界

2026-10-31；**提案，待独立审查和用户准确决定**。本文件不是采纳登记、真实调用授权或 T102 完成证明。

## 背景

旧审核把候选完整对象及其祖先对象的 canonical 文本作为可引用目标。无损压缩后，模型可能看不到这些祖先对象的原始字节；本地可以解压并不能证明模型实际看到或引用过它们。既有合法引用密集输入也能超过当前开发期 4 MiB 限制。详情见[压缩证据](../acceptance/phase-1.5-teaching-experiment-preparation-t102/COMPACT-PROGRESS.md)。

## 拟议决定

**A．可见材料。** 审核请求直接包含当前槽的学习目标、规格、完整讲解、代码、四题题干／参考答案／解析、完整状态与动作、引用原文及定义、必要上游和参考事实。B 的代码、答案、状态及动作仍来自 B 模型，不能由引擎代填；C 的程序事实和来源保持准确记录。详细字段、缺失规则和两臂来源见[视图契约](../acceptance/phase-1.5-review-view-contract-r01/VIEW-CONTRACT.md)。

**B．证据边界。** 新的逐版本审核视图对可引用的实际可见字符串赋短 ID；JSON 类型的状态或动作以实际传输的 canonical JSON 字符串为证据文本，禁止引用只存在本地或解压产物中的内容。真实原始模型审核响应独立留存，程序只在精确绑定当前候选／视图／目标及验证引用后生成本地裁决。兼容 Schema 的 ID 字符串不代表旧证据契约等价。

**C．旧目标迁移与内部完整性。** [逐类迁移表](../acceptance/phase-1.5-review-view-contract-r01/OLD-TARGET-MAPPING.md)列出旧祖先目标的拆分、教学字段映射、转为程序校验的内部元数据，以及不再允许按旧整对象字面值引用的范围。程序应对每个旧目标作可审计分类，未分类即失败；不得将旧引用视为新视图有效证据。原始请求、响应、解析树、摘要、完整映射及候选／父版本／审核收据链仍保留并重放校验。

**D．范围与公平性。** 这改变审核视图、目标集合及可引用字符串，是实验契约变化，不是等价 wire 转换；引用内容和教学标准不得降级。B/C 同槽、同审核视图结构和标准，C 的确定性资料、B 的原始输出差异如实披露；审核通过不等于教学真值，严重错误、未运行和拒绝维持原口径。新实现、冻结、独立选样和真实调用需依项目流程分别完成；本提案不批准 Provider、预算、生产或恢复旧批次。

准确附件、离线材料与待决定事项见[入口](../acceptance/phase-1.5-review-view-contract-r01/README.md)。
