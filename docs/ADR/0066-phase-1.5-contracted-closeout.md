# ADR0066：Phase 1.5 收敛退出与设计阶段交接

- 状态：Accepted
- 日期：2026-11-16
- 依据：用户提供 [GAPS §六 A–D](../acceptance/phase-1.5-t038-gap-review-t123/GAPS.md#六旧路线收敛退出交接待确认) 后指示“接下来归档后，提一次PR，再讨论重设计的任务”。此指令确认该收敛方案及归档、推送分支和创建 PR，不授权合并或新阶段实施。

## 决定

按工程能力、合格私有课程和完整失败证据完成收敛交接。原 ADR0027 质量与性能指标不变且未被证明通过；本决定替代本次阶段切换所需的退出条件，不追认质量成绩。

保留原157个 Task 对象、所有失败/未知/STOP、T157 两份合格课程及跨批画像对照 1/3 的失败。只新增 T158 收敛治理任务，最终158项为141 done、13 blocked、4 todo；T038/T102/T157仍blocked，T039–T042仍todo。将最终根账本逐字节归档到 docs/tasks/phase-1.5.json，同一提交将根账本切换至 Phase 2，仅 T001 todo，待讨论后领取。

停止旧路线的画像调优、补样本、修订、认证探测、Provider 批次和 T102 执行器修补。公开产品保持 catalog_only；私有课程及答案/评分权限保持。H01–H08封存，旧预算、样本资格和原件不转为新阶段授权。密钥、会话、私有库和加密原件继续本机保管。

可复用传输封存、私有快照权限、程序代码/事实/轨迹和服务端判卷；课程结构、动画与习题设计重新讨论，不强制沿用旧表现形式。ADR0056 是下一阶段设计起点，不预先批准嵌入架构或生成课件实现。

## 本次退出验收

核对原157任务逐值不变、最终旧根与归档摘要一致、新根仅含 Phase 2 T001 todo、历史证据文件未修改、文档引用及现有账本检查。纯治理不重跑数据库、播放器或模型验证。执行结果与归档摘要见 GAPS §六完成记录。

## 后续

本次创建 PR 后停止，不自动合并、部署、调用 Provider 或实施重设计。后续如恢复未满足能力，在新阶段另定任务与验收，引用原失败记录。
