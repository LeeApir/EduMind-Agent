# ADR-0040：最终D02复测中的不透明turn元数据隔离提案

2026-10-28。状态：**Proposed，未批准真实执行**。用户要求继续测试；T064最后一次语义修复已完成8b0cb8a，生成v5及教学标准不再调整。d01已停止，新执行须独立批准。本提案原型仅在隔离脚本中准备，不改变生产网关或旧验证器。

A：仅在本次D02合成诊断的reasoning项中，允许同时出现 `metadata` 与 `internal_chat_message_metadata_passthrough`。两者必须各为且仅为 `{turn_id: <字符串>}`；turn_id必须是小写规范UUID形状（36字符），两者必须相等。缺一、空对象、额外键、非字符串/非法或超长ID、两者不相等均拒绝。它们只是有界不透明标识，**不证明身份/指令/完整上下文**。不解释、展示或转发其值；仅私有校验视图隔离这两个已验形状字段，不改写原始响应，仍保存原始字节SHA与版本化观察收据。

B：除A外沿用ADR0038及原development-scene-review-v2。reasoning明文content必须空，摘要/密文仍按原形状大小隔离，不解密/解释/转发；其他未知reasoning字段、推理用量与项缺失、截断/工具/多消息、模型/effort/来源/精确引用/Schema/用量异常继续拒绝。原instructions缺失只记不可验证；有回显仍须准确原指令或已批准一次37字符后缀。原始请求/响应绑定和最终只读复验继续。生产不得继承此隔离例外；旧d01/r05 unknown不因离线新策略接受而重结算。审核pass仍需助手逐块逐题实际复核，不能证明答案可靠。

C：批准后仅执行一个新独立D02-known合成课程，恰好两场景；生成保持DeepSeek官方deepseek-flash/none、v5；审核AIAPI gpt-6.1-sol/low、原v2标准，由Codex assistant实际复核，independent_human_truth=false。新预算最多5 HTTP＝3生成（规划1＋场景2）＋审核2，无结构/语义修复或传输重试，首次Schema失败即停；新登记起1800秒含助手复核，每请求120秒、课程生成600秒。只外发本批目标、画像自述、计划、正文、私有答案、动作与必要上游，不含真实学生/封存H。token/金额不限需本包明确接受：实际费率/币种/硬限及中转上下文/留存未知，取消后可能继续计费，max_output_tokens≤8000是请求参数而非硬限。协议/安全/预算/未知发送即停；确认任何新的实质性教学/答案错误则直接进入方案重评，不追加Prompt、补样本或自动新批。旧相关29请求保留，新最多累计34；不完成T038全套、不开放生产。

离线回放只说明新规则对已见字段的工程兼容，不能追认旧pass、证明供应商通用兼容或新课程质量。准确范围/文件SHA以 `docs/acceptance/phase-1.5-d02-recheck-d02/manifest.json` 为准；A—C与准确包同时独立获准后才读取Key或执行。新批准登记不在manifest内以避免循环绑定，必须匹配准确包SHA、具体外发范围、新窗口及费用例外。
