# ADR0063 四主题共用流程的有限真实复用试验

状态为零调用准备。真实执行须另行批准准确提交、manifest、新预算、期限和本批 C2 例外。

1. 固定四个已知开发输入，按头插、栈、队列、二分查找顺序执行。头插使用模型规划和独立规划审核，其余沿用各自程序固定提纲。四课都使用 `course-question-stem-v2` 和现有主题 Schema、事实、轨迹、答案及全文审核项。前一课通过独立审核并写入私有版本才开始后一课。
2. `--live-reuse` 使用专用开发库和一个批次授权。每个已预分配阶段只能尝试一次，规划 1、首稿 4、条件修订最多 4，共至多 9 个 HTTP 请求。整批 90 分钟，各课程操作沿用 30 分钟期限，取两者较早。发出请求和写入准入都受限。原件和已保存课程可以在到期后读取。T125 首稿入口及 T126 的 `OFFLINE_ONLY` 夹具隔离保持。
3. 真实修订复用 T126 的字段与合并规则。首稿须从本批封存请求和响应严格重放，且通过全部机械检查。独立全文审核只能定位已存在的段落文字、事实引用、总结或头插展示范围中的次要措辞和引用问题。条件批准记录绑定整批窗口、准确父稿、审核、字段和唯一请求。修订后的完整新候选须再次通过独立全文审核。课程读取契约仅增加本批四个主题来源，真实来源与离线夹具各自保持绑定。首稿 Schema 失败、缺字段、重复键、严重或超范围教学问题、修订后仍不合格均保留并停止整批。
4. 仅本批拟沿用单前台 C2 例外。原始响应先加密保存再解析。超时、传输未知或停止后仍可能迟发或继续计费。本机原件没有独立抗回滚保障。服务端实际费用、可验证金额硬上限、实际模型快照和留存状态未确认。请求限额与回报校验只约束本机执行及准入。
5. 本批用于四个已知输入上的有限真实复用验证。原 T038 验收分母、T102 状态、历史冻结包和生产 `catalog_only` 适用范围保持。
