# ADR-0032：DeepSeek 官方候选的独立合成观察

日期：2026-10-27。状态：新合成观察的具体方案；生产契约变更尚未批准或实施。

用户已选择生成使用 DeepSeek 官方 API／`deepseek-flash`，并明确“直接执行，不用批准”。本次尊重该最新指令，仅准备并执行以下两次合成观察，不再要求重复批准。登记基于该明确指令，不伪造用户独立审阅未来 manifest 或逐条签核 A—C。若缺少官方凭据则停在出站前；不把已有 AIAPI Key 当成官方 Key。

## A：按官方能力观察，原准入门禁不改

准确端点 `POST https://api.deepseek.com/responses`，模型 `deepseek-flash`，reasoning none。仅新合成固定对象 S1（非流式）／S2（流式），原项目教学 Prompt、完整课程 Schema、H 封存和旧标签不发送。按文档使用 `text.format=json_schema`；不添加未明确支持的 strict 字段，不退为 json_object。探针保留完整本地 Schema 和固定对象相等校验。

这不撤销 r03／其他准确包 strict 或计数相等要求，不替换生产适配器。本次仅观察供应商实际行为，结果不叫完整兼容通过。官方文档未承诺所有回显字段，也未列明独立输入计数接口；因此回显缺失、独立计数及实际快照／收费分别记 unknown。可见回显若与请求矛盾则停止；没有回显不能证明没有注入或实际执行了输出上限。实际报告越界仍停止，不能用“可空回显”解释。

S1 必须 HTTP200／completed、model 准确相同、store=false、无工具或推理输出、本地 Schema 和固定值相等、usage 类型／算术／上限正确，才允许 S2。缺失文档未承诺的可选回显记 unknown，不阻止这一次 S2 合成观察；这项仅限实验的放行不是课程准入。S2 还要求唯一完成终态、事件序号递增、正文增量与终态一致。任何必需条件失败、凭据回显、存证失败、超时或未知发送即停止，无修复重试。

## B：准确预算与不确定性

批次 `p15-deepseek-flash-r01`：最多 2HTTP／2生成；本地输入每槽4096、合计8192，输出请求128＋512＝640（含推理），每次40秒／全批90秒（89秒运行＋结算余量），响应每次1MiB。无模型列表、计数、审核请求、工具、重定向、回退或重试。公共目标校验后固定IP、Host和TLS SNI，不继承代理环境。DNS由5秒限时无凭据子进程解析。

当前官方峰时USD价格为输入缓存未命中0.30/M、输出1.20/M，全部按无缓存估算，最大本地规划USD0.0032256；每槽预约USD0.005，合计USD0.01。费率快照有效24小时且启动须剩余至少90秒，过期不得自动刷新、改请求或复用批准。

上述输入占额并非独立计数或输入硬界，输出值是服务请求参数，本地留额也不是供应商发票硬限；服务器可能继续执行或收费，客户端取消不保证取消上游。本次按最新明确执行指令及已展示的不确定性作有限合成观察；不声称用户独立逐哈希审阅、不继承旧“无上限”例外。任何真实费用都以独立账单为准，未知保持未知。

两槽在DNS前完整预约。成功的协议观察不伪造可信账单结算，第一槽观察通过后在全额仍保留的条件下允许第二槽；无论结果最终都保留两槽全部本地unknown留额，包括未发槽，不把它当已收费。请求标记与服务端已执行的事实分别记录。历史累计／unknown账本原样保持，本批次单独记账。

## C：一次性、凭据隔离和后续门禁

专用Key只取本地环境或`.env`的 `EDUMIND_DEEPSEEK_COMPAT_API_KEY`，不回退通用Key。读取Key／DNS／建执行目录前先检查冻结材料、费率和准确指令登记。目录独占创建，首次尝试后任何结果均不得重启。证据权限0700目录／0600文件，Key若出现在响应中拒绝保存原文；摘要不打印任意错误或隐藏指令文本。

真实观察即便两例成功也保留计数／回显／快照／费用unknown，T038仍blocked。结果只用于决定下一步是否值得提出课程兼容契约及诊断包，不能自动领取T039–T042，不能自动把sol接入生产审核，也不能部署、push、merge或开放动态。cbbb继续停用，旧批次不恢复。

准确材料、执行入口、预算和原始收据说明见 [r01](../acceptance/phase-1.5-deepseek-flash-r01/README.md)。本方案不把“直接执行”扩展为生产契约批准或后续调用额度。
