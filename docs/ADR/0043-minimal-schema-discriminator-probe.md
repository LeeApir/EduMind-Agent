# ADR-0043：独立最小 enum Schema 单变量观察

2026-10-28；Proposed。仅PHASE-1.5-T074 / schema probe-p01，待准确A—C及manifest批准；T073只完成准备。依据T072离线审计，不把原400猜成某字段的已证实根因。

## A：新合成对照与可得结论

固定DeepSeek官方`https://api.deepseek.com/responses`、deepseek-flash、reasoning none、temperature0.2、非流式、strict true、store false。纯合成消息只要求`{"kind":"show_state"}`。S1的kind为string及原动作三个enum；S2完全复制，仅删除kind.type。消息、模型、Schema名字、其余请求字段及同次核定公网IP均相同。专用Key仅来自EDUMIND_DEEPSEEK_COMPAT_API_KEY，无其他服务或Key回退。

只有S1完整200/原严格响应协议/准确合成JSON和用量检查通过，才发送S2。复用原pilot generation响应校验，不允许额外编码指令后缀、reasoning内容、工具或其他输出；缺instructions回显保持不可验证，不宣称模型身份/指令/上下文或账单已认证。

S2为末次观察：匹配原错误类型/代码及缺type/anyOf/$ref消息的400，仅支持这个最小enum-only形式在本端点被拒绝；S2也成功则该窄拒绝没有复现；其他错误或任何S1失败均不确定并停止。小样本和别名/上游未认证限制保持；两请求不证明原完整Schema的首因/唯一根因，更不证明完整C链或教学质量。

## B：独立最小窗口、预算与证据

最多2模型HTTP；单次HTTP最多25秒，DNS核定最多9秒（一次、拒绝任意非公网A/AAAA），总新批准窗口90秒，包括本地处理/等待。每次请求max_output_tokens=32、请求体≤1024字节、响应体≤65536字节；本地输入占额各4096共8192、输出各32共64。非负整数可信用量返回后核对单次输入≤4096、总输出≤32，越界停止；没有输入计数API或额外探测。

输入占额是本地预约与报告门禁，无法让服务端按此硬截输入；输出32是请求约束与响应用量检查，无法独立保证服务硬界或取消后不计费。pricing.json保存2026-10-28公开标价，以峰时未缓存输入和输出乘占额参考为$0.0025344；实际账户费率/币种及账单未验证，不能写成实际金额硬上限。提议本次明确接受**实际货币总额不设硬上限**及未验证上游输入/输出限制风险，旧费用例外不继承。

先持久预约与原字节摘要，再唯一发送；无传输重试、重定向、回退、补样、未知重发或续批。固定新目录一次性创建，任何已有目录拒绝，崩溃/中断后不能恢复发送。保存0600原始请求、响应、状态和摘要链事件，目录0700，不记录Authorization。响应含Key则拒绝落盘并终止；用量/计费未知不退款或复用占额。

## C：离线准备与后续课程门禁

准确批准、scope/package/预算及新窗口在读取Key/.env、DNS或建立输出之前校验。两次完成或任何异常均终止，事件重演核验S1检查点、唯一出站、同IP、窗口及不可逆终态；只读检查器从原件重算，不凭可改summary采纳成功。摘要和本机时钟是程序证据，不是外部可信认证。

不发送旧p01请求、e03参数/真值、学生或课程材料，不改旧冻结、Schema、教学Prompt或验收标准，不调用sol。即使窄观察完成，相关C规划/内容及审核的准确wire Schema仍须先准入，才准备单个新合成支持槽的一份完整可评课程包；独立复核完整代码/题目/答案/动作后才讨论课程可行性。此提案不授权那次课程调用、完整诊断、T038解除、生产或部署，也不授p01重启。
