# ADR-0050：有限 C 完整中文课程可行性批次

2026-11-03；**Proposed，待用户准确批准 A–D 与附件 manifest**。本提案由 T104 的执行准备授权产生；准备任务可完成，但不表示本 ADR 已采纳或真实调用获准。T102 保持 blocked，所有旧批准/原件/失败保持。

## A．目标和有限样例

采用 [执行包](../acceptance/phase-1.5-limited-c-preparation-t104/README.md)：C01 为 T103 同参数成功样例，C02 为空初始链、分配掩码 false/true 的正常头插。它们是事前公开的**两个开发样例**，不是独立留出样本，更不替代 ADR0041 的双臂 10 支持＋4 拒绝。只检验这两个完整中文课程的生成与可学性，不报告稳定率或 B/C 提升率。下一核心交付是本批未经助手补写的真实完整课程与独立教学评估，连同全部失败及必要修复版本。

## B．完整教学字段与角色简化

采用同包 output-schema、准确请求及装配代码，复用 T100 指令组织、受限头插引擎和 T103 交互。模型生成正文、题干、解析、每步标题/说明、前提、总结、生命周期及未演示路径范围；程序生成示例代码、状态、帧绑定、高亮、四题答案和交互，不把助手现成段落送模型回显或补空。

本批不调用 C_plan、B、模型审核或七槽 echo 准入。规格/教学目标由本包预先固定，生成与一次条件修复使用 DeepSeek 同一路由；独立评估助手逐份审核，模型意见不替代教学真值。此为相对 ADR0041、0047 D、0049 的明确范围变化，非等价兼容或原门禁已通过。详细 [逐条差异](../acceptance/phase-1.5-limited-c-preparation-t104/CONTRACT-DIFF.md) 和 [T103 所有权审计](../acceptance/phase-1.5-limited-c-preparation-t104/T103-OWNERSHIP.md)。原正式实验及正式产品标准不改。

## C．前台单请求入口、停止与原件

采用包内 `execute_once.py`，人工逐次启动当前请求，无后台调度、通用监督器或子发送进程；不复用 T102 控制器。只向固定 DeepSeek HTTPS 端点发送，当前 Key 通过终端 getpass 输入，不放环境或参数；本批不持有另一家审核 Key。原始响应逐块加密、同步写入私有目录，完整收到后先回读核对再解析，非法 JSON 仍保留原件；缺件/断流/超限为 partial/unknown，停止且不重试。

**这并未修复 T102。** 前台进程仍存在检查后暂停再发的竞态；已启动或已排程的 CLI 可在停止请求之后继续发送。STOP 文件只是本地检查点，不保证停止返回后不新建进程或不首次发包。人工 Ctrl-C/终止是尽力操作，不提供独立监督、有界退出确认、进程树证明、独立锚或抗共同回滚保证。只在实际进程退出后才能报告本机该 PID 已退出，不能据此断言 Provider 未收到/不计费。接受此更弱的**单次人工探索语义**必须由用户准确批准；否则此入口不可真实执行，不能继续补监督器解决。

T105限定适配：本批消息phase仅接受缺省或准确`final_answer`，已核对白名单字段只在内存校验视图中移除，原始响应不改；其他phase/未知字段拒绝。适配即时输出与父稿重放，教学Schema/初始请求不变；[准确说明](../acceptance/phase-1.5-limited-c-preparation-t104/PHASE-COMPATIBILITY-T105.md)。历史共享校验器和冻结包不改。

## D．资源与授权边界

最多 4 HTTP、每例最多 2 次、单在途、每次 max_output_tokens=8000、温度 0.2、reasoning none、请求 128KiB、原件 2MiB；每次本地输入预约 139264（全批557056）、输出预约8000（全批32000）。1800 秒批次窗口与 90 秒单次 I/O timeout 是本地检查/超时参数，不是物理发送/总时长硬界。拟采用本批 C2 风险例外：实际金额没有可验证硬上限，按用量和账单另记；公开费率算术不是承诺。

当前真实额度为 0。用户须分别准确批准 A–D、包 manifest、当批 C2 费用例外、启动时刻/30分钟窗口和最多4请求才可执行；不得继承旧授权。下一真实执行任务只交真实课程/失败/修复及独立教学评估，不再默认插入通用执行器工程。若本提案不获批准，则停止并交具体取舍，不自动恢复 T102 或换框架。
