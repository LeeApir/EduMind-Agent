# ADR-0042：头插协作对照的独立受控执行

2026-10-28；Proposed。仅 PHASE-1.5-T069 的 execution-p01，等待准确A—C及执行包批准。ADR0041已批准职责；本提案不改变教学标准或生产权限。

## A：新准确包的传输边界

生成固定DeepSeek官方 api.deepseek.com/responses / deepseek-flash / none；审核固定AIAPI aiapi.world/v1/responses / gpt-6.1-sol / low，两臂同模型/参数。使用新pilot角色Schema及完整本地校验，不投影或放宽Schema；请求strict:true，真实端点是否接受这些具体Schema尚未验证，任何接口异常全批停止。

旧ADR0040只覆盖旧D02；现明确提议将同等有界规则用于这个新包：审核缺instructions回显记录不可验证；若有回显只接受准确system或其后追加固定37字符“\n\nYou are a helpful coding assistant.”。reasoning仅隔离最多一段4096字符summary和同时存在、仅含相同规范UUID的metadata/internal_chat_message_metadata_passthrough；不信任身份、不转发、不改原始响应。其他内容/密文/工具调用/未知结构拒绝。回显与隔离不是上游完整上下文或教学质量的证明。

只允许两个冻结HTTPS目标，全A/AAAA需为公网并连接已核定IP、保留Host/SNI；无重定向、传输重试、回退、未知重发、计数或/models探测。未知请求永久占用次数，原始请求体/响应体和状态均保存；请求记录字节与实际HTTP body一致，不记录Authorization。

## B：对照、预算与外发

10支持+4拒绝槽，B/C交错，共28臂槽；支持B最多4HTTP、C最多5HTTP，总计90（生成最多50、审核最多40），拒绝本地0HTTP。每个支持槽至多一次普通教学修复，首次和修复后分别保存。每次请求max_output_tokens=8000、请求体≤131072字节、响应体≤2097152字节；这是请求约束和客户端内存门禁，不宣称中转完整上游token/计费硬限。

新登记窗口3小时包含所有等待，单请求最多120秒；先预约再唯一dispatch，未知/协议/事实安全问题/超时或预算耗尽即停。提出本包token及金额总预算均不设上限，实际账户费率/币种/推理计费及取消后继续计费未知，须此次明确接受，不继承旧费用例外。公开标价仅用于参考，见执行包rates.json，不伪称实际账单。

仅外发本批合成目标、规格、固定语义、引擎代码/轨迹/观察、模型课程正文/题目/私有参考答案/动作以及必要上游审核或修复意见；独立真值、真实学生、旧签核课程和H封存材料不发送。B生成/修复不读取引擎输出或独立真值；B、C审核都可读取引擎参考，差异公开。基线与协作各用适合职责的Schema，复杂度差异不能隐藏或简单归因于角色数量。

## C：独立助手与证据门禁

按用户明确决定由独立子助手核定和评估，身份assistant，非human。e01问题及e02参考原样保留；e02早于全链冻结，不用于正式评估分母。代码/Prompt/执行器/政策全冻结后才选新的e03参数并手算真值。公开核定摘要绑定核定者、时间、完整候选摘要、输入/私有真值摘要；开发侧只读取调度输入，不读取或发送独立答案。

每个模型通过槽都暂停，独立助手核对全部版本的事实、答案、代码、动作与教学，再登记准确result摘要的报告才推进。首版事实/答案/代码检查失败不能因后续版本掩盖；失败检查必须有定位证据。独立助手报告/身份基于用户委托和记录，不是独立OS凭据或密码学认证。只读检查器重算来源、审计链、原始wire/用量、因果、修复、所有版本与报告；证据核验通过不等于模型质量合格。

T069仅在按准确授权采集和核对证据后完成；T070再交独立助手作全部内容与冻结指标复算，必要时结论为停止或证据不足。保持T038 blocked、catalog_only、原教学阈值和H封存；不重启旧批次、开放生产或推进T039。
