# ADR0052 补充：T108 r03 相同重复字段的本地派生恢复

2026-11-04，状态：用户本轮明确授权实施。仅适用于 r03 已保存的正文响应，不批准新 HTTP，不重启停止批次。原 ADR、批准 manifest、原稿、失败及 STOP/ACTIVE 保持原字节。

## 唯一格式差异

原流程的严格解析器仍拒绝所有重复键。本轮另设 `head-questions-identical-duplicate-v1`：完整 JSON 的 `/questions` 下既定四个题目键，各可出现最多两次；仅当两个值的字段集合、逐项类型及全部内容完全相同，删除第二个成员。对象与数组、布尔与整数等类型严格区分。题干和解析的字符不改变。其他位置重复、第三个成员、冲突、缺字段、截断、语法错误及非有限数值均拒绝；随后仍执行原完整教学 Schema、事实 ID、代码场景、帧绑定和响应信封检查。不是通用容错解析，也不自动修规划、补目标或改引用。

## 派生身份及主链接入

- 原 r03：首次正文结构不合格，2 HTTP、0 合格正文、STOP、余1失效的历史结论保留。
- 新派生：`evidence_kind=program_format_recovery`，batch=`head-goal-r03-derived`。教学原文来自 r03 模型响应；程序只删相同成员，再装配同版代码/事实/轨迹/答案。独立候选摘要域 `head-format-recovered-candidate`，并记录原始 HTTP/文本/请求/派生输出 SHA、规则版本和重复成员位置。无助手补写，不能计模型首次结构合格。
- 在本机实际预览学习身份下建立新的本地派生私有课程（原身份亦可；浏览器会话重建时使用新 guest，不复制会话凭据），复制准确真实模型规划（不是新规划），保留原目标/先备、自述证据及原 course/operation/request 绑定。原 r03 课程、失败操作不恢复、不改写。新课程 operation 仅用于本地快照写入，不派发出站。入库复用现有 store_plan / 准入 / commit_scene / 私有答案处理 / Vue 播放器；不新增调度器或播放器。
- 保留 `origin=head_goal_model_generation` 表示教学文字来源；以强制派生 evidence_kind、来源明示及独立 admission 分支区分。数据库行 sent_attempts=1 与 usage 是**原 r03 正文一次请求的历史归因**，不是本轮调用，不能与原件索引相加计算 HTTP。新调用数恒为0。未新增数据库字段或迁移。
- 产品 `HeadGenerationSource` 仅增加上述派生标记及限定格式恢复来源对象，并对 batch/evidence_kind 配对校验；原教学输出 Schema、练习答案私有边界及版本协议不变。

## 审核及停止

派生候选通过完整机械校验后，独立评估助手逐段/逐题/逐帧核对作用域、返回值、可达性、答案、泄题、范围与教学表达；按用户本轮“结构检查通过后交付完整课程预览”的要求，机械准入后可进入独立的私有审查预览：非 pass 必须带来源 `teaching_review` 和醒目问题警示，不冒充教学通过。ready 仅表示版本完整可读，不是语义签核。若有问题，只报告准确路径、引文和影响，不自动改写或调用模型。最终还需实际应用阅读、演示、反馈、刷新证据；教学非 pass 时保持 T108 blocked，恢复和可读预览不自动完成 T108。T102 blocked、catalog_only、原实验分母和 T038 门禁不变。本轮完成后交评估并停止。

## 本轮评估元数据勘误

独立报告将初次机读审查副本中的 `head-demo` 定位修正为实际 `head-state`，未改教学原文、候选、verdict或basis。已写入数据库的早期副本保留原字节于 `review-metadata-r01.record.json`；准入只额外承认该完整历史 record 的固定 SHA，不忽略字段或宽松比较。当前导出使用准确最终审查定位，两个副本的候选摘要相同。
