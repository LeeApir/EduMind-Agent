# ADR0052：限定头插的新目标主链生成

日期：2026-11-03。状态：Proposed，待本提交及准确 manifest 批准。T108 未完成，真实调用 0。

用户已授权本任务零调用接线与执行准备；本 ADR 集中列出真实执行前需要决定的 A—D。T107 已通过[独立评估](../acceptance/phase-1.5-head-replay-t107/INDEPENDENT-EVALUATION.md)，但其 ADR0051 批准仅涵盖固定回放。本提案不追改旧包、预算、失败或 T102 blocked。

## A．限定的新目标与规划

唯一目标为：“我已了解 C 指针、struct、NULL 和函数返回值，希望通过头插示例，理解新节点如何连接旧链表，以及为什么调用者需要接收函数返回值。”

实际应用目标输入 → 原 POST /api/free-courses → 现有快照仓储保存原文；不创建或修改画像来伪造掌握。请求原文中的自述先备知识以准确引文保留，其他学情未知。专用开发实例的服务端开关选择本接点，其他目标明确拒绝。

复用原规划的 build_request、输出 Schema、validate_response、persist_outcome、store_plan。限定能力块 `head_support` 仅出现在本版请求中，规划 Prompt `head-goal-plan-v1`；规划器必须从 head-new-A/B 选择一个准确 ID，并返回一个完整可变内容场景，覆盖连接旧头和调用者接收返回值两个真实目标。此处“一场景”是支持范围而非学生学习目标。旧默认规划仍 1–8 场景，旧请求字节/Prompt不变。本任务不接受程序手写大纲代替真实规划，不修改或自动补引用。规划澄清、越域、语义未通过均停止，不修规划。

## B．新来源及程序/模型边界

新增 `head_goal_model_generation`，与原 model_generation 和 existing_real_candidate_replay 分开；0050 迁移仅扩展允许的来源＋sent_attempts=1，不改旧行，不允许有本来源审计时降级。新增 public generation_source，不复用固定 replay_source 身份或 C01/C02 槽。`head_insertion_replay_v1` 保留其已批准帧表示名称，在新来源明确允许时复用同一组件；该类型名不是回放来源声明。

程序持有新示例规格、C模板、事实、完整轨迹、成功判空展示帧、作用域和高亮；模型生成全部教学段落、前提、逐帧讲解、总结、生命周期/失败范围、四题题干/解析。参考答案由同版共享引擎派生，并以独立闭式期望核对。两主示例均为新参数，不是 C01/C02 改名；练习使用独立新情境及 discard_return 对照，未另建算法引擎。题干必须含准确情境代码，不能含结果/答案示例或暗示，教学正文不得代答迁移题。

新增模型教学 Schema head-goal-course-v1，区别原有限C四种观察题和通用场景Schema。普通生成Schema不改。保留模型原文；课程组件以 Vue 文本插值转义展示全部字符串，无 raw HTML/Markdown 执行。程序装配字段是明确投影，不将模型ID引用当作语义正确证明。

使用现有私有候选审计、原件、校验、presentation、ready、manifest CAS与服务端暂定反馈；原稿和唯一修复稿都保留，最终稿成为v2。参考答案/解析沿原服务端私有存储和完整作答后反馈方式；不授予正式掌握度。刷新保持准确课/场景/题组/反馈，播放帧回首帧。数组严格JSON整数，旧short_text规范化保持；移除全局数组提示中的具体数值示例以防与答案碰撞，比较规则不改。

## C．本批独立执行及审核

拟议新批：一课，最多3 HTTP：真实规划1＋教学首稿1＋有条件普通措辞修复1。单前台、逐步人工启动；没有echo/探测/模型审核/重试/回退/并行请求。规划及首稿的实际未来输出尚不存在，准确请求按冻结构造函数，以真实私有身份/规划/父稿生成并在发送前保存，不伪造预先固定的真实请求。

沿用已验证过的 DeepSeek Responses 路由配置，但旧授权和费用例外不继承；实际别名权重不可锁定。准确配置、上限、外发材料见[执行包](../acceptance/phase-1.5-head-goal-t108/README.md)。整个新窗口600秒，起止时刻在实际开始前登记；原操作亦只有创建起600秒，取两者较早截止，不延长、不续窗、不恢复。

机械审核负责身份、目标引文、规划覆盖引用、支持域、Schema、事实ID/帧/代码/情境与答案绑定、原件完整性；不判断中文是否正确。独立评估助手审核真实规划的语义兑现，再审完整教学内容/不泄题/逐步事实/答案/生命周期/安全。规划评估通过才生成，首稿通过才装配；仅 minor difficulty/misconception 的普通措辞可修一次，不能修事实、答案、安全、结构、协议或unknown。修复必须带准确父稿和定位引文，完整返回同Schema；不允许助手补写教学正文计成功。此为本批开发草稿核对，不是通用产品“所有语义意见必须通过才能可见”的新门槛。

不走通用调度器的13/40预约或七角色准入，操作预算投影在本来源返回 execution_mode=finite_head_foreground/budget=null，避免将旧调度额度当作本批许可。真实尝试/用量以本批私有attempt/receipt为准。开发页面关闭大纲调整/恢复/导师/局部修订；对应服务端入口也拒绝。真实出站只有明确终端CLI；无后台生成。生产开关、catalog_only及普通API/调度不开放。上述差异不是对既有B/C双臂、角色准入或T038契约的等价验证，不回填其分母。

## D．停止/凭据/证据与本批C2例外

实际入口仍有T102已知“检查后暂停，停止后仍迟发”的反例风险，**未解除旧阻塞**。前台Ctrl-C、STOP和600秒检查是尽力停止，不能保证物理不迟发、Provider中断或停止计费；页面停止只围栏课程写入，不能终止终端HTTP。停止/过期/任何异常/原件缺失/协议事实安全问题/unknown均全批停止，保留未决，不补发或换样。未用额度失效。

Key仅终端getpass隐藏输入，不读项目.env、不从环境传入、不保存。复用旧原件加密收集/严格消息适配（缺省或final_answer，其他阶段/未知字段继续拒绝）；解析前逐块加密/fsync，非法JSON/超限/中断保留原件或前缀并如实标不完整。新目录/新raw.key、本机0700/0600；不触及T106原件或STOP。保存真实请求/原body/首稿/失败/允许修复/评估/发布绑定；不提交凭据、私有原件或截图媒体。

此原件保管没有独立保管者/抗回滚锚，不能保证本机所有者或全部副本共同回滚后仍可证明完整。DNS同步解析和HTTP单项I/O timeout90秒不是硬总时间保证。实际费率/上游隐藏用量/金额硬上限无法验证，本批必须重新接受C2费用风险例外；任何算术估算都不构成硬上限。本提案不自授费用例外。

准确批准仅覆盖manifest绑定文件和本批范围。新增实际课程及浏览器完整验收后交独立教学评估，任务完成后停止；不扩主题，不启动T038，不恢复T102或任何旧批次。
