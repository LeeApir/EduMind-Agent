# ADR-0026：草稿质量处置与有效学习证据

- 前提：[ADR-0024批准](0024-approval-20261021.json)、[ADR-0025批准](0025-approval-20261021.json)及ADR-0023已确认方向。
- 当前只设计，真实Provider请求0，catalog_only不变。

## 具体决定提案

| 决定 | 拟冻结规则 | 影响 |
| --- | --- | --- |
| A 问题确认与处置 | 学生反馈/模型意见只建待核事实；机械硬失败直接阻断，语义缺陷由可信本地维护者绑定准确版本、依据与范围确认；局部禁用并传播依赖 | 不做全量语义审核前置，不让模型标签或普通用户行使撤回权限 |
| B 练习与可靠性 | 首版沿用2–4道短文本题组；默认暂定比较；可靠答案和单节点映射只接受准确题组的维护者核定 | 模型pass、答案字符串相同、课程节点匹配均不能自动使成绩可靠；新草稿可学不等于可正式评分 |
| C 正式证据准入 | 核定发生在首次完整作答前；未求助、未看答案、未发生重复、准确版本可用时才准入；每owner/同题组最多一次 | 无追认暂定作答、无重复刷分；多节点/未可靠映射保留课程表现，不猜一个节点 |
| D 修订与撤销 | 新题不评价旧作答；旧贡献失效事实只追加，原子重放有效证据/更新掌握度版本/使路径失效 | 不做数值相减补偿，不删除历史；旧目录/legacy/planned原有资格与数学规则保持 |
| E 导师范围与成本 | 绑定准确课程/场景的一个导师，不含私有答案/跨owner材料；提问不改正文，补充解释修改走T002修订；每轮最多1次/90s | 复用T002持久操作、围栏、共享课程额度和容量隔离，新增tutor_turn类型及tutor_ready事件；无后台审核链或新增角色 |

规范附件：[质量与证据契约](../acceptance/phase-1.5-quality-contract-r01/contract.md)、[政策表](../acceptance/phase-1.5-quality-contract-r01/policy.json)、[API补充](../api/phase-1.5-quality.openapi.json)、[正负例](../acceptance/phase-1.5-quality-contract-r01/examples.json)；准确字节由[manifest](../acceptance/phase-1.5-quality-contract-r01/manifest.json)绑定，当前无批准登记。

## 兼容与重大取舍

本提案补足T001/T002预留的缺陷确认、题目资格与导师入口。T002的操作/事件enum按本提案新增tutor_turn/tutor_ready及独立一轮额度，不改已批准生成操作的13次/600s与课程累计40次上限；API/schema扩展在本附件声明，冻结文件原字节不改。根账本T020实施新API，T021验证兼容；早期附件x-implementation-task指向T021的元数据以根任务分工为准，不扩大T021范围。

首版不建立自动语义真值判定器；人工核定是可选的准确题组能力，不是所有草稿学习必经门。维护者只使用可信本地维护命令，沿用本地受信操作边界，不新增学生API管理员角色、教师编辑后台或跨用户权限。具体证据必须可复核，不因自称专家或模型同意代签。

T005仍独立冻结新链质量/性能验收。当前未证明自动质量或学习效果，旧失败、封存H和停止台账保持；本契约数值上限不是真实调用/费用批准。
