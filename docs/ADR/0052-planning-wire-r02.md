# ADR0052 补充：T108 限定规划线格式 r02

2026-11-04。状态：本轮零调用修复已获范围授权；准确执行包、真实新批次与本批 C2 尚待评估后单独批准。原 ADR0052、批准登记、head-goal-r01 STOP 与全部原件保持原字节。本补充不重开旧批次。

## 必要差异

1. **远端和本地分开。** 仅 T108 的前台规划入口发送 `head-goal-planning-wire-v2`，显式内联对象、数组、string/boolean 字段，每层对象关闭额外字段。没有 anyOf/oneOf/allOf、$ref/$defs 或 if/then/else，不发送内部条件分支和内部描述。参考 T106 成功请求的显式类型嵌套结构，但不宣称新协议已经被 Provider 接受。普通规划接口、原业务 Schema 和教学 Schema 均不改。
2. **固定转换，不修内容。** 线格式 `plans` 为数组：正常恰一项，澄清必须空数组；映射到原 `plan` 对象/null。正常 reason 空串映射 null；建议目标的 source_key/source_excerpt 必须同时为空串，映射 null；用户目标引用仍为非空原文。其余字段原样。非空无效数据、未知版本/字段、错误引用、孤立目标、越域示例、错误场景引用和不合法澄清均拒绝，不删除、不补写。转换后完整运行原 `validate_response` 和有限示例检查。语义覆盖仍由独立评估者核对，集合相等不等于目标已经兑现。
3. **来源和持久化。** 完整 HTTP body 仍先加密保存；`plan.output.json` 保留模型线格式原输出，`plan.mapping.json` 保存 wire/local 版本、双方内容摘要及转换结果。重新读取时解密原件、重新适配、重新转换并比较。规划入库继续保存本地 v1 格式，schema_version 不变，prompt_version 为线格式 v2，请求摘要绑定真实新 Prompt/Schema；无数据库迁移、新来源、课程字段或答案契约变更。
4. **新批准边界。** 新包位于 `phase-1.5-head-goal-t108-r02`；旧批准字段不被本入口接受，新批准必须含准确 manifest、`planning_wire_version=head-goal-planning-wire-v2`、`accept_ADR0052_R02_and_batch_C2=true` 及独立新窗口。其余 ADR0052 A—D 的目标、示例、模型/程序职责、课程私有版本与反馈、审核和停止局限继续适用。待评估后另批的上限仍是 3 HTTP/600秒，不继承旧余量或费用例外。简化后的规划协议若被拒绝，准确保留错误并立即停，交用户决定是否更换 Provider 路线；不得自行进入字段补丁、重试、探测或切换路线。

正文与修复都继续使用 `head-goal-course-v1`，Responses `text.format` JSON Schema、同一教学 Schema、同一响应适配及原件收集；本次只确认其所有 Schema 节点有明确基础类型且无上述联合/引用/条件结构。此静态核对与离线入口检查不等于真实生成通过。

## 执行与验收不变

新授权后从实际应用重新输入原目标，建立新私有课程和新操作；旧失败课程不改写、不恢复。真实规划通过本地检查及独立语义核验后才生成正文，首稿或唯一允许的普通措辞修复稿通过后入现有应用，完成阅读、逐帧演示/代码高亮、作答/反馈及刷新恢复，再交独立教学评估。未经助手补写的新完整课程才是验收对象，不以 Mock 或请求接受替代。

仍使用原单前台入口，不新增监督器/Schema 编译器，不迁移运行框架，不修改 T102 或解除其迟发反例。尽力停止、停止后可能迟发/继续计费、原件只有本机保管且无独立抗回滚保障、实际金额没有可验证硬上限均保持披露，须本批重新接受 C2。

准确材料、预算、命令和审查入口见 [r02 执行准备](../acceptance/phase-1.5-head-goal-t108-r02/README.md)。本轮交评估后再申请新的真实执行授权。
