# ADR-0041：头插法共享示例与隔离协作试验

2026-10-28；状态：Proposed，待准确 A—D 及 manifest 附件批准。任务 PHASE-1.5-T066；不是运行授权。

正式 D02 d03 在第二场景缺 actions 后停止。继续依靠模型同时生成事实、答案和动作无法提供稳定依据。本提案把受限算法状态交给可独立测试的程序，模型负责解释和教学审核；试验判断这种职责划分是否值得继续。

## A：职责与权限

采用 [CONTRACT.md](../acceptance/phase-1.5-agent-pilot/contract-r01/CONTRACT.md)。隔离脚本调用现有 Gateway，不新增线上 API、表、迁移或评分权限。程序拥有身份、版本、预算、结构装配和轨迹；模型无权修改标准答案、状态转换或校验规则。六个逻辑角色不意味着六个模型或六次调用。原生产生成器和审核门禁不改。

## B：受限示例与失败语义

采用 [SPEC.md](../acceptance/phase-1.5-agent-pilot/contract-r01/SPEC.md) 及 examples.json。限定整数值单链表与固定头插模板、最多四次尝试。正常插入、反序赋值自环、丢返回值、未初始化 next、分配失败均有明确观察边界；不执行任何 C。未知/越界拒绝；同源代码、答案和动作一致仅是必要条件，独立期望测试仍是正确性的前提。

## C：预冻结评估和有限修复

采用 [EVALUATION-PROTOCOL.md](../acceptance/phase-1.5-agent-pilot/contract-r01/EVALUATION-PROTOCOL.md)。开发矩阵与独立评估参数分离；独立参考真值须由评估者人工核对并绑定摘要，开发助手不能代签。双臂各14槽（10支持、4拒绝），最多一次内容修复；模型/参数在 T069 准确包锁定。没有同条件对照就不报告提升率。任何实际严重事实/答案错误即停并保留全部分母，不能追加样本或改规则挽救结论。

## D：实施、执行与独立评估边界

批准 A—D 后允许 T067/T068 零调用隔离实现与离线测试；T069 仍须冻结代码、Prompt、模型、费率、调用/token/金额/时间预算、材料外发和停止条件并取得准确执行授权。当前真实额度为0，旧额度/费用例外不继承。T070由独立于开发者的指定评估助手执行，不把开发者自查或模型 pass 当独立评估。评估材料未核定、服务能力不符或证据不足，保持 blocked 并交接。

catalog_only、H封存、旧批次停止及T038 blocked保持。试验完成不解除T038，不自动推进T039或开放生产；推广需要新决策。
