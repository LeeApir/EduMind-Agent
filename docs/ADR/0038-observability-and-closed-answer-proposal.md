# ADR-0038：审核可观测性与封闭答案契约提案

日期2026-10-27。状态：**提案待批准，仅允许文档与零调用证据整理；未实施，不授权真实调用**。依据r04实际停止证据与用户继续完成T038目标，保留sol路线和原教学阈值。准确附件：docs/acceptance/phase-1.5-observability-answer-plan-r01。

## A：隔离诊断中分离观察字段与硬内容校验

拟保留准确发送体SHA、准确stage/model/角色/完整Schema/源SHA/引用/工具拒绝/最终单一JSON/用量算术、限次限时/未知不重发等硬门。仅在合成开发审核建议的独立适配器中：

- response.instructions缺失或null记为echo_unavailable、instruction_delivery_verified=false、upstream_context_verified=false，不伪称原样回显或完整上下文可信。若字段实际存在且为文本，仍只接受准确发送系统文本或准确一次37字符后缀，其他字符串/未知类型拒绝。
- 唯一reasoning元数据项仍禁止明文content，仅允许空或至多1项summary_text，键只type/text，text必须字符串且≤4096字符；不读取含义、不作为证据、不展示/转发到课堂或其他模型，原响应仅私有封存。未知summary形状/额外项目、工具、额外message仍拒绝。不透明密文仍不解密且≤262144字符。
- 推理token仍包含在总输出中，不重复结算。响应元数据兼容不等于遵从所有指令、真实上游完整性、教学通过或生产准入；真实质量仍需主助手逐槽穷尽核对，独立人类真值仍false。

这是对已批准“必须echo且空summary”规则的具体变更，必须在新准确契约获批后才实施；不回写r04 unknown，不把其副本修改称作真实通过，不重启旧批次。本次未实现这些允许行为。

[官方迁移指南](https://developers.openai.com/api/docs/guides/migrate-to-responses?api-mode=responses)支持input中的系统/开发者消息或顶层instructions两种承载方式；并未在该指南保证原样echo。A是基于本地有限可观测性的**实验取舍**，不是宣称官方为AIAPI担保，也不证明45128输入token的构成。单纯移动字段或要求模型自述角色都不作为完整上下文证明。

## B：生成练习明确唯一答案域

拟版本化生成请求/提示中的练习要求，保留原输出Schema、题数/形式、原始目标/画像、上下游和事实/答案/评分阈值。需要精确匹配的练习必须在题干明确状态前提、有限答案域与输入格式，并具有唯一可核对的数字/标识符/固定选择标记；解释与论证放在讲解或solution，不把任意一句话当唯一定长正确键。

每类块仍只输出原Schema允许的字段，不能给code块填空markdown或剥除非法字段追通过。候选答案只是待审参考；语法形状不证明语义正确、评分可靠或适合掌握度，主助手仍逐题核对可接受/不可接受输入、原上下文和答案100%。不得裁剪题目、删除失败样本、降低召回/精确率/首次Schema门槛或把历史修复转成首次成功。暂定反馈与正式评分权限不变。

拟按两项独立零调用任务实施A和B，各自测试、记录与完成提交；A只改隔离诊断适配器，生产网关不继承；B按新Prompt版本保留旧源码/原件，并测试请求字节边界、Schema/形式及持久来源。未获此准确A—B批准不修改生产生成Prompt。

## 不包含的授权

A—B批准只覆盖离线实现、必要依赖/测试、隔离PG-Mock及文档，不包含真实Provider、计数探测、旧批次恢复、新token/费用/请求/时间预算、生产开放或T039。实施验证后才另冻结可直接审查的新准确执行包，不要求用户先批准未实现的未来付费代码。
