# ADR0065 栈课程画像对照的两次真实正文请求

当前为零调用准备。真实执行待用户批准准确清单、两份请求和下述 C2 边界。

1. 使用 T132 的两份原始请求，独立槽 A、B 各一条。目标、提纲、程序材料、系统提示、模型配置、输出 Schema 与 T132 相同。各槽用独立合成访客和所属画像版本创建新私有课程。画像版本及原证据、请求、封存响应和候选随操作绑定。候选经本次独立全文审核后准入，页面显示 A 或 B 来源；画像原证据和数据库标识保留在私有快照内。
2. 复用共用入口，固定槽 `stack-profile-array-first` 与 `stack-profile-operations-known` 各最多一条 DeepSeek 官方 Responses 正文。全批 0 规划、2 正文、0 修订，无重试、回退和探测。批准记录锁定同一清单及各槽请求；固定本机原件目录和原有一次性尝试标记避免同槽重复发送。T132 夹具仍仅离线。
3. 建议 A 后 B，每槽创建操作起独立 1,800 秒，发送前预留既有 90 秒 I/O 限制，审核及准入须在该槽窗口内。失败或结果未知时保留原件并停止该槽。另一槽只按已批准的准确额度继续。浏览器验收随后进行。两槽窗口各自计算，满额合计 60 分钟，间隔按实际登记。
4. C2 费用及保管边界为最多两次 HTTP，每次发送冻结字节，`max_output_tokens=4000`。严格校验每次回报输入最多 139,264、输出最多 4,000 token；回报校验阈值无法约束服务端费用。实际金额未知，无可验证硬上限；尽力停止后仍可能迟发或计费，本机原件无独立抗回滚保障，服务端留存未独立确认。
5. 两课各自完整审核事实、代码、帧、练习、解析、画像证据和任何越证据推断，绑定本次候选及真实响应类型。讲解深度评估必填，允许记录不足。课程正确、可学且无画像臆测时可独立准入；两课页面验收后，按 T132 既定三项逐项引用两课段落或帧及事实 ID，判断差异是否充分且符合画像。任何一项不足则对照未通过，保留各自通过的可学课程，原标准、额度和候选保持。该结果只覆盖一对固定栈画像，T038 不据此解锁。
