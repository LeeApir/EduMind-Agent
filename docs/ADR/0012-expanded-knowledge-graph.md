# ADR-0012：30节点知识结构、存储与课程资格

- 状态：**Proposed，待用户批准A–D及附件**。PHASE-1-T030未完成；不授权T031实施或动态开放。
- 日期：2026-10-09。
- 依据：PRD §0.1/§3.4/§5.4/附录B/§9.1，ADR-0003/0007/0010/0011。
- 附件：[确切节点/关系/教材依据](../../data/knowledge/expansion-v1/plan.json)、[可复核检查与微基准](../../data/knowledge/expansion-v1/check_plan.py)、[清单与测量报告](../acceptance/phase-1-graph-plan-v1.md)。附件摘要见[提案manifest](../../data/knowledge/expansion-v1/manifest.json)；批准须绑定准确字节，不追认未来实现。

## A. 确切范围和方向

冻结30节点：现有10节点的ID、名称和先修关系均保留，新增20节点详见报告表格。共69条有向关系，包括原16条关系；DEPENDS_ON从学习节点指向先修，EXTENDS从扩展指向基础，SIMILAR_TO显式保存双向。只有DEPENDS_ON必须DAG；循环链表知识节点不意味着知识依赖有环。

树遍历合并递归/迭代/层序，图表示合并矩阵/邻接表，排序对比为独立节点。平衡二叉搜索树本轮以红黑树概念说明平衡，非完整红黑树/AVL编程课程；哈希、最短路径、最小生成树、并查集和独立递归节点不在本次清单。快速/归并所需递归/分治基础写入学习目标与正文前置提示，不凭空建立额外节点。先修顺序是项目教学选择，教材链接提供概念依据，不谎称教材规定了本项目顺序。

参考以GNU C和作者维护的Open Data Structures C++ edition0.1G、OpenDSA官方索引为基础，只登记URL/章节，不复制教材正文或把C++实现当C代码。官网部分直接获取失败已在附件记录；T031须核对具体学习目标/误区与细节，不以一个URL证明正式课程已审核。

## B. 存储和版本边界

推荐继续版本化JSON-compatible YAML（现有文件格式）+进程内不可变Repository，用户证据/掌握度/路径版本继续PostgreSQL。30节点仅需单节点、直接先修/后继/相似、有限先修闭包及拓扑排序；O(V+E)扫描即可满足当前规模。微基准证明现有结构查询足够轻量，未测Neo4j，不声称Neo4j更慢。没有业务需求要求可变图事务、复杂路径模式或跨课程大型图，不增加Neo4j服务/驱动/账户和双写一致性边界。

T031发布独立`data/knowledge/phase-1.1.0.json`及来源sidecar；保留`data/knowledge_graph.yaml`、其mvp-0.2.0版本/字节及已签核10节点课程包。当前catalog loader用默认图完整ID集/版本验证manifest，直接覆盖seed会破坏目录基线；不得放宽该签核检查。T032将版本选择与catalog验证依赖分离，catalog固定历史图，扩展Repository由独立显式配置选择；未选择时仍使用原图。未知版本或损坏文件返回固定图不可用错误，不静默换回旧图或伪造空路径。

公共知识图内部schema v2保留现有节点字段，增加可验证来源sidecar/元数据核验状态，兼容读取v1。不得把自动核验记成`manual_fact_checked`或课程人工签核。公开图响应继续现有路径/字段/稳定ID，选择新图时如实返回其schema/version，T033客户端须兼容v1/v2；不添加owner、凭据或学习证据到公共图。T032/T033同步精确OpenAPI及测试。图不可用拟用503 `GRAPH_UNAVAILABLE`/固定文案；未知节点继续404 `GRAPH_NODE_NOT_FOUND`，不增加随存储后端变化的端点。

版本切换先离线校验再重启/配置切换不可变Repository，不热改活动对象。新路径固定新图/规则/画像/掌握度水位；旧路径及完成证据保留旧graph_version，旧DSL候选不冒充新图资格。回滚只切回已有合格版本并生成新路径，不改旧证据，不重新签核旧资源。T031补目标/误区/依据、T032补版本/查询/性能、T033补路径/UI资格；本提案不提前实现这些任务。

未来若出现大规模多课程/复杂关系查询，先取得真实查询/PG及内存测量，形成新的批准ADR再评估Neo4j；节点数量本身不是迁移触发器。

## C. 元数据与课程资格

新增20节点初始全为metadata_only；学习目标/误区/关系并非正式讲解、可评分题或掌握度证据。原10节点资格仍由当前有效签核目录manifest、版本/摘要和正式资源资格确定，不能仅凭图谱origin=legacy判定可学。

目录模式只进入已签核课程；可见元数据但查不到对应课程时显示“该知识点暂未提供已审核课程”，可浏览先修/返回可学节点，不生成临时课程、不输出虚假空资源、不标记掌握。路径保留目标及明确不可学习理由，不把未知节点或图加载故障当作缺课程；推荐的可进入下一节点必须通过当前课程资格判定，不能因教学顺序通向metadata_only就要求学生等待不存在的课程。既有catalog接口保持其404未发布课程语义，T033组合已知图节点与课程读取结果作明确展示，其他错误不冒充缺资源。

只有独立动态配置/模型/预算和ADR-0011准入全部通过，才可按原生成协议请求新节点课程；仍须schema+ReviewAgent后正式发布并实际评分才产生学习证据。按owner实际模型/资源资格判定，不把metadata_only一次性翻为所有owner已可学。没有本轮开放、真实调用、更多课程包签核或历史T033解封授权。动画DSL仍只覆盖ADR-0010目标白名单，不因图30节点扩大动作或动画支持。

## D. 批准与验证

本轮执行30唯一ID/来源、先修引用与DAG、三类方向/双向相似、旧10节点/16边保留、BFS队列/DFS栈闭包校验；每类结构查询15000次，记录Python/平台、图与实现摘要。测量对象只有未发布结构及现有查询实现，不制造manual review、课件或数据库数据。

用户需批准A–D及manifest准确附件后才能将T030记done并创建Task-Completed提交。批准前仅保存Proposed提案及blocked账本的治理提交，不能创建业务完成标记。批准不授予付费请求、动态开放、生产迁移/部署/push/merge。修改确切节点/先修/存储/API/资格边界需更新摘要并重新取得相应批准。
