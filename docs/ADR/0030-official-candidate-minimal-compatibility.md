# ADR-0030：官方候选的独立最小兼容入口（提案）

日期：2026-10-24。状态：Proposed，等待准确 A—C 与执行包批准。端点/模型选择已由用户确认；该确认不授权付费执行。

## A：准确配置和观察边界

仅 OpenAI 官方直连 `https://api.openai.com/v1`，模型 `gpt-6-luna`，Responses、reasoning none、service_tier default、store/stream false，不配置工具。凭据只读独立 `EDUMIND_COMPAT_API_KEY`，不读 `.env` 或旧 Provider key。无回退、代理环境继承、重定向或重试。先批准后读凭据和 DNS，公共地址验证后固定 IP、Host 和 TLS SNI。模型别名未获得日期快照，响应 model 仅接受相同准确 ID；出现其他映射则停止、提新包，不现场接受。

与教学代码隔离的 CLI 只运行冻结 S1/S2，每个用例向计数与生成接口发送完全相同的请求字节。S1 两个 system + 固定 OK，S2 顶层 instructions + 多字段/布尔/中文/引号/换行。S1 instructions null 符合官方可空语义，非 null 只接受准确系统列表或双换行连接；S2 必须准确回显顶层 instructions。max_output_tokens null 是上限证据未决，不宣称必然忽略限制，仍停止准入。按 output_text 类型聚合，允许前置 reasoning 项；完整原 Schema、本地固定预期对象、usage 与计数一致、总数算术及输出上限全部满足才通过。此处是小型合成观察，不证明所有输入或教学质量。

## B：有限预算和收费不确定性

新批次 `p15-candidate-compat-r01`，最多 4 HTTP / 2 生成，S1 完整通过才预约 S2；每次生成最多本地输入 4096，输出请求分别 16、128（含推理），合计 8192 输入 / 144 输出。单计数 10 秒，单生成 30 秒，全局预约起 90 秒含 DNS/关闭（DNS 用无凭据独立子进程，5 秒超时终止）；应用异步期限 89 秒留结算余量。响应解码上限每次 2 MiB。无重启、追加或补样本。

准确费率与来源见 execution package/pricing.json。USD 本地金额总额 **$0.02（20,000 micros）**；不是旧“无上限”例外。每对调用预约 `(4096输入 + 输出cap) × $1/百万token + $0.004096计数留额`，两对最多 **$0.016528**。该 $1 是保守计费包络，不是服务商报价；已覆盖当前各输入缓存费率及输出费率。公开文档未发现计数接口独立报价，不按免费处理：计数留额附在对应生成预约，计数成功也不释放它；unknown 保留整对最大预约。正常生成结算保留计数留额，以已验证 usage 加包络计价，账本不是发票。

有限本地占额不能强制服务端发票上限，计数收费仍有残余未知；只有明确接受这项不确定性的准确授权才能发送。若需要服务商账单硬上限，则先取得独立服务商证据，当前入口不能提供该保证。价格有效窗口 24 小时，启动时须有至少90秒余量；过期、涨价或映射变化需重新冻结批准，不自动更新。

## C：只准入下一步准备，不继承课程授权

任一 HTTP/Schema/计数/usage/回显/上限/凭据回显/存证/时钟/预算异常即停，未知保留，不再尝试 S2。输出目录独占创建，失败或中断后禁止重用；任何结果均终止本批次。两例真实兼容均通过后才可按用户要求另准备课程诊断，不能自动执行课程或将 T038 改为 done。当前只交付离线入口、测试和可审批材料；cbbb.fun 仍暂停，历史 r02/r03/p01、unknown、课程 Prompt、验收阈值及 H 封存不变。

批准 A—C 不等于批准任意端点或后续批次。准确包清单及两个独立批准登记均绑定 manifest SHA256；登记人工来源不能由脚本制造。`--check` 不读批准/凭据、不解析 DNS、不创建输出；`--execute` 必须先核验准确当前批准和价格窗口。
