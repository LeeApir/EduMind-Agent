## 逐项判断

| 内容或问题 | 判断及处理依据 |
| --- | --- |
| a1 的“sum()返回16，不直接打印” | 固定函数使用 `{2,5,9}`，循环下标 0–2，返回 16，且没有打印语句；无需展示调用方才能判断这段函数的返回语义。没有证据表明正文声称已运行程序或已观察到输出。 |
| 缺少调用示例 | 当前目标及计划未承诺完整可执行程序或调用演示；可作为展示建议，不能凭此列 `fact`。若其他课程明确承诺调用演示而未交付，应判断承诺覆盖，不自动推定事实错误。 |
| 缺循环状态和退出支持 | 正确代码可以被读者推演，但本目标要求追踪过程。学生正文/步骤没有明确状态对应和 i=3 退出教学；练习只问下标、算术与返回/打印。算术解析出现 2+5=7、7+9=16，并不等于讲明循环状态及退出。内部计划轨迹不计交付。具体缺口应进 `unresolved`，单元 `needs_human`。 |
| 未承诺动画却列 unresolved | 模型自己确认没有动画承诺和缺陷，仍列未决，违反可选媒体规则。这是额外无依据的不确定性；本次持久失败码仍为 `PURE_COVERAGE_FINDING_INVALID`，不重写原记录。 |
| 声称计划 key_steps 含轨迹 | 位置描述不准确：显式轨迹在内部 `shared_example.steps`；代码 `key_steps` 仅泛指遍历返回。主覆盖缺口仍成立，不能用这句误指作为交付证据。 |

`fact` 是问题类型，`minor/major/severe` 是严重度。把没有事实反例的问题改成 minor，并不能使分类成立。模型在同一 finding 中承认“presentation gap rather than a false arithmetic claim”和算术/return 正确，这也不足以支持它自己给出的 fact 类型。

## 必须同时保留的边界

| 对照 | 应有处理 |
| --- | --- |
| 正确函数返回 16，未承诺调用示例 | 不凭缺调用示例制造 fact；是否存在其他教学缺口另审。 |
| 明确承诺调用演示但未提供 | 指出承诺覆盖不足；无具体虚假陈述时不伪造 fact。 |
| 正文说返回 18，但同一固定函数返回 16 | 有可核对的事实矛盾，应保留具体 finding。历史 r03 `fact-contradiction` 保持原材料、标签和成绩。 |
| 长度为 3 却执行 `a[4]` | 有可达代码安全问题，应具体报告；历史 `reachable-safety` 对照不因当前误报而删除。 |
| 同时有教学缺口和有据严重事实/安全错误 | 两类证据可以并存；有据 reject 优先，不能全局清空 findings 或降为教学不足。 |
| 只能确定证据不足 | 具体说明无法判断的命题及缺失证据，进入人工；泛泛不确定性不能算检出。 |
