# MVP-0.3-T009 已审核动画缓存验收与交接

[缓存服务](../../backend/app/services/animation_cache.py) 先检查已审核的预渲染媒体，未命中才调用 T008 固定模板执行器；不支持的模板返回 `UNSUPPORTED_ANIMATION_TEMPLATE`，不会回退到模型代码或宿主 Manim。输入由 T005 白名单规范化，只允许两个公共链表模板及节点整数/索引，不接受 owner、画像、路径或自由文本。此服务只返回内部缓存媒体对象，不创建用户资源引用、不提供下载 URL；T010–T014 必须在 owner 授权与审核状态检查后才能让客户端读取。

缓存键包含知识点/模板 ID、模板与审核规则版本、规范化参数、语言、插入/删除源码摘要、固定镜像摘要、镜像内 376 条字体配置规范化清单摘要、执行器与容器入口源码摘要及字幕版本。字体摘要是 `9520e535c5093ae57e3e4b0707ee73d3d4b6f42d98ce05139654da991a9bfd6d`；镜像摘要见 [T008](mvp-0.3-t008-renderer.md)。缓存元数据再次核对 `approved`、版本、参数与全部运行身份。命中还逐个检查固定扩展名、非符号链接、大小、SHA-256、确定性 SRT 及 36/42 秒长度；损坏数据不返回命中。

同键请求通过文件锁串行，媒体对象发布阶段另加对象锁。正式 MP4/SRT 以内容 SHA-256 为文件名，通过硬链接创建不可变对象；损坏的原对象移入隔离目录并从已审核模板重新渲染，元数据在新媒体就绪后原子替换。只有当前请求的临时候选被清理；其他键的文件或用户数据不受影响。缓存仍是私有本地文件，数据库 Job/owner 绑定、内容引用事务及 GC 留给 T010–T014，不能将此本地缓存直接当成对外资源。

基准媒体在 `backend/` 执行 `UV_CACHE_DIR=/private/tmp/edumind-uv-cache uv run --frozen python scripts/prepare_animation_cache.py` 准备；首次通过真实隔离容器各渲染一次，第二次立即命中。实测如下：
