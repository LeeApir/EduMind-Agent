# 自由课程独立验收契约 r01

状态：待 ADR-0027 A—E 准确批准；不是执行授权或运行成绩。

## 1. 单位、证据与失败

课程槽是预先分配的一个输入/画像/配置/种子组合，一次create，含其批准范围内的重试/修复。重试算请求成本但不增加课程分母；首次输出失败不可因修复擦掉。用户调整、局部修订、恢复、导师操作独立标记，不伪装首次create。每槽保存输入摘要、owner匿名标识、版本、精确候选/Prompt/schema/规则/源码、请求预约和收据、原始输出、安全清洗后的实际可见输出、事件/时间与人工标签。凭据不进入证据。

计划分母固定。failed/timed_out/cancelled/partially_succeeded、超预算、中止后的未运行槽都保留；对完整课程类指标均算失败。需求本来要求的代码/练习缺失不能作为“不适用”删除。预先标注确实不适用的原子项才可排除，并报数量与理由；没有可评分分母意味着证据不足而非通过。待人工判断/分歧/缺少依据算未决：不能进入成功分子，整批不得done。

首完整场景可学与整课成功分别报告，局部就绪不补完整分子。明确澄清/不支持输入另设工程负例，不放进支持域课程成功分母；若冻结为支持域的槽被系统错误拒绝，仍是失败，禁止事后改成负例。

schema的预定场景数在独立包中预先标注期望范围；首次计划生成后在发起场景前冻结本槽实际数及摘要，必须在范围内，缺失计划采用预定范围上界列未运行槽，不能由失败结果选择小分母。schema只度量结构，不证明事实正确。可变大纲不要求精确场景数命中，语义质量按目标与依赖核对。

严重错误定义：导致核心结论/算法步骤错误、无法完成目标、代码危险内存访问、答案/评分键错误、误导正式掌握度的错误；全部实际自然输出（包括导师及修订）发现任何一项即停。严重probe是隔离的已知故障输入，不计自然错误事件，也不得向学生发布。待证实严重问题先停审查，不把模型严重度标签直接写成产品确认缺陷。

审核意见仅在隔离评测路径检查建议，不能给运行链新设“所有意见通过才可见”门禁。模型/GPT标签只作草稿；最终人工评测人身份、时间、确切内容摘要、证据及分歧处理必须真实存在。人工先看生成内容并标质量，再看模型意见；probe先标后跑。用于质量评测的标签不自动成为ADR-0026产品答案/节点核定。真实C执行只可使用已经批准的隔离固定驱动；本契约不授权新代码执行，可人工静态推演但须标方法及局限。

## 3. 样本、分区和诊断准入

T037开发输入12课程槽=6画像对，至少4个数据结构主题，含已知与未知画像、0/1/多节点建议、1–8场景边界和目标冲突负例（负例另计）。旧A/G/P/D和已暴露材料只用于开发回归。开发审核另10严重/10正确probe，召回至少9/10，所有其他率同表向上取整；schema无100项最低数但全量报告。诊断必须无未决、工程全过、零自然严重错误；性能作为诊断报告不替代T041，不是T038质量准入门槛。根账本T038/T040原通用“准入/质量/性能”门禁按各自任务验收对象澄清为开发质量准入及独立质量，作为ADR-0027 E待批准；T041独立性能门禁保持。只允许一个预冻候选的一批运行，无自动第二候选或追加抽样；失败blocked，再试须新的明确授权。

T039在候选冻结后准备未见独立质量40课程槽：10画像对20槽+20单目标；至少8个数据结构主题（线性表、栈、队列、树、图、查找、排序、复杂度），各主题≥4槽；至少10未知画像槽；10画像对包含已知对照及未知字段保持未知对照。主题分配表与每对预期教学差别先冻结，分层重叠可以但不得复制输入充数。期望场景覆盖1–8并产生至少100结构项，若不足只能在运行前重设计整包，运行后不足则证据不足不扩样。课程质量分层按主题、已知/未知画像分别计算同一95%门槛，禁止大主题掩盖小主题失败。画像对90%、事实99%、答案100%仍按各自单位。

独立probe20严重+20正确，与开发probe无同题/改写/变体；人工构造且先标，错误类型覆盖定义/步骤、代码、复杂度、答案及跨场景一致性，各≥4严重例。正确对照有相似表面特征，检验误拦。开发/独立素材、参考答案、人工标签、输出及候选修订访问分别记账。开发者可见的旧H资格只核对元数据；H01–H08仍封存，内容读取须另明确授权。无法证明未暴露或不适用即排除，优先新建样本，不从旧H补足数量。新独立集也须记录作者、访问/暴露、hash和冻结时点；用于修复后转为开发材料，不能在原候选或后继候选重新称未见。不得向独立内容调参。开发与独立集不用同题改写、同一代码错误模板或不同名字的同一画像对。

独立质量只一批，无择优种子/仅保留成功。失败后的新候选要另建独立集、冻结规则和授权；旧失败保留，不能以新批覆盖。质量/性能可分别失败，T041依赖T040通过。

## 4. 工程、兼容和安全

T035隔离PG/队列/真实HTTP+明确MockProvider，T036真实浏览器，均不借静态原型分数。固定工程矩阵至少覆盖：owner/CSRF、SSRF/凭据、XSS/动作/Manim隔离、未知画像、0/多节点、首次完整场景、局部失败可读、worker重启/lease、SSE重复与断线重放、unknown-outcome不重发/隔离槽、预算/并发、取消竞态、恢复不重复生成、修订原子切换/依赖失效、题组暂定反馈、有效核定准入、辅助暴露、撤销重放/不再授予、旧null来源/旧目录评分与签核、迁移兼容、页面桌面/320px/键盘、模型设置返回保留目标。每类有正/负例和断言（不适用须事前说明），逐项100%通过，0环境skip，日志、HTTP和数据库变化可追溯。不是按“测试总数多数通过”。

## 5. 性能与计时（T041）

独立40 create槽：期望长度2/4/6/8各5个目标，每目标冷/暖各一次；共20对、冷20暖20。均真实生成，暖只预热连接/进程，不命中旧课程/输出缓存，保持同一配置/并发owner=1、全局2，记录机器/队列负载、网络及Provider。单槽不得人为固定模型生成场景数；实际场景数用于分桶，T039冻结目标长度范围（2/4桶≤4，6/8桶5–8），越界计该槽失败。冷进程重启/无连接池复用；暖在前一操作结束后同进程连接池运行，顺序预先冻结。独立目标不能作为T040质量调参材料；性能输出也做硬门和语义严重错误复核，不能快但错。

使用单调时钟。t0=用户提交有效目标、客户端发请求之前；端到端包含网络/排队/规划/修复/持久提交/渲染。首完整场景=匹配版本的全部必需内容通过硬门、持久可取并在浏览器可读可操作（含该场景要求的代码/练习/动作，不必等非必需动画）。不把骨架、标题、首token、首段残片或done事件当首可学；同时保存服务端commit与客户端render时间对齐证据。P95首完整≤10秒，原PRD第一段≤10秒另报，不以新对象放宽旧目标。

后续等待：浏览器第一次导航请求每个非首场景时到该场景完整可操作；槽内按照前场景ready后立即请求下一个场景，禁止延迟导航直到内容生成完。每个非首场景一次，尚未生成等待也计；逐课程取最大等待，全部40槽均进分母；无后续/生成失败/未运行为+∞（本包期望≥2场景），P95≤30秒，附全部场景等待分布。

整课时间=t0至当前计划全部场景持久ready且浏览器可读。≤4场景桶P95≤180秒，5–8桶≤480秒；冷/暖各桶均报告并各达门槛。首场景和后续也冷/暖分别达门槛。P95=排序后第ceil(0.95*n)项，不插值。单个分位数允许尾部失败不代表整批通过，所有质量/工程门槛仍须同时满足且不得有未运行或未决槽。所有失败/未运行/中途取消/缺时钟为+∞，无分母不通过；报告中+∞保存为null及明确failure状态，不能JSON NaN。每个性能槽还须≤600秒操作上限。

另预冻10取消和10恢复控制槽（不混入40正常create分母）：取消从客户端点击到服务端cancelled且无新可见提交，P95≤5秒；远端结算未知仍隔离，cancelled不伪装停止计费。恢复从刷新请求到已保存场景可读P95≤2秒；未完成生成的续跑成本/等待另报，不算在2秒的已保存内容内。全部20槽状态/副作用须正确，否则工程失败。控制操作使用真实Provider与否/触发点在T039明确预算授权；未获准不执行，不能用Mock冒充真实性能。

HTTP首字节、正文首token、原首段时间与客户端/服务端偏差另报，首tokenP95≤2秒仍是非阻塞优化，不与内容门槛混同。

## 6. 冻结、预算和停止

当前请求0、费用0，不读取.env、不探测连接。T037/T039以后必须冻结准确源码/模型与版本/Provider/Prompt/schema/采样/运行参数/源码/材料hash、标签签名、配置、执行器、分母表、时间戳、请求/token/费用/墙钟四类数值上限以及一批次不可重复启动标识。缺任一准确上限/凭据/人工标签或真实授权即blocked；T005数值仅质量/性能设计，不等于上述执行包。

单操作create等沿用13尝试/600秒、课程40共享尝试、导师1次/90秒及共享token等既有准确契约；实际请求上限必须含重试、修复、审核probe、导师/修订/控制槽、可能已发送未知预约，不能直接把课程槽数当请求数。质量与性能单独预约与批次ID，不共享输出或双记成本；若未来改共享设计须事前新批准，禁止事后拣快样本。配置变化整批失效，不混算。

立即停发新请求并保留全账：自然严重错误、越权/泄密/隔离违规、预算/时钟异常、未知发送、独立性污染。普通失败一旦使任何固定率门槛已不可能达到也停止；尚可达到的普通失败继续按原固定顺序，仅到最先触发的上限为止。未运行保留且阻止完成。unknown outcome只按既有授权证据结算，无自动重发/转厂商。停止后最多做零调用取证，修复也不获自动重跑。两轮有实质区别的修复仍失败按AGENTS人工求助规则，不预先授权两轮真实执行。
