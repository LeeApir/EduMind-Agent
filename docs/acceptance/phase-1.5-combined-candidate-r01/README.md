# 新版角色准入与单份课程：准确候选包 r01

**待审查、待准确授权；本包尚未真实执行。** 本次以 T092 新 Prompt/绑定方式为基础，先运行七个合成角色协议槽，全部严格通过后，在同一新窗口内运行一份 C 臂头插课程并交用户评估。固定 7 个协议请求和课程首次规划请求的原始字节、本地源码及动态后续请求构造规则由 manifest 绑定；模型输出尚未知，后续内容/审核/修复请求的具体字节只能在前一步结束后生成并在发送前保存、验算摘要，不能声称事先已冻结这些未知字节。

本包建议调整 ADR0047 D 的执行顺序细节：原方案是“全部准入后另备课程包”，这里事先一并备好单份课程构造与预算，**只有七槽全部通过才在同一批次继续课程**；须在准确包审批中明确接受此调整。T038、原正式质量标准、旧停止/冻结包、旧预算和 H 封存保持。

## 模型、数据与顺序

| 阶段 | 模型及端点 | 请求和输出 |
| --- | --- | --- |
| S1–S5 | DeepSeek 官方 `https://api.deepseek.com/responses`，`deepseek-flash`，reasoning `none` | C 规划/内容/修复、B 生成/修复；合成固定内容的 Schema 严格回显，按顺序逐个验证。 |
| S6–S7 | AIAPI `https://aiapi.world/v1/responses`，`gpt-6.1-sol`，reasoning `low` | B、C 审核 Schema 的合成固定回显。 |
| 后续课程 | 同样的 DeepSeek 生成、AIAPI 审核 | C 规划→C 内容→C 审核；当前意见为普通教学 revise 时最多修复一次并复审，其他问题或失败立即停止。 |

七个协议请求使用专门的合成回显 system 指令；新版角色指令作为输入中的数据一起覆盖协议上下文，**不是把这七次回显当成新版教学指令已获服从或已完成课程**。七槽均严格 JSON/Schema/本地校验与固定值相等、完整准确 Schema 回显通过才进入课程；任一 HTTP、来源、响应、预算或校验异常即全批停止。实际课程使用 T091 原文 system 指令。C 规划结果经校验后完整进入内容请求；事实、代码、轨迹和答案由受限引擎提供，讲解及题目由模型生成。用户评估所有版本、审核意见与失败；模型 pass 为建议。

课程规格固定为初始 `[9]`、插入 `[1,2]`、`normal`、分配掩码 `[true,true]`。这些都是合成数据；发送目标、规格、引擎事实与轨迹、课程正文、私有答案、动作及必要审核/修复上下文，不含真实学生、独立真值或 H 材料。引擎模拟分配成功，实际 `malloc` 不保证成功；不执行 C。具体可查看离线 [课程样例](../phase-1.5-bound-course-sample-t093/course.html)，它是手写内容，不是本批模型结果。

## 预算、费用与停止

最多 **12 HTTP**（DeepSeek 最多 8，AIAPI 最多 4），其中协议检查 7，课程最多 5；无重试、回退、重定向、补样、旧批重启。新窗口登记起 **1800 秒**，单 HTTP 最多 60 秒、每目标 DNS 最多 9 秒；本地输入预约合计最多 98,304 token、每请求 8,192；请求总输出上限合计 56,896，课程每次请求 8,000。单请求最多 65,536 字节，原始响应接收最多 262,144 字节；既有 phase 校验视图实际还要求响应不超过 **65,536 字节**。时钟、来源、用量、响应格式、未知发送、事实/安全/unknown 或无效意见停止；不在截止后记录成功。实际输入和输出数量以上游自报为准并受本地校验，预约并不证明上游硬限。

公开峰值标价按全部预约估算约 **$0.4471808**（DeepSeek 输入 $0.30/百万、输出 $1.20/百万；AIAPI 页面列出输入 $2.50/百万、输出 $15.00/百万）；来源与计算见 [pricing.json](pricing.json)。实际账户分组、币种、费率和上游硬限未核实，取消后服务端仍可能计费，**无法保证金额硬上限**。若用户接受本包的费用例外，本包实际金额上限为未设硬限；旧例外不继承。

完整原始请求、状态、响应及事件按私有目录 0700/0600 保存，逐步预约后唯一发送、重放重建实际下一请求并校验绑定；已发送而未可信验证记 unknown。若响应超限或包含凭据，为安全只保留状态与有限诊断、不落盘敏感原文。摘要链只证明可信采集下的本地完整性；本地 `real` 标记也可被有写入权者整体重算，不能独立认证真实传输、上游路由、模型身份或完整上下文。凭据回显检测覆盖原字节、常见 JSON 转义与 UTF-8 内容，不可能识别所有编码变形。

## 用户评估与局限

本包将保留规划、原始/清洗后候选、全部代码、题干、解释、私有答案、程序事实引用、状态、动作、各版审核意见、失败和未运行项；按四项目标将对应题目、fact ID、轨迹和代码定位供用户逐项判断。需核对正文事实、题意/答案、代码、状态、动作及教学误解；引用正确不等于讲解正确。正式课程结果不因模型审核 pass 自动发布、评分或认定通过。后续具体请求字节、用量和真实失败须在执行后以原件呈现。

此单份 C 课程仅用于可行性，不是 ADR0041 的两臂 10 支持＋4 拒绝样本，也不能计算方案提升率或解除 T038。已有手写演示播放器的浏览器测试不自动转移到真实候选；真实课程如未对其实际数据完成播放、步进、重置检查，交付时只能标为静态/未验证交互。
