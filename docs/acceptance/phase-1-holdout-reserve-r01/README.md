# 留出验收输入预留 r01：先封存，不参与修复

这里预留8个与A01/A02原题不同的生成验收输入，在后续Prompt、模型、修复实现调整前冻结。**尚无模型调用、真实课程或独立人工签核，不能据此宣称泛化已通过。** 用户已指定由Lee本人核对；这只是复核人分工，不是内容批准。

## 分区与独立性的边界

- 开发回归：原A01–A04、沿用A目标的G01–G04、四类12个缺陷对照，以及这些材料的生成/审核回答与失败记录。后续36＋16诊断提案也只是开发诊断，不承担泛化证明。
- 预留输入：本包H01–H08，目标及预标签分别存放，摘要绑定。不得送入调Prompt、few-shot示例、模型选择、自动修复反馈或开发早停决策；开发两个入口没有加载本目录。
- 内容独立性有限：样本仍由参与修复的交互GPT编写，作者已经看过内容；文件在共同工作区中，不是密码学密封。检查器只能防止字面复用/改摘要，不能证明语义无近似、作者没见过或来自独立总体。它们是用途分离的留出候选，不是盲作者/独立真人真值。
- 当前交付的是**生成输入和预期参考，不是已签核的固定审核测试集**。生成模型实际给出什么尚未知，不能预填审核应该pass。独立审核材料须在候选配置冻结后取得新内容，由Lee不看审核模型回答先标注内容，再冻结这些正文/标签测审核。
