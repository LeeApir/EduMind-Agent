# 兼容等价性、契约变化与对照公平性

## 等价性边界

| 调整 | 分类 | 理由与证据边界 |
| --- | --- | --- |
| 字符串enum/const加蕴含的type:string | 接受集合等价的Schema转换 | 对任意输入JSON都不改变验证结果；旧ADR0045已有批准，但本轮不复用旧真实授权 |
| type:[...]改anyOf单类型分支 | 逻辑等价，远端不兼容候选 | 兄弟约束不变时析取集合相同；T081控制失败，所以本方案不沿此路线继续补items |
| 长度/数量/格式/唯一性等wire约束移至本地 | 校验分层改变；仅最终合取可等价 | wire单独接受集合扩大；只有本地逐条恢复并且拒绝不合格原件才保持最终约束。不能声称strict远端仍保证这些界限 |
| C fact_refs={path,value}改fact_ids | 实验契约变化，需A/B/C确认 | 不再测试模型复述正确值；程序解析确切事实。保留源版本/定位和值 provenance，不记录模型事实复述正确率 |
| C plan去spec复述/coverage，改spec_id和objective_ids | 实验契约变化 | 模型仍需正确选择/覆盖目标，但不再暴露重复映射出错机会；不与旧规划结构成功率直接比较 |
| 四题固定字段、B答案按题型 | 实验契约变化 | 限制了旧任意JSON域，格式约束减少错误机会；旧错误类型被提前拒绝。B仍必须自行计算四答案，不能代填 |
| B节点map改ID数组，null改none，data未知tag，动作按order分组 | 有条件可逆编码，仍按新契约审批 | 唯一ID、规范占位、全局order成立时信息可逆，但允许域/本地规则及模型输出难度已变，不是同一JSON Schema接受集合 |
| 审核digest→candidate_id、pointer→target_id、null理由→空串 | 实验契约变化 | 程序保存完整绑定，模型不再复制摘要/自由构造路径；移除部分抄写错误机会，未知/定位/逐项语义审核责任不减 |

“自然语言照原样保留、程序解析值不改写正文”是强制设计限制。例子中的错误讲解即使引用全部正确仍需要审核，不能把解析事实当正确讲解。未实现的本地验证不能作为迁移已完成的证据。

## 两臂继续可比的条件

- 相同原始目标、规格、四个题型/观察范围、生成模型/参数、审核模型/参数和教学判定标准。输出最大文本/状态范围相称，模板语义、节点ID约定和题型说明均为公开格式信息。
- B生成/修复只得原始规格与通用约定；C得确定性事实和代码/动作。这是已声明的干预变量，输入不完全相同；禁止把C事实ID解析器用于B答案，禁止按正确答案动态缩窄B的enum。
- B的答案、代码和动作均由模型提供；统一程序包装、none/tag解码、数组顺序合并、anchor/ID/摘要计算只改变表示，不改事实值。缺字段直接失败；错误答案即使程序已知道正确答案也不替换。新实现必须有反例验证“缺答案拒绝、错答案保留、没有事实泄漏”。
- B与C的结构复杂度和请求量天然不同。首轮角色Schema成功率分别报告实际调用分母与计划未运行数；首次完整结构仍按每臂10支持槽报告；新增本地格式拒绝单列，不把它混称模型教学失败。
- 参考答案/事实、自然语言、代码、题意与动作按同一独立标准判定。C答案来自引擎是系统方案优势的一部分；不能说它证明生成模型解题更好。审核同时看到两臂完整候选和允许程序参考，不见独立评估真值；未核定上下文不能pass。
- 保留B最多4、C最多5HTTP/支持槽、两臂10支持+4拒绝、最多一次普通教学修复、全批严重错误/安全/unknown即停等原协议。修复范围B整候选、C只内容不同，单列披露。新Prompt/契约冻结后重新选择独立参数并核定全部版本；开发正反例不得充作独立样本。

## 不能做的比较

旧失败来自接口拒绝，不能计成已观察教学质量失败，也不能与新成功单例相减算提升率。新结构成功率不能直接与旧Schema分子合并，因为题型、ID及编码改变了错误机会。七次合成echo不进入任何课程质量指标；单份C课程只证明可评产物存在，不能宣称达到10/10最终、9/10首次、4/4拒绝、0严重错误、0题意相关动作降级等原采用门槛。

即使新一轮B/C都成功，也只能评估“受限确定性引擎＋分工的整体方案”；没有“相同引擎但不拆角色”的消融，不能归因于Agent数量。若需该消融应另提任务/准确包，不在本轮增槽。

## 离线材料的解释

[examples.json](examples.json)故意包含：正确引用/错误正文、合法类型/错误B答案、结构可过/题干范围不成立。check_design.py应让其结构通过并标注待语义审核，不能自动确认教学质量。B正例是协议形态示例，代码为synthetic文本、动作极简，**不是完整可评课程**；C手写开发说明也不是独立核定真值。离线检查不产生任何模型能力、教学质量或实验改善结论。

## 待评估助手决定的具体事项

1. A/B：是否接受事实值改ID、固定四题结构和基线有类型答案/动作编码；能否覆盖已批准四变体及分配失败组合，有无漏掉可知前缀/未知中间状态？
2. B/C：短ID/target表的版本绑定与完整语义审核责任是否充足；是否接受删除复述错误机会后的指标解释及旧成绩不可合并？
3. D：是否同意7HTTP整体准入顺序/停止门，以及“缺Schema回显仅观察兼容、不能证明强制执行”的证据等级？金额边界未知时仍不得执行。

以上为审查议题，不登记任何现时批准。若评估认为对照已经改变过多，可以选择停止或要求新实验协议；不得以本设计完成提交代替接受。
