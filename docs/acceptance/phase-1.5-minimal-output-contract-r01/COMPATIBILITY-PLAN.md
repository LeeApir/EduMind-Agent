# 整套角色兼容验证提案（本轮不执行）

本方案不含HTTP入口、Key读取、准确请求体或有效授权；参数机器表见[compatibility-plan.json](compatibility-plan.json)。只有评估助手审查、用户接受ADR0047具体变更、离线实施完整校验且新准确执行包/新窗口/费用边界获准后才可以执行。任何旧包或未用请求均不继承。

## 阶段0：实施前审查与离线证据

先审本包四个完整Schema/六种模型阶段、事实/题型/动作表示和B/C信息隔离。若接受再实现新版本隔离原型及纯本地校验，不修改生产教学链路。未来实现必须新增：无答案代填/不泄漏事实、每个变体与分配失败的完整轨迹可逆表示、目录唯一/版本/摘要篡改拒绝、C正文错误仍能送完整审核、review完整target覆盖、未知/严重错误停止及全批时钟/原件验真回归。当前51个静态用例不足以代替这些运行测试。

实施冻结后再制作准确请求字节、最终Prompt信封（只调整输出说明、教学标准逐字保留）、源码闭包、公开与账户费率/币种/收费规则、总预算、外发清单和pending授权门禁；未获批前不加载凭据/DNS/建真实目录。存在无依据关键参数/费率时不运行，不默认沿用旧金额不限例外。

## 阶段1：一次完整的纯合成协议准入

每槽用最终完整角色Schema，系统说明“只原样回显固定合成JSON，不生成/评判课程、无工具文件网络”；仅通用合成数据和固定fixture。为覆盖嵌套输出，B fixture含非空节点/状态/高亮/步进，审核fixture含非空issue、unknown理由及准确target/quote；完整提议在[protocol-fixtures.json](protocol-fixtures.json)。它们不是课程、参考真值、教学审核意见或生成能力证据。修复阶段使用同Schema、显式合成旧版本/普通教学意见输入包装，不把格式失败当可修复教学错误。

接口分别为`https://api.deepseek.com/responses`与`https://aiapi.world/v1/responses`；温度0.2、text.format=json_schema/strict:true、stream:false、store:false。以上是已有候选的设计配置，不是重新确认当前账号可用。审核同一个Schema在B/C两种合成包装各测一次；首次/修复后共用Schema的revision/parent绑定由离线负测及准确包装检查，不另加调用。全部逻辑角色（含程序示例/动作）均要离线完整检查，但程序角色没有HTTP。

**严格上限：7HTTP（DeepSeek5＋AIAPI2）**。每槽仅1次，前槽完整通过才后槽，S7任何结果结束。新登记起900秒，含等待/本地处理；单HTTP60秒、每目标DNS9秒。两Provider分别固定本次核定公网IP并保持TLS Host/SNI，禁私网/元数据/重定向/环境代理借用/静默回退；不查询models、不额外计数，不自动新开窗口。

输入每次本地占额8192、合计57344；请求max_output_tokens如表、总16896，任何报告用量超占额即停；每请求≤65536字节、响应≤262144字节。占额与max_output_tokens是请求/客户端规则，服务端硬限/取消后计费未因此得到验证。未知占额保留，不退款重发。

金额设计建议USD1.00账户支出上限，不沿用旧“金额不限”。本轮离线不查询新费率，实际账户费率/币种/推理/缓存/中转计费规则仍未冻结；**该金额目前不可执行**。后续必须用可核验账户费率和保守调用/token占额确认可限制预算；若无法做到则保持不发，只有用户对新准确包明确接受新的费用例外后才可变更。不得把参考标价当账单硬上限。

## 成功与停止

每槽：真实HTTP200/completed、准确模型/参数/来源、strict JSON及完整本地规则、固定fixture逐值相等、无工具/拒绝/截断/协议异常、用量存在并在占额内、处于有效窗口。原始响应不改写；已知phase/summary/UUID/37字符后缀如要沿用须新包明确列举授权，未知形态拒绝，不能当场加容错。

Schema/strict/format回显若矛盾立即停止；缺回显记unknown enforcement，不能称服务强制执行已证。未来准确包若没有明确接受“仅观察兼容”的证据等级，则缺回显也停止。即便完整回显及fixture符合，也不是所有未来输入受约束的证明。

任一HTTP非200、超时/unknown发送、来源/模型/reasoning冲突、解析/Schema/ID/固定echo失败、工具/拒绝/不完整、用量缺失/越界、预算/时间/安全异常，**全批终止**。保留该槽失败/unknown与后续未运行；不重试/重定向/换模型/回退/逐字段改Schema补发/重启。若仍遇兼容问题，交付整套结果再决定是否修改契约，不能临时改字段挽救批次。

全部7槽通过且结束于窗口内，结论只能写“这套准确角色Schema与合成包装在本批观察兼容”；输出七槽分母和全部原件/hash/事件/时钟/来源/费用未知，独立只读复核。协议fixture不记课程数量、质量分子或教学审核召回。

## 阶段2：另行准备一份可评课程

只有整套准入通过后才准备新单份C课程可行性包，不自动发出。建议一份受支持规格的C规划→程序示例→内容→完整动作→审核→独立逐块逐题复核，首次3HTTP，普通教学修复/重审最多再2，共≤5HTTP；事实/答案/安全/unknown即停，不补样。该预算也只为后续设计建议，新的准确样本/源码/Prompt/外发/窗口/费率/授权须单独冻结。

可评产物必须含真实自然语言讲解、完整C代码和调用者、四题题干/参考答案/解释、所有必要状态/动作与审核原件，完整独立核对全部版本。不能用协议echo、只有规划、只图表或极简动作冒充课程。先证明能交付可评产物，再决定是否准备10＋4双臂对照；若需要单槽配对B可行性需另提≤4HTTP而非暗加到本批。任何单份成功均不达到原正式验收或ADR0041整体采纳阈值。
