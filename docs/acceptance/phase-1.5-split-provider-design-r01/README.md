## 固定范围

沿用用户已采纳的原34槽和顺序：12支持课程／6画像对、2负例、20审核探针；`slots.json`与原r03 manifest的slots逐项相同。既有材料来源不改写为独立人类原创或留出标签，不访问H01–H08。

DeepSeek官方`deepseek-flash`负责原规划与场景；AIAPI `gpt-6.1-sol`增加逐场景审核并保留20探针。按原场景上界，最多48个场景，因此审核总请求68次。每个成功场景的最终准确版本审核一次，课程槽人工核对前完成；失败／未生成内容不伪造审核。所有意见为建议，不发布、不写掌握度、不放行课程。

具体路由、凭据与信任边界、逐场景语义、停止和人工规则见 [ADR-0033 A—E](../../ADR/0033-split-provider-course-diagnostic.md)。`policy.json`列机器可读路由与预算，`scene-review.schema.json`和`scene-review-prompt.txt`是新场景审核契约草案。`probe-review.schema.json`保留现有resource-review-v3结构，不用新场景审核契约替换原探针或篡改历史评分。

## 尚不能启动的原因

1. 现有调度器要求可靠的`input_upper_bound`和已验证总输出限制；DeepSeek两例是小型协议观察，未建立独立输入证明。sol所在供应过去实际报告输出超出请求值，尚无新证据解除。
2. 本设计不把`bounded_output_verified`置true，不删除计数／完整Schema／教学门禁，也没有允许250次调用的实验豁免。公开价格不能证明当前AIAPI分组费率。
3. 新逐场景意见的PG／来源／预算联调尚未实施；本包只有离线路由、准确来源和引用校验原型，没有DNS、HTTP、Key读取、批准创建或执行命令。

后续可以实现A—C的隔离编排与PG-Mock验证，但若希望绕过缺失的边界证明开展真实实验，须先提出具体实验范围与证据等级，不能用普通配置修改将其伪装为生产安全条件已满足。真实完整诊断须重新冻结全部源码／材料／请求／双供应价格与准确授权；旧合成两次或“无上限”例外均不继承。
