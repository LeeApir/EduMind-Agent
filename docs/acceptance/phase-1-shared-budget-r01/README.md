# T083：共享持久预算与绝对截止

0033迁移新增操作预算版本/映射/重建/剩余必需请求计数，以及learning_correction_permits、learning_generation_attempts。原操作generation_call_count仍是统一计数，每次发送前只加1并追加attempt；记录代表已消费的发送预约，网络前失败也不退款，不声称每条都实际到达Provider。

操作行锁串行保护计数。映射最多1次，与后续共享20次/180秒；截止初始化一次，失败不清空或重新计算，单次超时不超过60秒或剩余窗口。预约提交后再检查截止，过期不发网络。旧非零无版本账本拒绝续跑，不把历史迁移成新预算。

基线为9+M+2R，资源修正每对2次、单资源最多2对，无重建共享5对、有重建4对。修正先预约独立permit，不增加实际请求计数；发送修正及其审核时分别消费一个permit槽并各增加一次attempt。permit只能按0→1→2消耗，数据库禁止退款/删除；attempt禁止UPDATE/DELETE。未消费对不允许并发抢另一个对，剩余必需基线tail独立保护。修正池耗尽转明确needs_human，仍完成剩余资源和最终单元审核，不能拿人工结果补自动分子。

复用旧计划/内容的重解释按实际跳过的基线请求减少tail，但修正池仍保守使用同一5/4上限，不能借复用扩大重试。180秒不保证完成20次；终止后的尾部/未消费许可保留，不退款续跑。重建计数实际预约与新版本编排待T084，当前默认空验证器。

映射输出512、计划2048、资源4096、全部审核8192，预算版本/上限纳入政策摘要。22种M/R/K组合及108种资源分配符合冻结算式，最大输出配置求和117248；不是总Token或真实费用估计，输入依赖上游内容。本包真实请求授权0。
