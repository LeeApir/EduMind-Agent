# T037：720p / 15fps 呈现修订

用户明确要求将固定 DSL 视频从480p提升至720p/15fps，并一起修复字号、箭头、方框比例与留白。此变更不代表旧媒体获得人工签核，也不开放动态模型入口。

## 行为

- DSL固定输出1280×720、15fps；Manim显式传入分辨率与帧率，容器逐帧解码和宿主均严格核对新规格。模板运行规格维持原版本。
- 节点使用1.3×1.35卡片：标识、数值、访问状态分占独立位置。数值28、短标识20、长标识18按8字符分行、指针/说明22、标题24、复杂度20；交换只更新数值，位置不会跳动。
- 箭头头部0.14、比例上限0.3、线宽3、端点留白0.04，均由固定编译器生成并由AST精确白名单核验。边与方框边界求交，指针入口避开节点标识；NULL在指针标签行显示。
- 布局用整段可信轨迹的网格占用范围一次确定居中变换，最大横向跨度10.2、列距上限2.25；不会随着新节点出现重新排版。
- 核对页按16:9显示、宽度上限1280。截图等待实际目标帧呈现（时间误差≤1帧），去掉播放器控件；逐动作图可点击查看原图。画面自带说明，外置字幕默认关闭，仍可下载SRT。

## 身份与限制

编译/静态政策版本为`animation-dsl-compiler-v2-720p`、`animation-dsl-static-v2-720p`。编译器、政策、执行器、媒体校验器的变化进入现有候选/审核/缓存身份，不复用旧480p资格。九动作、文本输入边界、独立审核、owner授权、容器禁网/非root/只读及CPU2/RAM1GiB/120秒/输出256MiB约束维持。固定字体镜像没有变化；不用Provider。
