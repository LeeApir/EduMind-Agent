## 4. 历史失败、新样本与预算

[归档账本](../tasks/mvp-0.3.json) 的 `MVP-0.3-T033` 保持 blocked，历史累计2033/2500不变。原失败材料和恢复来源见 [材料索引](README.md)，本地证据归档为 `588f5dc90680ab551b70f13c5f8a77c8cece6b60`。T035 先只读恢复/核对具体失败样本 ID、hash、故障类型；材料缺失须求助，不能凭空重写“等价通过”样本。

正式集合包含旧失败复验组和未参与调参的新案例组，分别冻结并报告。schema/生成、严重错误、正确对照、长审核各组均须有新案例；确切分组数和人工标签由 T035 在调用前保存，独立保留新例，不反复将其用于诊断调参。诊断样本不算正式分子，正式失败不补跑替换；变更代码/Prompt/模型后新一轮独立冻结，不能只重跑失败槽获得整轮通过。

当前真实本地模型/云端 Provider 授权均为 **0请求，付费上限0**。安装适配器、配置Key、拥有历史剩余额度或获准执行T001都不授予真实探测/生成许可。T039接入、T040诊断、T040正式质量、T041端到端分别批准，前一步通过不会自动授予下一步预算。

调用前冻结附件必须记录：

- 明确目标 URL/Provider/模型及本地或云端、生成/审核档位、数据类型与可发送上下文；实际 Key 只经安全配置注入，不写附件。
- Git SHA、锁文件、Prompt/规则/schema/编译器/模型配置版本及hash；不可变样本、顺序、N、判定、报告目录、硬件/浏览器/容器及缓存状态。
- 各步骤请求硬上限、并发/timeout/重试/最多2次修正，以及费用币种/上限；真实接入探测、列表刷新、画像、生成、审核、回退、修正、重试和计费预热全部计数。
- 用户明确批准的附件/版本与范围；批准的回退目标独立计费，不允许静默跨厂商。缺授权、目标不可用或预算不足即停，保留剩余未运行槽。

按实际出站尝试计请求，超时/失败也占预算。发送前原子预留请求与费用，未知用量不当0；无法保守限制费用时停止并求助，不事后补账。未发送即失败可记0，具体证据保留；实际Token、估计值和未知分别列报。T035 实现并Mock验证未授权/超额拒绝，T001只固定规则、不修改运行时。

诊断先分严重错误检出、分类、正确对照、长审核/结构化四组设置独立上限和通过/停止条件，逐组评估；连续异常、泄漏/越权/未许可回退、安全失守、预算/能力/准入不通过立即停止。不得拿少量诊断≥90%宣称正式召回达标，也不得反复失败后自动扩额。环境修复后的新轮次保留初败，不覆盖旧文件。
