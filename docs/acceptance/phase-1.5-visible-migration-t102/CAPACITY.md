# 可见视图容量和本地预约：开发策略与证据

这些数值构成本轮隔离开发策略，不是已批准的真实实验预算。旧冻结文件不变，也没有据此调整正式样本或教学标准。**不要求证明所有结构合法输出均能装入限额**：真实实验应按事先固定的策略处理，超限停止并保留失败或未运行槽，不能借选样避开超限，不能把停止当成通过。

## 已有边界与计量

原模型输出的 canonical JSON 上限为 128,000 字节；每个段落、题干及解析最多 4,000 个 Unicode 码点，最多 8 段和 4 题，共最多 16 个此类正文位置。B 代码最多 20,000 个码点；B 的原始动作最多 64 个状态、180 个总动作，每个状态最多 7 节点。C 的代码、状态和动作来自受限 3+4 规格引擎。这些限制不能简单相加当作可同时达到的样本，因为还需同时满足 128,000 字节总上限。

审核实际请求通过 [完整外层构造器](../../../scripts/isolated_diagnostics/p15_visible_request_budget_v1.py)测量：最终 JSON 包括两段实际 `input`、版本化审核指令、完整 Schema、模型/推理参数以及用户消息的第二次 JSON 转义。开发预约按 **最终 UTF-8 请求字节数 + 8,192** 计算，输出请求值按 8,000 预约；共享账本对所有已预约调用保留占额并求和。它是可重算的本地记账规则，不是服务端 tokenizer 上界、上下文保证或费用保证。

项目锁定 Mistune 3.4.0；本地源码中的 block 和 inline parser 默认 `max_nested_level` 均为 20。它限制各自解析器的一部分嵌套过程，但还不能单独推出组合解析树深度、节点总数或整个审核视图的大小上界。不能将该默认值当作已证明的项目契约或在运行中静默收紧。

在已生成可见视图后，若该视图的 canonical UTF-8 长度为 `V`，将其作为 JSON 字符串放进外层请求时，字符串内容的保守编码长度不超过 `6 × V` 字节；还须加实际系统指令、Schema、JSON 字段名、其他参数及引号。这个关系只解释二次转义，**不证明**从原始合法 payload 到可见视图的 `V` 上界，也不等于模型 token 数。现在用增量编码在超过请求字节门限时终止，不截断教学内容；单个 JSON 字符串片段仍可能先整体分配。

## 预演结果

下列结果取自 [capacity-evidence.json](capacity-evidence.json)，含原 payload、修订后 payload、每次外层请求及本地预约。参考/代码/动作均为合成结构数据，不能据此判定教学质量。

| 样例 | 原 payload 字节 | 引用出现次数 | 状态／动作 | 初次审核字节 | 修复后审核字节 | 本槽本地输入预约合计 |
|---|---:|---:|---:|---:|---:|---:|
| B 密集引用及 20,000 行 | 113,695 | 10,656 | 21／61 | 4,525,213 | 4,525,309 | 9,239,349 |
| C 密集引用 | 64,914 | 10,656 | 21／61 | 2,466,392 | 2,466,488 | 5,094,282 |
| B 不同定义及 20,000 行 | 113,704 | 9,693 | 21／61 | 7,680,483 | 7,680,579 | 15,549,898 |
| C 不同定义 | 64,923 | 9,693 | 21／61 | 5,621,662 | 5,621,758 | 11,404,831 |
| B 转义字符 | 87,293 | 8,000 | 21／61 | 1,934,595 | 1,934,691 | 4,026,138 |
| C 转义字符 | 77,778 | 8,000 | 21／61 | 1,912,387 | 1,912,483 | 4,013,536 |
| B 状态/动作上限及 20,000 行 | 75,564 | 128 | 64／180 | 2,266,018 | 2,266,114 | 4,688,672 |

B/C 不同定义样例的静态本地输入预约合计 26,954,729，输出预约 72,000；若仅作算术演示，10 对完全相同的此类支持槽分别为 269,547,290 和 720,000，**不是**全域上界或实际收费预测。脚本中的 13,000,000 是**单次请求**估算门槛，而 B 单槽四次合计已达 15,549,898；不能把该数字直接当作全槽或全批预算。B 的 worker 完整结果为 19,722,308 字节，仍低于开发期 32 MiB 输出门限；非空修订意见重建的 worker 输入为 21,189,934 字节，低于开发期 64 MiB 输入门限。

同规模 B/C 合成材料另经共享控制器走完 9 次 Mock HTTP；实际登记的本地输入预约合计为 26,954,741，输出为 72,000，与上面的静态计算相差 12 字节，来自模拟审核意见的具体文本。完整请求和响应保存在[压缩证据](stress-mock-flow.json.gz)，可用独立脚本重放；其中的 10／20 token 使用量由 Mock 夹具提供，不代表真实服务。旧 4 MiB 已被合法结构样例超过，不能通过正式选样避开。

以当前开发门限作保守记账算术：单次请求最多 12,000,000 字节，对应本地输入预约不超过 12,008,192；B 每支持槽至多 4 次、C 至多 5 次，分别是 48,032,768／60,040,960，本地输出预约分别为 32,000／40,000。10 对支持槽至多 90 次，因此仅从这些门限可推出全批本地输入预约不超过 1,080,737,280、输出预约不超过 720,000；8 个拒绝臂槽本地处理，0 HTTP。这只是乘法上限：不证明所有合法输入都能通过 12 MB 请求或 worker 门限，也不证明账户上下文、token 计数和费用可接受。真实包仍须明确各槽及全批的实际授权预算。

## 实际开发策略与停止行为

| 层次 | 隔离开发门限或规则 | 超限／不确定结果 |
|---|---|---|
| 原始候选 | canonical JSON 不超过 128,000 字节，并遵守原角色字段、状态和动作限制 | 该臂槽失败，全批停止；不截断或补样 |
| 子进程 | 输入 64 MiB、结果 32 MiB；CPU 25 秒、墙钟 35 秒，另最多 0.5 秒回收及 0.5 秒监控线程收尾；RSS 每 0.1 秒采样，超过 1 GiB 停止 | 停止并保留原因；无法确认进程状态按未知处理 |
| 单次请求 | 含外层 JSON、实际 Prompt 和 Schema，最多 12,000,000 字节；本地输入预约为实际字节数＋8,192，输出预约 8,000 | 在发送前拒绝并停止；不截断内容 |
| 全批预约 | 按固定槽位、阶段和包共享累计：开发算术上限为 90 次、输入 1,080,737,280、输出 720,000；正式包可以事先固定更低的上限 | 任何一项不足即停止，原分母保持；这些数值不是上游 token 或费用保证 |
| 响应 | 原始流最多 2 MiB，禁止非 identity 内容编码；精确回包校验和用量结算 | 超限／缺失用量／超预约／不可信响应停止，已预约占额保留；对于不安全正文，离线适配器不保存该正文 |
| 时间 | 当前开发控制器单次 HTTP 最多 60 秒，且不得超过包的绝对截止；批次到期应返回超时并停止 | 已登记发送的结果未知时占额不退；在本进程可继续接收的迟到回包只留证、结算，不推进 |

`fixed_denominator_summary()` 按预先登记的每个臂槽生成记录，区分机械完成、本地拒绝、失败或未知、未运行；在 10 支持＋4 拒绝、B/C 两臂的开发夹具中，分母保持 **28**，其中支持 20、拒绝 8。未运行不是错误回答，也不是成功；机械完成不是教学质量通过。失败前没有创建 HTTP 预约的槽也先持久登记为已启动，崩溃恢复时保留为失败或未知；未启动槽仍为未运行。

开发 worker 先限原 payload 和合法角色结构，再在子进程中解析 Markdown、重组候选与视图；视图展开及审核重建都在该子进程。采样 `ESRCH` 只有在有界等待确认子进程退出后才视为退出竞态，仍存活或无法确认时停止。超时后对子进程组尽力终止，并且只做有界回收；逃离进程组的后代不能据此保证被终止。当前 worker 不是可执行不可信代码的安全沙箱。

直接 Mock 控制器按流累计，超限时保留有界前缀；新版隔离适配器为避免写入可能含密钥的前缀，在其自身检出超限时不保存正文。正常回包从原始响应解析用量，未知或超预约时不退占额。服务可能忽略输出参数或报告不同 token 数，取消客户端不证明上游停止。

**能力边界与当前阻塞：** 12 MB／32 MiB／64 MiB 不保证容纳所有结构合法内容，这不再是继续工作的前置条件。macOS 这里没有可靠的地址空间硬限制，RSS 采样可能超冲，父进程和单个 JSON 字符串片段也不是硬内存界；守护线程无法强杀，同步 SQLite／`fsync` 期间异步截止不能保证调用方硬实时返回。真实部署若要求操作系统级硬资源上界，必须使用具备该保证的隔离环境并实际验证。另有停止与凭据隔离的具体反例，见[阻塞说明](BLOCKED-20261101.md)；在其关闭之前不得把本策略视为真实执行准入。真实 Provider 上下文、计费及取消行为仍需独立准确包验证。
