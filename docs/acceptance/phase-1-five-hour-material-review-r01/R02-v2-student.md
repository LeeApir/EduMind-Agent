# C 指针：取地址、解引用与返回值

看下面这个函数，区分“变量本身”“变量的地址”和“变量中保存的值”：

```c
int pointer_sample(void) {
    int value = 21;
    int *p = &value;
    return *p;
}
```

1. `int value = 21;` 创建一个 int 对象，并把它的值设为 21。
2. `&value` 使用取地址运算符 `&`，取得对象 value 的地址。`int *p = &value;` 声明一个 int 指针 p，并用这个地址初始化 p。因此 p 保存的是 value 的地址，不是整数 21。声明中的 `*` 表示 p 是指针；这里没有读取所指对象。
3. 在表达式 `*p` 中，`*` 是解引用运算符，表示访问 p 所指向的 int 对象。本例 p 已由 `&value` 初始化，读取发生在 value 仍存活时，所以这次读取的值是 21。不能把这个结论推广到未初始化、空指针或对象生命期已经结束的指针。
4. `return *p;` 把读取到的 int 值 21 返回给调用者，没有把 value 的地址返回给调用者。函数结束后 value 的生命期结束，但调用者得到的是整数值 21，不依赖这个局部对象继续存活。

“返回值”是函数交给调用者的值，与“打印到屏幕”不同。这个函数没有打印语句；若调用者希望显示返回值，需要另外处理输出。
