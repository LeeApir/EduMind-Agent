# T103 来源审计与本批责任分配

T103 已复核可学，但其成果不等于模型原样生成完整中文课程。依据 [T103 构建器](../phase-1.5-unified-head-course-t103/build_course.py)、[lesson.json](../phase-1.5-unified-head-course-t103/lesson.json) 和 [独立评估](../phase-1.5-unified-head-course-t103/ASSESSMENT.md)。

| 学习材料 | T103 实际来源 | 本批要求 |
| --- | --- | --- |
| 最早四段讲解、四题题干/解析 | T095 真实模型英文原稿；T100 中文由助手重写 | 不沿用这些句子，由本批真实模型生成 |
| T103 实际中文正文 | T100 助手中文；最后一段判空覆盖句由 T103 助手调整 | 本批 `paragraphs` 原样，不能替换句子 |
| 每步标题、状态解释、两次成功判空说明 | T103 助手手写 notes/titles | 模型生成 `step_notes`，程序只核对 frame_id 和绑定；缺少即失败，不补写 |
| C 代码、11 状态、原31动作、四题答案 | 程序受限引擎/模板，经 T095/T098 同版保存 | 保持程序派生，按各样例重建；不声称模型生成算法或验证任意 C |
| 13 步装配、补入成功判空帧、局部作用域标签 | T103 助手编写程序规则 | 规则作为冻结程序派生，说明文字由模型写；固定指针字段标签/不在作用域等格式标注仍属程序 |
| 学习目标/前提/页面说明 | T103 助手撰写 | 本包固定目标和有据前提输入；模型生成展示用 prerequisites/learning_summary，不臆测学情 |
| 生命周期、失败边界、专用收尾 C 片段 | T100/T103 助手解释，片段由助手写 | 模型生成 lifecycle/failure_scope；本批不展示或执行收尾代码，不能把 T103 片段补进课程 |
| 页面布局、控制按钮、输入格式提示、答对计数和通用反馈 | 助手编写的程序模板 | 冻结程序资产复用；不算模型文本或推理成功 |
| 来源/未签核/非正式评分提示 | 助手维护的产品与证据说明 | 程序固定来源标签保留，不用来替代缺失正文 |

“未经助手补写”指真实教学字段从完整原始回包解析后直接转义装配；程序并不要求模型重写代码或按钮。助手可以提出定位问题，由模型按一次普通措辞修复规则生成新完整版本；不得直接改 JSON/HTML 中的教学内容，也不得静默沿用 T100 的答案解析、步骤说明或资源段落。原始回包、解析失败、首版与修复版分别保存。
