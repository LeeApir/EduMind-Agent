# MVP-0.3-T032 模板可用率与动画性能验收

## 冻结输入与环境

采样前将 [100 个模板质量、100 个浏览器缓存播放和 20 个按需渲染槽](mvp-0.3-t032-frozen-slots.json) 固定（SHA-256 `3edaaf5bb3fa273da64b12207649ea47859c328e3eba0a0dd544ba0e29810bec`），基线提交为 `27628dfab7c9580d06d4f29383bdbe08f852a3ac`。质量矩阵两模板各 50 槽：空/头/中/尾/单节点等合法边界，20 组不同参数各重复五次。首次 20 槽由固定 Manim 容器实际渲染、完整解码并校验 MP4/SRT；后 80 槽检查审核缓存、摘要及指针遍历语义。非法参数单列测试，不放进合法样本分母。浏览器缓存播放两模板各 50 槽；按需渲染两模板各 10 槽，每槽使用全新缓存目录，保证服务端未命中。单并发，无 Provider 请求或付费重试。

环境为 Apple M3、16 GiB 内存、macOS arm64，Chromium 153.0.8010.12；浏览器 HTTP 缓存由 CDP 禁用。渲染镜像摘要为 `sha256:89ab433ce59134a4dcf351deb2511e067ab354393c0bb7d1859f3e8f0b2406a3`，执行器限制 2 CPU、1 GiB 内存、120 秒墙钟、禁网和 256 MiB tmpfs。质量媒体及新渲染媒体分别放在 `/private/tmp/edumind-t032-quality-20260929` 和 `/private/tmp/edumind-t032-fresh-v2-20260929`，浏览器使用新建并迁移到 head 的隔离 PostgreSQL 库，不触碰开发卷。样本从点击到浏览器 `loadeddata` 且 `playing` 的单调时钟计时；P95 使用 nearest-rank，失败记为 `+inf` 并计入分母。
