# 引用表示与播放器开发预览

[打开隔离预览](course.html)。这是助手对旧合成候选加工后生成的**开发样例**，不是新的模型输出、教学签核或正式产品播放器。旧 T095 原件、T098 播放器和 T101 冻结包保持不变。

新 `isolated-reference-document-v1` 保留每份原始 Markdown、惰性 token 树、按目的地去重的引用定义、声明的定义（包括未使用项）及每处引用的 token 树路径、标签和定义 ID。位置是树路径，**不是原文字符或 UTF-8 字节偏移**。原始内容与定义会被重建校验；没有导航链接、远程图片或模型代码执行。

`isolated-reference-artifact-v1` 由原始候选直接构建该表示，避免先生成旧的展开 Markdown；C 的事实/答案/动作仍由程序生成，B 仍由基线输出，不给 B 代填引擎答案。预览现使用 ADR-0049 的 `visible-review-view-v1` 开发视图，段落、题目、答案、代码行、引用、状态和动作绑定相应可见短 ID 与视图摘要；它不再使用旧 `isolated-reference-review-v1` 的目标 ID。空标签以实际显示的 occurrence 结构单元作为非空证据，类型是派生结构信息，不能冒充原文摘录。预览显示转义后的**原始 Markdown 字面文本**，并集中列出惰性定义、引用标签及树路径；这是一项展示语义变化，不是旧展开视图。B 预览状态来自 B 自己的 `show_state` 动作，不从程序参考代填；目前只在合成开发数据上验证，不能称为正式实验结果。

浏览器命令：`PYTHONPATH=backend:. backend/.venv/bin/python docs/acceptance/phase-1.5-reference-player-t102/check_player.py`。本机 Chromium 实际检查了 C 同一候选/可见视图目标、多个不同定义及引用标签与路径、四题及答案、31 动作/状态/高亮、前后步、自动播放、暂停和重置；另以合成 B 候选故意让模型状态与参考不一致，逐动作核对模型状态、动作短 ID 和 Unicode 换行代码高亮。正文、题干、解析及引用从安全 JSON 通过 `textContent` 填充；合成 NUL、CR 和 CRLF 原文逐字符匹配目标，未执行 HTML 或产生外部请求。B 答案使用模型原值及对应目标；这些是开发样例，不是教学验收。macOS 默认沙箱不能启动 Chromium，测试使用允许的本机执行环境。

此前 34,735 字节 Markdown 展开反例在新表示下审核请求为 1,379,840 字节；16 个字段、每字段 240 个嵌套引用的合成压力样例，B/C 请求分别为 2,670,764/2,653,555 字节。每处引用除文字目标外另有类型目标，以便空标签仍可使用非空证据；因此目标目录带来额外开销。它们是有限样例，**不是** 4 MiB 全域上界证明。解析树深度、目标目录、中间副本、最大转义与 128,000 字节原始 payload 仍须推导和验证。当前 `bytes + 8192` 只表示本地预约数字，不能保证服务端 token 或费用。完整真实控制器、受控响应/用量、复审和独立评估仍未交付；不得发送真实 Provider 请求或提前冻结/选样。
