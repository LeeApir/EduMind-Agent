# 引用表示与播放器开发预览

[打开隔离预览](course.html)。这是助手对旧合成候选加工后生成的**开发样例**，不是新的模型输出、教学签核或正式产品播放器。旧 T095 原件、T098 播放器和 T101 冻结包保持不变。

新 `isolated-reference-document-v1` 保留每份原始 Markdown、惰性 token 树、按目的地去重的引用定义、声明的定义（包括未使用项）及每处引用的 token 树路径、标签和定义 ID。位置是树路径，**不是原文字符或 UTF-8 字节偏移**。原始内容与定义会被重建校验；没有导航链接、远程图片或模型代码执行。

`isolated-reference-artifact-v1` 由原始候选直接构建该表示，避免先生成旧的展开 Markdown；C 的事实/答案/动作仍由程序生成，B 仍由基线输出，不给 B 代填引擎答案。`isolated-reference-review-v1` 和本预览使用同一份产物；目标目录保留原目标并给每个引用标签增加独立目标 ID。审核必须遵守既有 Schema、候选 ID、意见与精确引用校验。空标签可引用独立的 `link`／`image` 类型目标，此类型是派生结构信息，不能冒充原文摘录。预览显示转义后的**原始 Markdown 字面文本**，并集中列出惰性定义、引用标签及树路径；这是一项展示语义变化，不是旧展开视图。当前预览只支持 C，明确拒绝 B，不能据此证明 B 播放器可用。

浏览器命令：`PYTHONPATH=backend:. backend/.venv/bin/python docs/acceptance/phase-1.5-reference-player-t102/check_player.py`。本机 Chromium 实际检查了同一候选/审核目标、逐项定义和引用标签与路径、四题及答案、31 动作/状态/高亮、前后步、自动播放、暂停和重置，以及无 HTML 执行与外部请求。macOS 默认沙箱不能启动 Chromium，测试使用允许的本机执行环境；结果只针对该合成预览。

此前 34,735 字节 Markdown 展开反例在新表示下审核请求为 1,379,840 字节；16 个字段、每字段 240 个嵌套引用的合成压力样例，B/C 请求分别为 2,670,764/2,653,555 字节。每处引用除文字目标外另有类型目标，以便空标签仍可使用非空证据；因此目标目录带来额外开销。它们是有限样例，**不是** 4 MiB 全域上界证明。解析树深度、目标目录、中间副本、最大转义与 128,000 字节原始 payload 仍须推导和验证。当前 `bytes + 8192` 只表示本地预约数字，不能保证服务端 token 或费用。完整真实控制器、受控响应/用量、复审和独立评估仍未交付；不得发送真实 Provider 请求或提前冻结/选样。
