# 小型对照评估协议 r01

## 样本与独立真值

开发矩阵固定12类：空链单插/空链多插/非空链/重复值/负值/反序自环/非空反序/丢返回值/未初始化next/全分配失败/中途失败/未知规格拒绝。examples.json为手算种子，不是独立评估集；旧D02仅作开发回归，H01–H08禁止读取。

独立评估每臂14槽：normal、reversed_assignment、discard_return、uninitialized_next、allocation_failure各2槽（共10支持）；未知变体、过长序列、任意代码、未初始化精确结果问题各1槽（共4拒绝）。两个臂使用同一槽规格与真实教学目标。评估者在候选代码/Prompt冻结后、任何真实调用前，独立选参数、手算完整预期及逐项核对，保存受控位置并登记SHA；不由待测引擎或生成器提供真值。独立参数不反馈开发调优。开发者只能读取调度所需输入，真值不给生成/审核模型。评估者发现引擎真值冲突立即停止，原样交接，不能运行中改正确答案。

真实入口拒绝缺少准确候选SHA、独立真值签核姓名/时间/digest及执行授权。人工核定若由助手代劳必须如实标为assistant，而不能记作human；缺乏任务要求的人工核定时blocked，不伪造标签。T066批准只批准流程，不代签尚不存在的独立材料。

## 对照与调用

B基线：同一目标/规格输入，以同一生成模型一次返回完整代码/题目/答案/actions，不提供引擎输出；保留原生产教学要求与安全检查，程序用独立参考对照。C协作：同目标输入与允许规格池，规划/选择一次，内容一次，动作由程序生成；选择结果必须等于该槽要求的规格，否则该槽失败。两个臂同一审核模型、参数、目标和最终审核标准；协作能读取轨迹是干预变量，不能伪装为输入完全相同。

每个支持槽基线最多4HTTP（生成、审核、一次内容修复、重审），协作最多5HTTP（规划/选择、内容、审核、一次内容修复、重审）；10×(4+5)=90 HTTP上限。4拒绝槽/臂共8槽在本地拒绝，0HTTP。基线修复可改其完整候选；协作只改内容，差异单独披露，不将修复收益归因于纯角色数。每槽仅一次生成尝试，非pass流程保留；不做网络重试/回退/未知重发。若服务实际接口另需计数HTTP，该数必须加入T069准确预算，不突破90后暗补。

运行交错按槽顺序B,C，然后下一槽，顺序效应披露；不宣称随机盲测。准确模型ID、Provider、参数、Prompt/兼容门禁、费率和币种、token/金额上限、单请求及总时间、外发材料在T069执行包另行锁定；本提案未授真实额度。历史费用例外不继承。无获准同条件基线只可报告绝对结果，不报告提升率。

## 指标与采纳门槛

- 首轮角色Schema成功率：首轮通过各自严格payload Schema的实际模型调用/首轮实际调用；另报计划角色调用中未运行数，不把程序装配字段记成模型成功。
- 首次完整结构成功：无需修复的完整候选结构通过/10支持槽；缺失、失败、未运行均不进入分子。两臂的模型任务不同，连同各payload复杂度披露。
- 首次端到端成功与修复后成功：完整结构、独立事实/答案、接口、动作及原教学标准全部通过的槽/10支持槽，分别报告首次/最终，不能把模型pass替代独立核对。
- 严重事实/答案错误：逐槽与逐题两个分母；漏检=独立确认严重且模型未报严重/独立严重总数，误报=独立确认无严重但模型报严重/独立无严重总数；分母0写N/A。额外构造的审核故障Mock不混入真实召回分母。
- 未知拒绝率=正确拒绝/4拒绝槽；支持范围内错误拒绝/10另列；indeterminate被正确说明可成功，编造精确值算严重错误。
- 修复收益按“首轮未成功且允许一次普通教学修复”的实际槽报告转成功数和总数；首次严重错误不允许修复后抹除。
- 动作完整率/降级数按10槽；每槽耗时、实际请求、输入/输出/推理用量、币种费用、缺失用量单列。只报全部样本原值、median/max，不推断稳定P95；停止/取消不作为低时延成功。

仅在C全部10支持槽最终成功、至少9首次成功、4/4拒绝正确、0严重错误、0影响题意的动作降级，且记录完整，才可建议继续更大独立评估。B同口径报告；不要求为证明改善而让B失败。样本小且缺少“只用引擎不拆角色”的消融，无法区分确定性引擎与角色拆分贡献，不能宣称多Agent提高可靠性或正式98/95/90验收通过。

## 停止与交接

确认任何严重事实/答案错误、安全/隐私问题、协议异常/来源不符、unknown发送、硬预算/时钟耗尽即全批停止；普通教学revise仅允许上述一次修复，unknown停。未运行槽保留完整分母和原因。失败不补样、不重启、不换模型、不改规则。停止后保留已完成原件、所有修复/审核及缺失清单，T069可因证据采集合规完成但质量失败，T070仍独立给出采用/修改后复评/停止建议，T038不变。
