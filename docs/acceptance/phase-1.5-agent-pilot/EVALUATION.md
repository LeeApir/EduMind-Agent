## B/C可比性与因果范围

冻结设计为相同14槽/学习目标、同一生成模型及参数、同一审核模型及原标准，并固定每槽B后C。实际只获得B的一次接口拒绝，没有成功B/C配对；因此不计算改善率、效应量、相对可靠性或相对成本。

即使将来有输出，以下差异也必须披露：

- C内容读取引擎准确代码/轨迹/观察，B生成只读取固定语义和规格；这是干预变量，不是完全相同输入。
- B一次返回完整内容/代码/答案/actions，C规划/内容Schema负担不同，代码/答案/动作由程序装配；结构率不能混入程序字段。
- B允许一次全候选普通教学修复，C仅修内容；两者修复空间不同。
- 固定B→C顺序存在顺序效应；本次正因首B接口拒绝，全部C被停止策略截断。
- 没有“只用确定性引擎但不拆角色”的消融，不能将引擎的共源状态/答案约束收益归因为角色数量。

因此本次既不能证明多Agent优于单次生成，也不能证明多Agent或所选模型教学更差。确定性引擎、内容/动作分离和硬停止门禁是已交付的工程候选属性；它们不是本次真实教学效果已通过的结论。
