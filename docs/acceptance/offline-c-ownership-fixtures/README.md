# T068 固定所有权驱动与受控反例

本目录为原准入包的独立扩展，不修改原封存C、旧驱动或旧准入manifest。manifest绑定2个新驱动和3个最小派生反例；review-registry记录维护者对准确字节、接口和事件的技术审阅，未授予课程人工签核。

驱动include原字节/函数片段，覆盖固定从空表插1、2、3的正常及malloc1/2/3失败；按真实节点值/next/计数断言并输出逐分配/逐释放事件。函数驱动直接检查每步caller head与返回/Node**更新；原main保持运行原函数体，通过下一次分配/首次释放前的实际allocation-root快照、原打印和全部分配释放验证，不把该根冒称局部head观测。原main返回后的局部置空不可观测，结果显式null。OM驱动中类型别名只属独立环境，原main依然不可编译。

异常终止保留已发事件和诊断，不由UB推导固定数值、未发最终汇总或“已全部释放”。正常完成须三步状态、精确值序/长度、每个slot释放一次、live0、空释放安全及准确输出同时成立。LSan始终未运行。

丢链、重复free、忽略main接收返回值只写入三份单独派生文件；检查器复算每一处准许替换并核对摘要，原件永不修复。宿主只允许枚举case，不能提交新源码或flags。

运行时包摘要为 `SHA256(sorted JSON {base:原manifestSHA, ownership:扩展manifestSHA})`；review_registry同样组合两个审阅登记SHA。驱动和派生source另绑定各自原字节SHA。所有组合都保留两个原始登记供复核，结果不是“原程序通过”的替代标签。
