## 计数口径

先固定计数单位再汇总。同一可见块中，关于同一对象、条件、时点和属性的同义重复合为一项，并标明原文位置。不同块、不同帧或不同题解的独立可见陈述各记一项，便于定位单独错绑。播放器重复展示同一代码和同一帧字段只算一次。数组或按时间排列的一条同属性序列作为一个整体，逐值核对，任一值错则该项错。返回值、栈顶、逻辑栈、底层槽、调用者 `value` 和新出栈值属于不同属性。事实表每行一项，帧表每个带判定的属性格一项。界面控件、标题、输入指令和事实 ID 本身不进入事实分母。题目中可核实的条件、选项和时点进入事实表，输入要求与实际判卷的符合性按六题单独统计。
