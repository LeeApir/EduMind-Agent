## 样本和比较

依[既定评估协议](../phase-1.5-agent-pilot/contract-r01/EVALUATION-PROTOCOL.md)，候选、真实执行器及策略全部冻结后，由独立评估助手选择并手算：每臂各 10 个支持槽，正常、反序自环、丢弃返回值、未初始化 next、分配失败各 2；另各 4 个本地拒绝槽，分别为未知变体、过长序列、任意代码、未知指针的精确结果。两臂配对同槽规格与目标，按每槽 B、C 顺序执行；不是随机或盲测。独立答案保存在受控位置并按摘要登记，不发送给模型，不用于修改已冻结候选；如发现与引擎冲突即停止。助手核定如实标为 assistant，不记为人工。目前尚未选择正式样本。

B 由模型独立生成代码、答案和动作，程序不得代填正确结果；C 可用引擎给出的事实和轨迹，程序生成动作。两臂共享教学规则和审核标准，但输入和修复权限不同；不能把差异归因于角色数。真实样本的最终结论需独立逐项复核，模型审核意见不能代替真值或教学审核。

## 判断、停止和交接

按原协议报告各臂首轮及最终成功、拒绝、严重错误、动作、真实耗时和请求用量，保留未运行槽在分母中。C 须最终 10/10、首次至少 9/10、拒绝 4/4、零严重错误及零影响题意的动作降级，才能建议更大独立评估；B 同口径报告，不声称正式验收通过。

任何严重事实或答案错误、安全/隐私事件、协议异常、来源不符、未知发送、预算或时钟耗尽即停；unknown 停止，不重试、补样、回退或修改规则。保留原始请求响应、每次版本、失败与未运行原因，供独立评估。上游硬限、实际计费及中转留存不能由离线测试确认。
