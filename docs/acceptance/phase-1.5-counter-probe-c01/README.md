## 官方语义与仍缺的服务商证据

OpenAI 的计数接口针对同一 Responses 输入返回完整输入计数，包含消息结构、Schema 等开销；`max_output_tokens` 限制全部生成 token，包含不可见与推理 token，最小值16。该语义用于设计对照，不能当作 cbbb.fun 已正确实现的证明。[官方计数说明](https://developers.openai.com/api/docs/guides/token-counting)、[创建响应参数](https://developers.openai.com/api/reference/python/resources/responses/methods/create)。

仍需核对：实际两端对应的型号／tokenizer 映射；最终送入模型的上下文和所有追加来源；计数是否覆盖追加上下文／Schema；输出限制传到上游的准确字段及强制语义；两接口收费口径。请求服务商资料的询问只展示给用户，本轮未代发消息。
