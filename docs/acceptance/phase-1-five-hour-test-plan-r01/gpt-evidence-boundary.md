# GPT评分的证据边界（冻结契约）

此包是4份完整生成输入及12份完整审核材料的准备包。真实Provider调用授权为0，所有实际结果null；不创建真实运行T0，不沿用旧授权或human confirmation。生成目标的学生输出在实际获准运行前不存在，不能把验收清单或脚本化计划当作已经生成的课程。实际运行仍须按README计入准备/校验时间，不因本次预备文件存在而省略执行前核验或排除额外执行器开发。

## 评分主体和标签

- 标签由Codex GPT编制，依据封存材料的静态程序事实与数学推演；不是独立真人真值，不是双盲评分，也不证明GPT与被测模型的错误相互独立。
- 本包使用新写材料，但沿用历史诊断结构。换数字或换名称不等于独立新例；case文件披露这种关系。历史失败栈样本不在本包，不用新结果替换它。
- 评测者须记录实际可获得的身份/模型/配置。客户端不暴露精确model ID时记录null和原因，不能把被测Luna ID冒充评测者ID，也不能编造自己的推理档位。
- 预期标签只供评分者使用，不进入候选模型的Prompt/请求。所有原始候选和回答先封存再评分，标签不能根据结果修改。R03/R04的资源级允许路由集合事前固定为revise/reject；这是现有契约允许的集合，不是运行后放宽。
- 不新增项目judge API；交互式测试者GPT读取本地证据。若后续另需模型评测调用，须先明确该调用的材料/路由及归属，不得暗中调用或把它排除基础测试计数。

## 证据能支持什么

| 证据 | 可支持 | 不可外推 |
| --- | --- | --- |
| JSON Schema/摘要/实际请求与回执 | 字段合法、完整性、来源/版本与出站参数绑定 | 教学正确、服务端实际内部high推理力度 |
| 具体算术与静态代码推演 | 在明确前提下的返回值、边界、状态及可达路径 | 代码已编译/运行、未检查路径绝对安全 |
| 已批准固定C样本的真实编译/执行 | 该准确源码/驱动/工具链/输入的观察 | 本次新生成课程代码也可运行或安全 |
| 实际PG断言/浏览器观察 | 精确环境下的状态、隔离、原子版本读写 | 模型语义质量或总体性能/P95 |
| GPT解释与判定 | 有引用和推演过程的受限评分意见 | 真人审批、独立客观真值、总体错误频率保证 |

所有本包静态新写C代码与后续新生成C代码，除非另有范围内的准确授权及实际适用证据，均记录“未实际编译/执行”。不得运行本包越界代码来获得所谓确定返回值，也不得扩展固定C执行器到任意新代码。确定性检查失败优先于GPT叙述；证据冲突或无法判断记unresolved，不能推测通过。

## 核对全部断言和引用

1. A组须保存初候选、所有中间审核/修正及最终版本；不能只看最后一次pass。U/R组保存整份实际回答。
2. 每份审核的每条condition/counterexample、impact和unresolved均建立逐项检查记录，包括核心拒绝正确时的附带建议。实际回答里的每个finding锚点分别核对。
3. 锚点必须在实际请求目录中，resource_id、内容digest、JSON Pointer与UTF-8区间逐项一致；引用文本只能支持它实际包含的命题，不能借邻近字段。没有finding引用只代表本例无引用待核，不宣称引用能力验证通过。
4. “无法保证P”不能推出“非P”。UB不能推出确定数值、必然崩溃或必然不等于某值。若出现修改建议，具体执行其语义推演；例如递减后再次top-1会取错元素，不能因主要reject正确而忽略。
5. 区分用户要求、计划承诺、参考背景。分散在代码步骤/题目解析中的教学支持计入学生交付；内部计划轨迹不计。未承诺的媒体或教学时序不能变成必达要求。
6. 严重错误被具体检出与完整审核质量分开计分。expected needs_human对照符合标签可作为“测试项符合预期”，课程状态仍待审，不能写成课程发布pass。

## 记录和结果边界

[evaluation.schema.json](evaluation.schema.json)固定逐例格式，[evaluation-template.json](evaluation-template.json)仅是全未运行模板。真实评测填写case/label摘要、实际请求/回答证据路径、评测者、逐项主张与引用、静态或机械证据、路由/传播、用量、未决和最终状态。示例或模板不能充当实际结果。

完整质量pass要求技术、核心预期、全部断言/引用均通过且无未决；任何实质附带错误都使该项完整质量fail。本基础包最多1/16项低风险附带错误的总体容许政策不改变该单项失败，不允许写16/16全通过。缺结果、不确定、未完成均不计通过。

U/R只是独立审核调用，不创建课程，`actual.course_state`强制null。U04/U05输出needs_human而符合冻结预期时，测试项可以符合预期，但不得填课程completed或产品人工批准；其具体教学缺口写在封存原回答与评分理由中，不等于评分者自己仍无法判断。A项只有实际自动completed且内容合格才能计自动成功，待审不得代填completed。A的输入/教学绑定快照是离线fixture，不是线上入口实际解析的观察；执行时仍须核对真实原文解析/路径/节点绑定，不能硬塞预期node后声称已测解析。

发现错误意见已进入修正，按实际传播记录红停。评分在目标完成后进行，不能声称提前拦截，也不能掩盖同一操作中已经发生的后续请求。停止影响后续新目标/槽，原操作内已发请求全部计数。GPT不给生成器补提示、改内容或改路由；评分记录不写产品人工批准，不改原始模型审核。

本轮只能报告“受限小规模、GPT评分条件下的观察”。没有自然修正就报告未观察到，不追加样本；没有真人审批就不声称完成真人发布流程。原100目标/98%/95%/90%及完整T041、P1退出条件不由本包或16项结果自动替代；PRD/ADR及T040受限完成条件尚须在执行前同步批准。
