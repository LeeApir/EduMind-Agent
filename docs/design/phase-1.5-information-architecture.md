# Phase 1.5 信息架构与主要页面流程 v0.1

> 2026-10-21，设计初稿。依据已确认的A—F方向，供主要页面视觉设计使用；不是已实现页面或已冻结API。

## 1. 全局结构

桌面建议使用稳定侧导航和页面标题区。一级区域为学习、图谱与路径、画像与掌握度、学习记录；设置位于导航底部，模型设置在其中直接可达。

移动端采用同一功能命名，通过收起的导航访问完整模块；课程正文占据主要空间，不照搬桌面三栏。不把五个入口全部塞入课程页。

登录与权限沿用现有能力，本阶段不设计新账号体系。未实现的Phase 2模块不显示入口或伪造空页面。

## 2. 主要页面清单

| 页面 | 首要操作 | 内容顺序 | 离开后的去向 |
| --- | --- | --- | --- |
| 学习首页 | 输入目标开始生成 | 目标输入／可选偏好、继续学习、我的课程、签核课程 | 生成进度或指定课程 |
| 生成与大纲 | 看懂课程方向，必要时调整 | 原始目标、课程大纲、当前进度、停止或调整 | 首场景就绪后进入课堂 |
| 课程学习 | 学习当前场景 | 课程标题与类型、进度、当前内容、练习／提问 | 下一场景或学习首页 |
| 图谱与路径 | 理解下一步建议 | 当前目标、推荐理由、路径列表、图谱及节点详情 | 可用课程或带目标的生成入口 |
| 画像与掌握度 | 理解与纠正个人信息 | 目标与偏好、证据说明、掌握度、未知项 | 相关学习记录或课程 |
| 学习记录 | 找回学习现场 | 课程记录、练习记录、准确版本与状态 | 恢复课程或查看作答 |
| 模型设置 | 选择可用能力与连接 | 当前配置、连接与能力状态、凭据操作 | 返回原页面，不自动重启生成 |

“课程类型”“生成进度”“质量提示”是三个维度。例如AI草稿可以已生成完成，签核课程也可以尚未学完；不得合成一个含混的“完成”标签。

## 3. 学习首页

目标输入是页面主要操作。时长、难度、代码语言放在可展开偏好中，未知画像不要求补齐。首次访问没有记录时，展示真实示例输入及签核课程，不展示虚构掌握度。

继续学习卡片显示课程名称、最近位置和实际生成状态。签核课程与AI草稿有简短标识，不用警告弹窗阻止每次打开草稿。

模型未配置或不可用时说明具体原因，并提供模型设置入口；用户写下的目标须保留，配置返回后不丢失，也不擅自发起调用。

## 4. 生成与大纲页面

页面用自然语言显示“准备课程”“生成第一节”等过程，不展示hash、内部任务ID或审核字段。大纲默认自动继续；用户主动选择调整时，须明确暂停点和影响的内容，避免编辑与生成竞态。

仅在真实需求歧义时显示澄清问题，保留原目标和用户补充。图谱未命中不是澄清理由。

首场景就绪后进入课程；其余章节显示真实状态。若用户正在调整大纲，不强制跳转打断编辑。具体转场交互在视觉原型中验证。

## 5. 课程学习页面

桌面建议：左侧场景目录，中间内容，右侧按需展开的提问／补充解释。移动端目录使用抽屉，提问使用独立面板；返回时保留正文位置。

内容区域随场景类型变化：

- 讲解：分段呈现重点，导师动作与当前内容对应。
- 代码：语法高亮、当前行定位、变量与结构状态对照；没有执行能力时不显示可点击的运行按钮。
- 练习：题干、选项或现有输入控件、提交与反馈；显示答案修订，不把反馈包装成可靠掌握度证明。
- 可视化：步骤、播放／暂停、上一步／下一步与当前状态说明；静态替代与生成中动画不混同。

常用操作限于继续学习、提问、补充解释及局部重新生成。高级信息收起，避免将学习页做成运维控制台。

已完成场景可以继续阅读。一个场景失败时显示局部失败和可执行操作，依赖场景显示为何暂不可用，不能隐藏缺章后宣布整课成功。

## 6. 修订与作答

学生针对具体内容反馈问题，定位到准确课程／场景版本。重新生成期间旧内容如何保留或禁用，取决于是否已确认存在缺陷：普通优化可保留旧版，明确错误不可继续当作正确答案使用。

修订完成后显示内容已更新。旧作答与旧题保持关联，不套用新题答案重评分；如需撤销旧评分或掌握度贡献，展示原因并保留记录。

需要依赖重建时明确告知范围，不把“重新解释本段”偷偷扩大为整课重生成。成本与状态由后续契约约束。

## 7. 图谱、画像和记录的联动

图谱同时提供列表视图，避免只有复杂画布可操作。节点标明是否有签核课程、可否按目标生成，以及掌握度是未知还是有证据；这些状态独立显示。

自由课程可能没有可靠图谱映射。页面仍可学习和留记录，但不显示伪造节点或掌握度变化。推荐以建议呈现，不覆盖用户当前明确目标。

画像页区分学生自述、真实作答证据和未知项；学习记录页负责追溯具体课程与题目，不预先实现报告分析或新的画像评分算法。

## 8. 共用状态与视觉设计约束

| 情况 | 必须表达 | 避免 |
| --- | --- | --- |
| 加载 | 正在读取还是正在生成，已有内容是否可用 | 无期限转圈且无法判断状态 |
| 空数据 | 尚无课程、作答或证据，下一步可做什么 | 展示模拟成绩或虚构进度 |
| 失败 | 影响范围、已有内容、是否可重试 | 所有故障都提示“稍后再试” |
| 无权限／失效 | 不可访问或版本已失效 | 泄露其他用户内容或自动换版本 |
| 草稿 | AI生成、可反馈、与签核课程有区别 | 标成已审核或反复弹窗打断 |
| 已确认错误 | 哪部分暂停、修订状态 | 仅加免责声明继续判错学生 |

视觉稿需覆盖桌面和窄屏，统一字体层级、间距、颜色语义、卡片、按钮和焦点。长代码局部滚动，页面本身不横向溢出；状态不得只依赖颜色。动画尊重减少动态效果设置。

## 9. 下一份设计材料应展示什么

先呈现学习首页、生成大纲、课程学习的关键页面，验证一条完整旅程；随后补齐其余主要页面，全部主要页面设计完成后再实施前端改造。原型使用明确标识的示例内容，不冒充真实后端或模型结果。

视觉设计阶段需选择具体排版、配色与组件，不在本轮用文字宣称视觉设计完成。后续模块仅在设计结构上预留接入位置，不绘制成当前可用入口。
