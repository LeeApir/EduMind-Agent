## 核对旅程

1. 首页输入目标进入大纲；调整会停止模拟自动进入，需确认新操作影响。大纲状态可切首场景就绪、澄清、未知调用结果、已停止。
2. 课堂用“下一步”观察头插，代码高亮对应状态。短文本题组的部分作答不显示答案，完整组给暂定比较，不写正式掌握度。
3. “调整这节”展示范围与旧版保留，确认后模拟修订，全部就绪再切版本2并清空旧题输入；反馈入口绑定当前场景/版本。
4. 课内状态可预览生成期间禁用导师、题组停用与失效导师回复。提问先确认辅助学习影响，仅显示固定回复。
5. 图谱可切关系/列表、选择节点、带目标回首页；不自动发起生成。
6. 画像区分自述/有效证据/未知，自述编辑仅改本页来源；记录可筛选、恢复只读、查看暂定与撤销反馈，补生成另确认。
7. 模型设置说明下一次操作生效；原型检查仍显示未验证，凭据输入禁用，不读取/发送任何密钥。

## 视觉与范围

延续深蓝、青绿、浅冷灰和系统中文宋体标题/无衬线正文，具体见[视觉规范](../../phase-1.5-visual-spec.md)。关系、来源、版本是主要信息，Phase2模块没有可用入口。

所有内容固定为本地示例，不请求网络、调用Provider、存浏览器持久数据或真实用户信息。刷新重置，不能验收真实持久恢复；课程数据/连接状态/作答与记录都不是后端返回。个别章节复用头插演示，第3节保留预设故障；没有暗示模型按输入生成了新内容。
