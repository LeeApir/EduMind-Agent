    一次头插，两个指针动作

    先让新结点接住原来的链表，再把 head 移向新结点。

    在链表头部插入 8状态演示 · 非代码执行
    head↓
    8next
    →
    3next
    →
    NULL
    尚未连接
    准备：head 指向 3，新结点 n 的 data 为 8。
    启
    为什么先连接，再移动 head？

    旧的 head 是找到原链表的入口。先把它交给 n->next，再更新 head，就能保住原来的结点。

    C · 已有有效结点的指针连接片段
    1// head 指向有效的原链表，n 指向独立有效的新结点2n->data = 8;3n->next = head;4head = n;

    这里演示同一作用域中的指针更新；不包含内存分配、函数传参或完整程序。
