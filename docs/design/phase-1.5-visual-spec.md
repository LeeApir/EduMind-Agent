# Phase 1.5 全站视觉与交互规范 v1

2026-10-22，T004待确认设计。复用已确认的三页学习原型，补齐全部七个主要页面；不改生产Vue页面或后端。具体权限/生成/练习规则沿ADR-0024/0025/0026准确批准。

## 1. 视觉方向

延续深蓝正文、青绿操作与浅冷灰画布。学习内容保持主位置，证据来源/生成状态紧靠对应对象；不使用虚构总分、排名、报告或装饰性增长指标。图谱的关联结构、原始作答和指针步骤承担图形表达，不引入外部图片/字体请求。

| Token | 值 | 用途 |
| --- | --- | --- |
| ink | #19334a | 标题、正文、重要标签 |
| muted | #607283 | 来源、辅助说明 |
| accent / accent-dark | #14756c / #105c55 | 当前项、主要动作、按钮 |
| accent-soft | #e5f2ee | 当前选择和说明背景 |
| canvas / surface / line | #f5f7fa / #ffffff / #dce4e9 | 画布、内容层与分隔 |
| warning / warning-soft | #81531c / #fff3df | 未验证、暂停、评分撤销；同时写出文字 |

标题使用系统宋体衬线（Songti SC/STSong）保持原三页方向，正文PingFang SC/Microsoft YaHei/system-ui；代码SFMono-Regular/Consolas。主要页面标题桌面34px、小屏29px，卡片标题19–21px，新页面正文13–14px、辅助11–12px；学习首页保留原展示标题。常用间距8/16/24/32px，内容面板边框1px、圆角12px；不在每张卡片叠加装饰性阴影。

## 2. 七页结构与关键动作

| 页面 | 组成 | 必须可核对的动作 |
| --- | --- | --- |
| 学习首页 | 目标输入、可展开偏好、继续学习、签核课程样式 | 进入大纲、恢复课程；输入只用于原型文字 |
| 生成大纲 | 目标来源、大纲、首场景进度、调整/停止 | 自动继续；调整先停止旧模拟，再确认新操作；澄清/结果未知/已停止状态 |
| 课程学习 | 场景目录、正文/代码/短文本题组、按需导师 | 指针步骤/代码定位、部分与完整暂定反馈、题组停用、反馈位置、修订集合就绪后切换 |
| 图谱路径 | 关联图与列表、目标、节点详情、推荐依据 | 选择节点、切列表、带入新目标，不覆盖已有学习目标而自动生成 |
| 画像掌握度 | 自述与来源、有效证据、未知字段 | 本页纠正自述；查看无分数原因及记录依据，不把自述写成成绩 |
| 学习记录 | 课程/作答/修订分类、准确版本、恢复入口 | 筛选、恢复只读、显式补生成确认、查看暂定/撤销反馈；旧原始作答可保留 |
| 模型设置 | 连接/能力/凭据状态、任务偏好、配置生效说明 | 保存仅影响下次操作；原型检查不返回真实成功，密钥输入禁用，移除仅确认样式 |

主导航为学习、图谱与路径、画像与掌握度、学习记录，模型设置在底部。学习内部包含首页/大纲/课堂。顶端“设计预览”七页导航和状态选择器只用于核对设计，不作为生产导航交付。Phase 2题库、真并行辩论、教材RAG和学习报告没有可用入口。

## 3. 状态规范

颜色不能独自表达状态，始终有标题和说明。课程类型、生成进度、学习进度、质量/证据可靠性分别显示，不合成“完成”标签。

| 状态 | 表达与行为 |
| --- | --- |
| 加载 | 明确正在读取既有记录，不能称为生成；不自动增加调用 |
| 空数据 | 没有课程/作答/证据时如实说明；不得填示例成绩。原型状态控件只切换固定画面 |
| 网络失败 | 说明没有读到记录、已有内容保留，重新读取不重新生成 |
| 无权限 | 统一不可访问，不泄露另一用户内容或存在性 |
| 失效版本 | 不自动回退最新；自己的原始作答可从记录查看，错误答案不展示 |
| AI草稿 | 标识可学但可能有误；暂定比较不是可靠掌握度 |
| 已确认题目错误 | 停用该题组提交与错误反馈，保留无关讲解/代码 |
| 导师回复失效 | 正文不展示，保留问题与原因，不用旧回复充当新版本解释 |
| 调用结果未知 | 后续调用暂停，不自动重试，已有内容保留，需可靠确认 |

原型右上“状态预览”可在每页切读取中/空/失败/无权限/失效；这是一组共用状态组件设计。课堂和大纲另有局部状态选择器，属于设计审阅控件而非真实操作。

## 4. 调整、恢复、修订与反馈

大纲调整期间停止模拟自动跳转，并要求确认全课影响；它不实际生成新大纲。局部修订弹窗列出影响范围、保留旧版与评分撤销规则，必须填写意图并确认；开始后仍显示旧版本，点击“全部修订就绪”才切到示例版本2，清空旧题输入，不拿新题答案判旧作答。

“恢复阅读”只打开准确位置，页面说明没有重生成；“继续生成缺失内容”另外显示新操作与预算确认样式。原型刷新重置全部示例，不能以它证明持久恢复已实现。

内容反馈显示当前场景/版本，只表示待核实问题。新课堂题型按T003使用2题短文本组：空输入拒绝、部分作答不展示答案、完整组只显示暂定比较；本页不保存真实作答或改变掌握度。

导师请求先确认对练习独立性的影响。生成仍活动时禁用发送，提示等待或主动停止；原型不自动停止生成。导师回复为固定示例，没有模型调用。未知或失效上下文下不展示旧回复。

## 5. 响应式与可访问性

宽屏采用稳定侧导航，四个新页面内容＋说明栏；≤1200px新区域合并单列；≤850px主导航使用可关闭面板；≤620px课堂目录折叠、导师按需面板，表单与记录单列。代码区域允许独立滚动，页面不能横向溢出。浮动提问按钮已改为正文之后，不覆盖演示控制。

键盘Tab/Shift+Tab可以完成操作，菜单和弹窗保持焦点回绕；Escape关闭后回到触发按钮。导航切页聚焦主要标题，提供“跳到主要内容”；表单有显式标签、有效焦点描边。确认框不是仅颜色提示。系统减少动效设置会去掉动画/过渡。

浏览器检查覆盖42组页面宽度（1440/1280/1024/768/390/320 × 七页）、70组通用状态（1440/320 × 七页 × 五状态），以及主要交互、键盘与减少动效。不是完整WCAG审计，不代表所有浏览器/读屏器验收。

## 6. 示例与真实能力边界

全站固定链表示例，图谱、签核记录、自述、连接都标“示例”。关系图用于说明布局与关联方向，不替代实际版本化知识图谱查询；没有真实模型、账号资料、掌握度或凭据。设置页按钮不会发请求，暂未真实验证的Provider不标为通过。全部状态存在浏览器内存，无fetch/localStorage；不得将静态原型的成功当成业务E2E、质量或持久性成绩。
