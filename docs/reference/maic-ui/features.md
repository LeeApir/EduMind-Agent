# MAIC-UI — 核心功能

## 功能矩阵

### 1. PDF 智能解析

```
PDF 上传 → 文本提取 → 结构识别 → 内容分析 → 多模态生成
```

- 自动识别章节/段落结构
- 提取关键概念 + 学习目标
- 识别程序性知识（步骤/流程/操作方法）
- 支持双语 (中文/英文) 内容分析

### 2. 个性化引擎

| 维度 | 调整方式 |
|------|---------|
| 年级适应 | 调整语言复杂度 (K-12) |
| 兴趣匹配 | 用兴趣领域替换通用案例 |
| 文化适配 | 根据语言/地区调整语境 |
| 进度调整 | 根据测验表现调整难度 |

### 3. 五种学习模态详解

#### 模态 1: 沉浸式文本 (Immersive Text)
- 交互式课本风格
- 内嵌测验题目
- AI 生成插图
- 可展开的拓展解释

#### 模态 2: 幻灯片 + 旁白 (Slides & Narration)
- 类似 PPT 的演示格式
- AI 语音旁白（可选）
- 逐页推进的讲解节奏

#### 模态 3: 音频课程 (Audio Lessons)
- 模拟师生对话模式
- 口语化、自然的教学语言
- 对话脚本由 AI 生成

#### 模态 4: 思维导图 (Mind Maps)
- 层级化知识结构可视化
- 可展开/折叠节点
- 概念间关联展示

#### 模态 5: 测验评估 (Assessments)
- 基于 Bloom 认知分类
- 多题型: 单选/判断/拖拽
- 自动反馈: 强项 + 提升建议
- 进度追踪

### 4. 交互式 HTML 生成

MAIC-UI 的核心差异化能力，将抽象知识转化为可操作的交互界面：

#### Fast Mode (一阶段生成)
- 输入: 内容分析 + 用户画像
- 输出: 完整 HTML + 交互元素 + 元数据
- 耗时: ~30 秒
- 适用: 简单概念、快速预览

#### Heavy Mode (两阶段生成)
- 阶段 1 — 内容对齐的交互式模拟:
  - 左侧: 过程步骤展示
  - 右侧: Canvas/SVG 交互模拟
  - 验证: 交互功能可用性

- 阶段 2 — 布局精修:
  - 视觉风格打磨
  - 响应式适配
  - 功能完整性验证

### 5. 教学场景覆盖

| 场景 | 描述 | 前端页面 |
|------|------|---------|
| 课堂引入 | 吸引注意力的互动页 | Lesson Introduction |
| 知识讲解 | 抽象概念可视化 | Knowledge Explanation |
| 实验模拟 | 替代真实实验 | Experiment Simulation |
| 课后巩固 | 交互式练习 | Consolidation |

### 6. 模板系统

- Demo 模板库 (预生成的教学页面)
- 模板注册 + 定制
- 支持网站页面作为模板源
- 批量导入模板
