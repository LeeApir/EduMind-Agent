# OpenMAIC — 核心功能

## 功能矩阵

### 1. 课堂场景类型

| 类型 | 描述 | EduMind 对应 |
|------|------|-------------|
| **Slides** | AI 生成演示幻灯片，含文本、图片、代码块 | DocAgent |
| **Quiz** | 交互式测验，支持单选/多选/判断/填空 | QuizAgent |
| **Interactive HTML** | 3D 可视化、物理模拟、游戏、思维导图 | — (差异化方向) |
| **PBL** | 项目制学习活动，AI 引导讨论 | TutorAgent |

### 2. 多智能体课堂

```
课堂参与者:
├── AI 教师 (Teacher Agent)
│   ├── 语音讲解 (TTS，多音色)
│   ├── 白板绘图 (Canvas)
│   └── 课堂控制 (切换场景、发起提问)
├── AI 同学 A/B/C (Student Agents)
│   ├── 提问、讨论
│   ├── 代表不同理解水平
│   └── 语音互动
└── 真人学生
    ├── 聊天框互动
    ├── 测验作答
    └── 举手/响应
```

**Agent 画像结构** (agent-profiles API 输出):
```typescript
{
  name: string;          // "张老师" / "小明" / "小红"
  role: "teacher" | "student";
  personality: string;   // 性格描述
  avatar: string;        // 头像 URL/emoji
  speakingStyle: string; // 说话风格
  ttsVoice: string;      // TTS 音色 ID
}
```

### 3. 交互模式 (v0.2.0+)

| 交互模式 | 描述 | 技术实现 |
|---------|------|---------|
| **3D 可视化** | 分子结构、几何体、地形 | Three.js / WebGL |
| **模拟实验** | 物理、化学、生物实验模拟 | Canvas + JS 物理引擎 |
| **互动游戏** | 单词拼写、数学闯关 | HTML5 Game |
| **思维导图** | 交互式知识图谱可视化 | D3.js / SVG |
| **在线编程** | 代码编辑器 + 运行沙箱 | Monaco Editor |

### 4. 白板系统

AI Agent 可以实时在白板上：
- 绘制图表/示意图
- 书写公式 (LaTeX → 渲染)
- 标注重点
- 逐步展示解题过程

### 5. TTS 语音系统

- **引擎**: VoxCPM2 (v0.2.1+)
- **能力**: 音色克隆、自动生成音色
- **多语音**: 支持多角色不同音色
- **ASR**: Azure STT / 浏览器内置
- **讨论语音**: AI 同学之间可以语音讨论

### 6. 导出功能

| 格式 | 内容 | 用途 |
|------|------|------|
| `.pptx` | 可编辑幻灯片 | 教师复用/修改 |
| `.html` | 交互式页面 (离线可用) | 学生课后自学 |
| `.zip` | 完整课堂包 | 导入/导出迁移 |

### 7. MAIC Editor (v0.2.2, 实验性)

轻量级课堂编辑器：
- 编辑生成的幻灯片内容
- 生成前可编辑大纲
- Pro Mode：场景级编辑

### 8. OpenClaw 集成

通过聊天应用生成课堂：
- 飞书 / Slack / Discord / Telegram 等 20+ 平台
- 两种模式：托管（无需本地部署）/ 本地
- 指令式操作：告诉 AI 助手 "教我量子物理"
