## 预先固定的独立检查

- **完整性与一致性**：讲解覆盖头指针、节点、头插过程；完整 C 程序含结构体、头插/遍历/释放函数与 main；从空表依次插入 1、2、3；输出顺序应为 3、2、1（格式按原程序）；三题各有答案解析，全部使用相同示例。
- **分配失败路径**：检查 malloc 返回 NULL 是否先于解引用处理；原有链表所有权是否保持；若程序提前退出，已分配节点是否释放。返回旧 head、状态码、二级指针等正确接口均可，不预定唯一实现。
- **调用者赋值**：按实际函数签名检查 head 是否正确更新；若函数返回新 head，核对调用者是否接收，以及失败返回值是否会覆盖并丢失旧链；若使用 Node **，检查调用参数与失败时的所有权。
- **资源释放**：正常/失败路径全部节点恰好释放一次；释放前保存 next，避免释放后读取；不得丢链、重复释放或在释放后使用。
- **验证**：保存编译命令、警告、退出码与标准输出；在工具可用时运行 AddressSanitizer/UndefinedBehaviorSanitizer，以及 malloc 首次、第二次、第三次失败的独立故障注入。注入用测试副本/包装器，逐项比较已分配与已释放节点，不把工具不可用当作通过。
- **判定边界**：能运行不代表讲解/练习正确；静态审查不等同于故障注入；没有泄漏报告不自动证明所有失败路径正确。尚无生成内容，因此目前没有质量结论。
