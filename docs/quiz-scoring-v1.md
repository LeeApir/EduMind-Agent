# MVP 0.2 测验评分规则 v1

`quiz_schema_version = 1`、`rule_version = quiz-exact-text-v1`。本版本只评分 `learning-resources-v1` 生成、审核通过、已发布且当前 owner 可读取的 `exercise` 资源。资源 ID 与版本由服务端读取；客户端提供的题干、标准答案、解释、分数、正确性和错误模式一律不作为评分依据。

## 题目和作答

- 资源内容为 `{"items": [...]}`，包含 2–4 道题。每道题严格包含 `id`、`question`、`answer`、`explanation` 四个非空字符串；`id` 在资源内唯一且不超过 128 字符。标准答案是被审核资源中的 `answer`，而不是请求字段。
- 请求作答为 1–10 个 `{question_id, answer}` 对象；`answer` 必须是长度不超过 500 字符的字符串。未知题目 ID、重复题目 ID、额外字段或非字符串答案均拒绝。未提交的题目按未答处理，不因只提交正确题而抬高得分。
- 现有 v1 练习是固定短答案题，不能用 LLM 作语义判断。题目必须在审核时保证标准答案适合精确匹配；主观题和需要同义改写判断的题目不属于本规则支持的客观题。

## 确定性计算

对作答和标准答案分别做 Unicode NFKC、大小写折叠、首尾及连续空白归一化，然后进行完全相等比较。不做模糊匹配、同义词推断或模型复判。逐题按资源顺序返回 `correct`、已审核的 `explanation` 和错误模式：未答/空白为 `blank_answer`，非空但不相等为 `answer_mismatch`，正确为空列表。总分为正确题数除以资源中全部题数；同一资源版本、规则版本和作答得到相同结果。

评分结果同时携带资源 ID/版本、schema 版本、规则版本、正确题数和总题数，供 T012 写入只追加证据。T012 负责 HTTP 契约、owner 鉴权后的持久化与幂等；T020 负责前端提交。未来新增选择题、接受多个标准答案或更复杂的错误模式时，必须发布新 schema/规则版本，不得静默修改 v1 含义。
